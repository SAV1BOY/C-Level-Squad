# Planeamento Trimestral — Fase 02: Apostas Estratégicas

## Objetivo desta Fase

Definir as 3-5 apostas estratégicas do próximo trimestre — as áreas onde a organização
vai concentrar energia, recursos e atenção executiva para criar o maior impacto possível.
As apostas estratégicas traduzem a visão de longo prazo em prioridades trimestrais
concretas, informadas pela retrospetiva do trimestre anterior e pelo market update.
Priorizar significa dizer não a muitas coisas boas para dizer sim às poucas essenciais.

## Agentes Envolvidos

- **CEO Agent**: Lidera a definição de prioridades estratégicas e faz trade-offs
- **CFO Agent**: Quantifica o impacto financeiro e investimento de cada aposta
- **COO Agent**: Avalia viabilidade operacional de cada aposta
- **CTO Agent**: Avalia viabilidade técnica e dependências tecnológicas
- **CMO Agent**: Avalia oportunidade de mercado e impacto em growth
- **CHRO Agent**: Avalia capacidade de talento para executar cada aposta
- **Chief of Staff Agent**: Facilita o processo de decisão e documenta apostas

## Inputs Necessários

1. Quarterly Performance Report e lições aprendidas (output da Fase 00)
2. Market Update Report com implicações estratégicas (output da Fase 01)
3. OKRs carryover do trimestre anterior
4. Plano estratégico anual (para garantir alinhamento)
5. Inventário de capacidades e recursos disponíveis
6. Backlog de oportunidades e iniciativas pendentes
7. Feedback de board ou investidores (se aplicável)

## Processo (step-by-step)

1. **Opportunity inventory**: Chief of Staff Agent compila todas as oportunidades
   identificadas: lições do trimestre anterior, implicações do market update,
   carryover items e novas ideias dos agentes
2. **Strategic framing**: CEO Agent reafirma a visão e estratégia de longo prazo,
   definindo o contexto para as decisões trimestrais
3. **Opportunity assessment**: Cada agente avalia as oportunidades na sua área,
   estimando impacto potencial, esforço necessário e risco
4. **Trade-off discussion**: CEO Agent facilita a discussão de trade-offs, forçando
   a equipa a escolher entre opções mutuamente exclusivas ou que competem por recursos
5. **Portfolio balancing**: CFO Agent e CEO Agent garantem que o portfólio de apostas
   está equilibrado entre: defend (proteger o existente), extend (crescer o core) e
   create (criar novas oportunidades)
6. **Resource reality check**: CHRO Agent e COO Agent validam que os recursos
   (pessoas, orçamento, capacidade) existem para executar as apostas selecionadas
7. **Bet definition**: Para cada aposta selecionada, o agente responsável define:
   hipótese, métricas de sucesso, recursos necessários e owner
8. **Prioritization and sequencing**: CEO Agent finaliza a priorização e sequenciação
   das apostas, definindo qual é a mais importante se for preciso escolher
9. **Communication preparation**: Chief of Staff Agent prepara a comunicação das
   apostas estratégicas para a organização

## Outputs / Entregáveis

- **Strategic Bets Document**: Documento com as 3-5 apostas estratégicas definidas
- **Bet Canvas (por aposta)**: Canvas detalhado de cada aposta com hipótese e métricas
- **Resource Allocation Preview**: Visão preliminar de alocação de recursos
- **Portfolio Balance View**: Visualização do equilíbrio defend/extend/create
- **Trade-off Log**: Registo das decisões de trade-off e suas razões
- **Priority Stack Rank**: Ranking de prioridade entre as apostas
- **Communication Draft**: Rascunho de comunicação para a organização

## Quality Gates

| Gate | Critério | Responsável |
|------|----------|-------------|
| QG-02.1 | Máximo de 5 apostas estratégicas (foco é essencial) | CEO Agent |
| QG-02.2 | Cada aposta tem hipótese testável e métricas de sucesso | Chief of Staff |
| QG-02.3 | Recursos confirmados para executar as apostas selecionadas | CHRO Agent |
| QG-02.4 | Portfolio equilibrado entre defend, extend e create | CFO Agent |
| QG-02.5 | Trade-offs explícitos e documentados | CEO Agent |
| QG-02.6 | Apostas alinhadas com o plano estratégico anual | CEO Agent |

## Critérios para Avançar

Para progredir para a Fase 03 (OKRs and Roadmaps), todos os critérios devem ser satisfeitos:

- [ ] 3-5 apostas estratégicas definidas e priorizadas
- [ ] Cada aposta tem owner, hipótese e métricas de sucesso
- [ ] Recursos confirmados como suficientes para a execução
- [ ] Trade-offs documentados e aceites por todos os agentes
- [ ] Alinhamento com o plano estratégico anual confirmado
- [ ] Comunicação preparada para a organização

## Riscos desta Fase

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| Demasiadas apostas (falta de foco) | Alta | Alto | Limite rígido de 5 apostas; CEO Agent arbitra |
| Apostas desligadas da realidade operacional | Média | Alto | COO Agent valida execução para cada aposta |
| Consenso forçado que diluí boldness das apostas | Média | Médio | CEO Agent toma decisão final sem exigir unanimidade |
| Apostas "seguras" que não movem o needle | Alta | Alto | Exigir pelo menos uma aposta "create" transformacional |
| Falta de alinhamento com plano anual | Média | Médio | Verificação explícita de alinhamento como gate |

## Duração Estimada

- **Mínimo**: 1 dia útil (continuidade do trimestre anterior com poucas mudanças)
- **Típico**: 2-3 dias úteis
- **Máximo**: 5 dias úteis (mudança significativa de contexto)

> **Nota**: Estratégia é a arte de sacrifício. Se tudo é prioridade, nada é prioridade.
> A coragem para dizer "não" às boas ideias é o que separa organizações focadas de
> organizações dispersas.
