# Planeamento Anual — Fase 02: Escolhas Estratégicas

## Objetivo desta Fase

Definir as escolhas estratégicas fundamentais para o ano — as decisões de posicionamento,
investimento e foco que determinam a direção da organização. As escolhas estratégicas
são diferentes de objetivos ou OKRs: são decisões sobre "onde jogar" e "como ganhar"
que criam o enquadramento para todas as decisões operacionais do ano. São as decisões
que dizem tanto sobre o que a empresa não vai fazer quanto sobre o que vai fazer.

## Agentes Envolvidos

- **CEO Agent**: Lidera a formulação e decisão das escolhas estratégicas
- **CFO Agent**: Modela o impacto financeiro de cada escolha e cenários
- **CMO Agent**: Define posicionamento de mercado e estratégia de growth
- **CTO Agent**: Define estratégia tecnológica e prioridades de investimento
- **COO Agent**: Define modelo operacional e prioridades de eficiência
- **CHRO Agent**: Define estratégia de talento e capacidades organizacionais
- **Chief of Staff Agent**: Facilita o processo de decisão e documenta escolhas

## Inputs Necessários

1. Market Thesis aprovada (output da Fase 01)
2. Annual Retrospective com lições estratégicas (output da Fase 00)
3. Plano estratégico de longo prazo (3-5 anos) existente
4. Análise SWOT atualizada
5. Capacidades e recursos disponíveis
6. Perspetivas do board ou investidores (se aplicável)
7. Competitive intelligence detalhada

## Processo (step-by-step)

1. **Strategic context setting**: CEO Agent apresenta o contexto estratégico completo:
   retrospetiva, tese de mercado, visão de longo prazo e estado atual da organização
2. **Where to play decision**: CEO Agent e CMO Agent definem os segmentos de mercado,
   geografias, customer segments e categorias de produto onde a empresa vai focar
3. **How to win decision**: CEO Agent e equipa definem a vantagem competitiva a
   construir ou reforçar: diferenciação, custo, experiência, tecnologia ou ecosystem
4. **Investment thesis**: CFO Agent e CEO Agent definem a tese de investimento anual:
   quanto investir, em quê e com que retorno esperado
5. **Build vs partner vs acquire**: Para cada capability gap, CEO Agent decide se vai
   construir internamente, encontrar parceiros ou adquirir
6. **Kill list definition**: CEO Agent define explicitamente o que a empresa vai parar
   de fazer, investir menos ou descontinuar para libertar recursos
7. **Strategic trade-offs**: CEO Agent facilita a discussão explícita de trade-offs:
   crescimento vs profitabilidade, velocidade vs qualidade, inovação vs core
8. **Capability requirements**: CHRO Agent e CTO Agent definem as capacidades
   organizacionais e tecnológicas necessárias para executar as escolhas
9. **Financial modeling**: CFO Agent modela o impacto financeiro das escolhas em
   cenários otimista, base e pessimista para o ano
10. **Strategic choices documentation**: Chief of Staff Agent documenta formalmente
    as escolhas estratégicas como o "documento constitucional" do ano

## Outputs / Entregáveis

- **Strategic Choices Document**: Documento principal com todas as escolhas do ano
- **Where-to-Play Map**: Mapa visual de segmentos e mercados priorizados
- **How-to-Win Statement**: Declaração de vantagem competitiva a construir
- **Investment Thesis**: Tese de investimento com alocação indicativa
- **Kill List**: Lista de iniciativas a descontinuar ou desinvestir
- **Trade-off Register**: Registo de trade-offs aceites com justificação
- **Capability Requirements**: Capacidades necessárias para executar as escolhas
- **Financial Scenarios**: Modelo financeiro com cenários para o ano

## Quality Gates

| Gate | Critério | Responsável |
|------|----------|-------------|
| QG-02.1 | Where-to-play definido com segmentos específicos e mensuráveis | CMO Agent |
| QG-02.2 | How-to-win articulado com vantagem competitiva clara | CEO Agent |
| QG-02.3 | Kill list com pelo menos 3 items que libertam recursos | CEO Agent |
| QG-02.4 | Trade-offs explícitos e aceites (não tentativa de "tudo") | CEO Agent |
| QG-02.5 | Modelo financeiro com cenários validados por CFO Agent | CFO Agent |
| QG-02.6 | Capacidades necessárias mapeadas e gap analysis feita | CHRO Agent |

## Critérios para Avançar

Para progredir para a Fase 03 (Budget Allocation), todos os critérios devem ser satisfeitos:

- [ ] Escolhas estratégicas documentadas e aprovadas
- [ ] Where-to-play e how-to-win claros e específicos
- [ ] Kill list definida com owners para descontinuação
- [ ] Trade-offs explícitos e aceites por todos os agentes
- [ ] Modelo financeiro com cenários validados
- [ ] Capacidades necessárias identificadas

## Riscos desta Fase

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| Escolhas demasiado vagas ("crescer em tudo") | Alta | Crítico | Exigir especificidade e kill list |
| Falta de coragem para fazer trade-offs reais | Alta | Alto | CEO Agent decide, mesmo sem unanimidade |
| Escolhas desconectadas das capacidades reais | Média | Alto | Capability check obrigatório para cada escolha |
| Influência excessiva do board sem contexto operacional | Média | Médio | CEO Agent filtra e contextualiza input do board |
| Escolhas que mudam a cada mês (instabilidade estratégica) | Média | Alto | Commitment mínimo de 6 meses antes de revisão |

## Duração Estimada

- **Mínimo**: 3 dias úteis (continuidade estratégica com ajustes)
- **Típico**: 5-7 dias úteis
- **Máximo**: 10 dias úteis (mudança estratégica significativa)

> **Nota**: As escolhas estratégicas são as decisões mais importantes do ano. Cada
> escolha deve ser um compromisso genuíno, não uma declaração vazia de intenções.
> Se a organização não está disposta a alocar recursos e dizer "não" a alternativas,
> não é uma escolha — é um desejo.
