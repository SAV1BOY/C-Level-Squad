# Gestão de Stakeholders — Framework de Mapeamento e Engajamento

## Propósito e Contexto

Stakeholders são todas as pessoas ou grupos que têm interesse ou influência sobre as decisões
e resultados da organização. Gestão de stakeholders é a prática de identificar, priorizar e
engajar esses grupos de forma proativa — em vez de descobrir tarde demais que alguém importante
está insatisfeito, desinformado ou ativamente bloqueando uma iniciativa.

Este framework é especialmente relevante para C-levels que operam em ambientes complexos com
múltiplos stakeholders: investidores, board, clientes enterprise, reguladores, parceiros,
equipe interna. A capacidade de navegar essas relações é frequentemente a diferença entre uma
estratégia que se materializa e uma que morre na implementação.

## Quando Usar

- No lançamento de iniciativas que afetam múltiplos grupos
- Na preparação para mudanças organizacionais significativas
- Em processos de fundraising, M&A, IPO
- Ao assumir nova posição de liderança (mapear o campo político)
- Quando há resistência a uma iniciativa sem causa técnica óbvia
- Na gestão de grandes contas/clientes estratégicos

## Componentes do Framework

### 1. Mapeamento de Stakeholders

**Identificação:** Liste todos os stakeholders relevantes para a iniciativa:
- **Internos:** CEO, board, C-level peers, líderes de time, colaboradores impactados
- **Externos:** Investidores, clientes-chave, reguladores, parceiros, fornecedores
- **Indiretos:** Imprensa, comunidade, ecossistema, associações do setor

### 2. Matriz Influência × Interesse

```
              ALTO INTERESSE
                    |
    MANTER          |         GERENCIAR
    SATISFEITO      |         DE PERTO
    (Inform)        |         (Collaborate)
                    |
BAIXA INFLUÊNCIA ---|--- ALTA INFLUÊNCIA
                    |
    MONITORAR       |         MANTER
    (Minimal)       |         INFORMADO
                    |         (Consult)
                    |
              BAIXO INTERESSE
```

| Quadrante | Estratégia | Cadência |
|-----------|-----------|----------|
| Gerenciar de perto | Engajamento ativo, co-criação, feedback loops | Semanal+ |
| Manter satisfeito | Informar proativamente, consultar em temas relevantes | Quinzenal |
| Manter informado | Updates regulares, estar disponível para consultas | Mensal |
| Monitorar | Updates quando relevante, não over-communicate | Trimestral |

### 4. Stakeholder Communication Plan

| Stakeholder | Canal Preferido | Frequência | Conteúdo | Owner |
|-------------|----------------|-----------|----------|-------|
| Board | Meeting + report | Trimestral | Strategy, financials | CEO |
| Investidores | Email update | Mensal | Metrics, highlights | CEO |
| Clientes key | QBR | Trimestral | Roadmap, value review | CS/Sales |
| Reguladores | Formal | Conforme necessário | Compliance, cooperação | Legal |
| Equipe | All-hands | Mensal | Direction, wins, asks | CEO |
| Parceiros | Meeting | Mensal | Pipeline, joint initiatives | BD |

## Processo Passo-a-Passo

### Fase 1: Mapeamento (1-2 dias)
1. Listar todos os stakeholders relevantes (brainstorm com equipe)
2. Classificar na matriz Influência × Interesse
3. Identificar posição atual de cada stakeholder no quadrante "gerenciar de perto"
4. Documentar o que importa para cada um (do ponto de vista DELES, não nosso)

### Fase 2: Estratégia (1 dia)
1. Para cada stakeholder crítico, definir posição desejada
2. Identificar gap entre posição atual e desejada
3. Definir ações específicas para mover stakeholders (informar, consultar, co-criar)
4. Atribuir owners para cada relacionamento

### Fase 3: Execução (contínuo)
1. Implementar cadência de comunicação por stakeholder
2. Registrar interações e compromissos (CRM ou doc compartilhado)
3. Monitorar sinais de mudança de posição
4. Adaptar estratégia conforme contexto evolui

### Fase 4: Revisão (mensal)
1. Rever posição de stakeholders críticos
2. Identificar novos stakeholders (reguladores, concorrentes, contratações-chave)
3. Avaliar eficácia das ações de engajamento
4. Ajustar plano para o próximo mês

## Métricas de Sucesso

| Métrica | Alvo | Frequência |
|---------|------|------------|
| Stakeholder satisfaction (key accounts) | > 4/5 | Trimestral |
| Board relationship quality | NPS > 8/10 | Semestral |
| Investor update timeliness | 100% no prazo | Mensal |
| Key stakeholder meetings completed | > 90% da cadência | Mensal |
| Stakeholder surprises (negative) | 0 | Contínuo |
| Support on critical decisions | > 80% dos key stakeholders apoiam | Por decisão |
