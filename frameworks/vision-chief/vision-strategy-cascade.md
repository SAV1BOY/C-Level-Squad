# Cascade de Visão para Estratégia — Framework de Desdobramento

## Propósito e Contexto

A maioria das organizações sofre de um problema silencioso: a visão existe no topo, mas se dissolve
antes de chegar às equipes que executam. O resultado é uma desconexão entre o que a liderança
acredita estar comunicando e o que os times realmente entendem como prioridade.

O framework de Cascade de Visão para Estratégia resolve esse problema criando uma cadeia explícita
de tradução: Visão → Tese Estratégica → Prioridades Estratégicas → Objetivos por Área →
Iniciativas → Métricas de Progresso. Cada nível traduz o anterior em linguagem e granularidade
apropriadas para seu contexto de decisão.

Este framework foi desenhado para organizações de 50 a 5.000 pessoas, onde a distância entre
visão e execução já é grande o suficiente para criar ruído, mas ainda é possível manter coerência
sem burocracia excessiva.

## Quando Usar

- Após definição ou atualização da visão organizacional
- No início de ciclo de planejamento estratégico (anual ou semestral)
- Quando há percepção de desalinhamento entre áreas ou camadas hierárquicas
- Depois de mudanças significativas na liderança sênior
- Quando times reportam confusão sobre prioridades ou direção
- Para onboarding de novos executivos C-Level

## Quando NÃO Usar

- Como exercício puramente top-down sem input das camadas de execução
- Em momentos de crise aguda onde decisão rápida importa mais que alinhamento
- Como substituto para conversas difíceis sobre trade-offs estratégicos
- Quando a visão em si ainda não está clara (use primeiro o vision-chief-strategic-thesis.md)

## Componentes do Framework

### 1. Pirâmide de Tradução Estratégica

```
VISÃO (10 anos)
  "Onde queremos chegar?"
    │
TESE ESTRATÉGICA (3-5 anos)
  "Qual nossa aposta fundamental?"
    │
PRIORIDADES ESTRATÉGICAS (12-18 meses)
  "Quais as 3-5 batalhas que precisamos vencer?"
    │
OBJETIVOS POR ÁREA (trimestral)
  "O que cada área precisa entregar?"
    │
INICIATIVAS (trimestral/mensal)
  "Quais projetos e ações específicas?"
    │
MÉTRICAS DE PROGRESSO (semanal)
  "Como sabemos que estamos avançando?"
```

### 2. Matriz de Coerência

Cada nível deve responder a três perguntas de coerência:
- **Para cima**: "Como isso contribui para o nível acima?"
- **Lateral**: "Isso conflita com prioridades de outras áreas?"
- **Para baixo**: "Isso é traduzível em ações concretas no próximo nível?"

### 3. Filtro de Prioridades Estratégicas

Para cada prioridade candidata, avaliar:
- **Essencialidade**: Se não fizermos isso, a tese estratégica falha?
- **Timing**: Por que agora e não daqui a 6 meses?
- **Capacidade**: Temos (ou podemos construir) capacidade para executar?
- **Mensurabilidade**: Conseguimos saber se estamos progredindo?

## Processo Passo-a-Passo

### Fase 1: Articulação da Visão (1-2 semanas)

1. Reunir o time executivo para sessão de alinhamento sobre visão
2. Documentar a visão em formato narrativo (não apenas uma frase)
3. Validar que cada executivo consegue articular a visão com suas próprias palavras
4. Identificar as 3-5 premissas implícitas na visão
5. Testar essas premissas contra dados de mercado disponíveis

### Fase 2: Derivação da Tese Estratégica (1-2 semanas)

1. A partir da visão, formular a tese estratégica central
2. Identificar as hipóteses que sustentam a tese
3. Para cada hipótese, definir sinais de confirmação e refutação
4. Documentar usando o template do vision-chief-strategic-thesis.md
5. Obter validação formal do board ou conselho

### Fase 3: Definição de Prioridades Estratégicas (1 semana)

1. Listar todas as potenciais prioridades (brainstorm amplo)
2. Aplicar o Filtro de Prioridades em cada candidata
3. Selecionar no máximo 5 prioridades (idealmente 3)
4. Para cada prioridade, definir o "Definition of Done" em 12-18 meses
5. Mapear interdependências entre prioridades
6. Atribuir um sponsor executivo para cada prioridade

### Fase 4: Tradução por Área (2 semanas)

1. Cada área traduz as prioridades em seus objetivos específicos
2. Líderes de área apresentam seus objetivos ao time executivo
3. Identificar sobreposições, gaps e conflitos entre áreas
4. Negociar recursos e sequenciamento entre áreas
5. Formalizar os objetivos de cada área com métricas claras

### Fase 5: Cascateamento para Iniciativas (1-2 semanas)

1. Cada área desdobra seus objetivos em iniciativas concretas
2. Priorizar iniciativas usando framework de impacto vs esforço
3. Definir owners, timelines e recursos para cada iniciativa
4. Criar dashboard de acompanhamento integrado
5. Estabelecer ritmo de revisão (semanal/quinzenal)

## Template: Documento de Cascade

```markdown
# Cascade Estratégica — [Período]

## Visão
[Narrativa de 2-3 parágrafos]

## Tese Estratégica
[Hipótese central + premissas]

## Prioridades Estratégicas

### Prioridade 1: [Nome]
- Sponsor: [Executivo]
- Definition of Done: [Descrição clara]
- Prazo: [Data]
- Áreas envolvidas: [Lista]
- Métricas: [KPIs específicos]

### Prioridade 2: [Nome]
...

## Tradução por Área

### [Nome da Área]
| Objetivo | Prioridade vinculada | Métrica | Meta | Status |
|----------|---------------------|---------|------|--------|
| ...      | ...                 | ...     | ...  | ...    |

## Mapa de Dependências
[Diagrama ou lista de dependências entre áreas]

## Cadência de Revisão
- Semanal: Check de métricas operacionais
- Mensal: Revisão de progresso das iniciativas
- Trimestral: Revisão de objetivos e prioridades
- Semestral: Revisão da tese estratégica
```

## Checklist de Qualidade do Cascade

- [ ] Cada nível é claramente derivado do anterior
- [ ] Não existem mais de 5 prioridades estratégicas
- [ ] Cada prioridade tem um sponsor executivo nomeado
- [ ] As métricas são mensuráveis e têm baseline definido
- [ ] As dependências entre áreas estão explicitamente mapeadas
- [ ] O cascade foi comunicado para toda a organização
- [ ] Existe um ritmo de revisão definido e agendado
- [ ] Cada time sabe como seu trabalho conecta à visão

## Métricas de Sucesso do Framework

- **Clareza percebida**: >80% dos colaboradores conseguem articular as prioridades estratégicas
- **Alinhamento**: >90% das iniciativas ativas mapeiam para uma prioridade estratégica
- **Velocidade de decisão**: Redução no tempo para resolver conflitos de prioridade entre áreas
- **Coerência**: <10% de sobreposição não intencional entre iniciativas de áreas diferentes
- **Adaptabilidade**: Tempo para recascatear após mudança de prioridade < 2 semanas

## Anti-Padrões Comuns

1. **Cascade de PowerPoint**: Documentar tudo perfeitamente mas nunca usar no dia-a-dia
2. **Excesso de prioridades**: Ter 15 "prioridades" é não ter nenhuma
3. **Cascade unidirecional**: Apenas top-down, sem feedback da execução
4. **Métricas de vaidade**: KPIs que não refletem progresso real
5. **Cascade estática**: Não revisar quando o contexto muda significativamente
