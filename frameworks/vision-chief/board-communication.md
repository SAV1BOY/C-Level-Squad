# Framework de Comunicação com Board — Governança Executiva

## Propósito e Contexto

A comunicação com o Conselho de Administração (Board) é uma das competências mais críticas e
menos ensinadas na formação executiva. Um board bem informado é um ativo estratégico — fornece
governança, orientação e conexões. Um board mal informado é um passivo — consome tempo executivo
com perguntas que deveriam ter sido respondidas proativamente e toma decisões baseadas em
informação incompleta.

Este framework estrutura a comunicação board-management para maximizar a qualidade das
discussões, construir confiança e garantir que o tempo do conselho gere valor real para a
empresa. É especialmente relevante para CEOs de primeira viagem, empresas em transição de
founder-led para governance profissional, e momentos de crise ou transformação.

## Quando Usar

- Na preparação de qualquer reunião de conselho (ordinária ou extraordinária)
- Ao estabelecer a cadência de comunicação com um novo board
- Em momentos de crise que exigem comunicação rápida e precisa
- Ao preparar pedidos de aprovação (budget, M&A, fundraising)
- Na transição entre estágios da empresa (seed → Series A → growth → IPO)
- Quando há tensão board-management que precisa ser endereçada

## Componentes do Framework

### 1. Arquitetura de Comunicação

**Cadência Regular:**
- Board Package: enviado 5 dias antes da reunião
- Board Meeting: reunião trimestral (3-4h)
- Board Update: email mensal entre reuniões
- Board Dinners: 1-2x por ano para relacionamento informal
- Committee Meetings: Audit, Compensation, conforme necessário

**Comunicação Ad Hoc:**
- Regra de Ouro: board members nunca devem ser surpreendidos
- Notícias ruins viajam rápido — comunique antes que descubram por fora
- Cadeia: CEO → Chair → Board (nunca pule o Chair)

### 2. Estrutura do Board Package

O board package é o documento preparatório. Deve ser auto-contido — um membro deveria
entender a situação sem assistir à reunião.

**Seção 1: Resumo Executivo (1 página)**
- 3 destaques positivos
- 2-3 preocupações/riscos
- 1-2 decisões necessárias do board
- Mudanças desde o último report

**Seção 2: Métricas-Chave (2-3 páginas)**
- Dashboard financeiro: receita, burn, runway, unit economics
- Dashboard operacional: growth, retention, NPS, headcount
- Pipeline e forecast
- Comparação com plano/budget
- Tendências (mínimo 6 meses de dados para mostrar trajetória)

**Seção 3: Tópicos Estratégicos (2-5 páginas)**
- 1-2 deep dives em temas relevantes
- Formato: Contexto → Opções → Recomendação → Decisão necessária
- Análise com dados, não apenas narrativa

**Seção 4: Apêndice**
- Financials detalhados
- Cap table atualizado
- Org chart com mudanças
- Atas pendentes para aprovação

### 3. Formato da Reunião de Board

**Agenda Modelo (3.5 horas):**
```
00:00 - 00:15  Abertura e aprovação de atas anteriores
00:15 - 00:45  CEO Update (contexto estratégico, não repetir o package)
00:45 - 01:15  Deep Dive #1 (tema estratégico com discussão)
01:15 - 01:30  Intervalo
01:30 - 02:00  CFO Update (financeiro com projeções)
02:00 - 02:30  Deep Dive #2 (tema estratégico com discussão)
02:30 - 03:00  Decisões formais e votações
03:00 - 03:15  Sessão executiva (board sem management)
03:15 - 03:30  Feedback do Chair para o CEO
```

**Regras de Ouro para a Reunião:**
- Nunca leia slides — o package já foi enviado
- Comece com as notícias ruins — constrói confiança
- Reserve 50% do tempo para discussão, não apresentação
- Tenha posição sobre cada tema — boards respeitam convicção
- Documente action items e owners antes de encerrar

### 4. Board Update Mensal

Email conciso (máximo 1 página) entre reuniões:

```markdown
Assunto: [Empresa] — Board Update [Mês/Ano]

## TL;DR
[3 bullets com as informações mais importantes]

## Métricas
- MRR: R$ X (+Y% MoM)
- Burn: R$ X (runway: Y meses)
- Headcount: X (+/- Y)

## Wins
- [Conquista 1]
- [Conquista 2]

## Preocupações
- [Risco/problema 1 com ação sendo tomada]

## Asks
- [Pedido específico para board members, se houver]
```

## Processo Passo-a-Passo

### Preparação (T-3 semanas antes da reunião)
1. Definir agenda com o Chair — alinhar os deep dives
2. Coletar inputs de cada C-level para suas seções
3. Identificar 1-2 decisões que precisam de aprovação formal

### Produção (T-2 semanas)
1. Montar o board package seguindo a estrutura acima
2. Revisão do CFO em todas as métricas financeiras
3. Revisão do General Counsel em temas legais/compliance
4. Revisão final do CEO — teste: "Eu ficaria confortável se vazasse?"

### Distribuição (T-5 dias)
1. Enviar board package pela plataforma segura (Diligent, BoardVantage)
2. Oferecer pre-reads individuais para membros com temas delicados
3. Confirmar presença e quorum

### Pós-Reunião (T+2 dias)
1. Distribuir atas em até 48h
2. Registrar action items com owners e deadlines
3. Follow-up individual com membros que tiveram concerns

## Checklist de Qualidade

- [ ] O package foi enviado com pelo menos 5 dias de antecedência?
- [ ] Métricas mostram tendência (≥ 6 meses), não apenas snapshot?
- [ ] Notícias ruins estão presentes e contextualizadas?
- [ ] Cada decisão tem opções claras com recomendação da management?
- [ ] O tempo de reunião é ≥ 50% discussão, ≤ 50% apresentação?
- [ ] Não há surpresas — membros já foram preparados para temas sensíveis?
- [ ] Action items da reunião anterior foram reportados?
- [ ] Cap table e runway estão atualizados?

## Métricas de Sucesso

| Métrica | Alvo | Frequência |
|---------|------|------------|
| Board NPS (pesquisa anônima) | > 8/10 | Semestral |
| Tempo de discussão vs apresentação | > 50% discussão | Por reunião |
| Package enviado on time | 100% com ≥ 5 dias de antecedência | Por reunião |
| Decisões tomadas por reunião | ≥ 2 decisões substantivas | Por reunião |
| Board member engagement | 100% leram o package antes da reunião | Por reunião |
| Follow-up completion rate | > 90% dos action items concluídos | Por reunião |

## Erros Comuns

1. **Information dump** — Enviar 80 slides pensando que mais = melhor
2. **Sunshine reporting** — Só mostrar métricas boas, esconder problemas
3. **Pedir aprovação sem opções** — Board quer governar, não rubber-stamp
4. **Tratar board como ameaça** — Board alinhado é o maior aliado do CEO
5. **Não usar o board** — Members têm redes e experiência; peça ajuda específica
6. **Surpresas em reunião** — Comunicar notícias ruins pela primeira vez na reunião
