# Kill Phrases — Frases para Matar Projetos, Iniciativas e Ideias

## Princípio Central

Saber matar é tão importante quanto saber começar. Organizações que não matam projetos
diluem foco, desperdiçam recursos e criam dívida organizacional. Estas frases facilitam
a decisão de parar — com clareza, dados e dignidade.

**Mantra: "Não passou no gate. Dados insuficientes. Kill."**

---

## Frases de Avaliação para Kill

1. **"Não passou no gate. Os critérios de sucesso não foram atingidos."**
   Contexto: Quando há gate review com critérios pré-definidos.

2. **"Dados insuficientes para continuar investindo. Kill ou pivot, não mais do mesmo."**
   Contexto: Quando o experimento não gerou evidência suficiente.

3. **"Se começássemos do zero hoje, investiríamos nisso? Se não, por que continuamos?"**
   Contexto: Zero-base thinking para desafiar inércia.

4. **"O custo de oportunidade é maior que o benefício potencial. Vamos realocar."**
   Contexto: Quando há opções melhores para o mesmo recurso.

5. **"3 quarters sem tração. O mercado votou. Hora de ouvir."**
   Contexto: Quando múltiplos ciclos não geram resultado.

6. **"Estamos investindo por convicção ou por sunk cost? Se for sunk cost, pare."**
   Contexto: Sunk cost fallacy check.

7. **"O que mudou desde que começamos? Se as premissas não são mais válidas, o projeto não é."**
   Contexto: Reavaliação quando contexto muda.

---

## Frases de Decisão de Kill

8. **"Decisão: descontinuamos [projeto]. Motivo: [dados]. Efetivo: [data]."**
   Contexto: Comunicar kill decision com clareza.

9. **"Não é fracasso. É aprendizado aplicado. O que aprendemos vale o investimento."**
   Contexto: Reframing positivo para o time que trabalhou no projeto.

10. **"Matar o projeto agora evita desperdiçar mais [X meses / $Y / Z pessoas]."**
    Contexto: Quantificar o que se economiza ao parar.

11. **"Preferimos um kill rápido a uma morte lenta. Mortes lentas consomem mais."**
    Contexto: Justificar velocidade na decisão de kill.

12. **"O projeto morreu. A equipe vive. Vamos realocar para onde terão mais impacto."**
    Contexto: Proteger as pessoas mesmo quando o projeto é cortado.

---

## Frases de Critério de Kill

13. **"Kill criteria definidos no início: se [métrica] < [threshold] em [prazo], matamos."**
    Contexto: Definir critério de kill antes de começar.

14. **"Qual é o mínimo aceitável? Se não atingimos, não faz sentido continuar."**
    Contexto: Minimum viable success definition.

15. **"Gate review: resultados vs critérios. Passou ou não passou. Sem zona cinza."**
    Contexto: Rigor na avaliação de gates.

16. **"Se precisamos de mais uma exceção para justificar continuar, é hora de parar."**
    Contexto: Quando exceções viram regra.

17. **"O que precisaria ser verdade para continuar? Se não é plausível, kill."**
    Contexto: Reverse engineering da viabilidade.

---

## Frases de Comunicação de Kill

18. **"Para o time: obrigado pelo esforço. O projeto não deu resultado, mas vocês deram."**
    Contexto: Comunicar com dignidade para quem trabalhou.

19. **"Para a empresa: descontinuamos [X] para focar em [Y, Z]. Os recursos serão melhor utilizados."**
    Contexto: Comunicar para toda a organização.

20. **"Para o Board: killamos [projeto] por [motivo]. Saving: [valor]. Realocação: [para onde]."**
    Contexto: Comunicar para o Board com dados financeiros.

21. **"Lessons learned documentados e compartilhados. O aprendizado não morre com o projeto."**
    Contexto: Capturar valor do investimento feito.

22. **"A decisão de matar é mais difícil que a decisão de começar. Mas igualmente importante."**
    Contexto: Normalizar kills como parte da gestão.

---

## Frases de Resistência a Kill (e Como Responder)

23. **Argumento: "Mas já investimos tanto..." → Resposta: "Sunk cost. O investimento passado não muda o retorno futuro."**
    Contexto: Combater sunk cost fallacy.

24. **Argumento: "Mais 3 meses e funciona." → Resposta: "Isso foi dito há 3 meses. Que evidência nova justifica mais tempo?"**
    Contexto: Exigir evidência, não esperança.

25. **Argumento: "O competidor faz." → Resposta: "O competidor pode ter prioridades diferentes. Nosso contexto é [X]."**
    Contexto: Decisão baseada em nosso contexto, não no do outro.

26. **Argumento: "O time vai ficar desmotivado." → Resposta: "Mais desmotivante é trabalhar em algo sem futuro."**
    Contexto: Reframing de motivação.

27. **Argumento: "Era minha ideia..." → Resposta: "Respeito a ideia. Os dados não sustentam. Isso não é pessoal."**
    Contexto: Separar ego de decisão.

---

## Frases de Kill Preventivo

28. **"Antes de começar: quais são os kill criteria? Se não definirmos agora, não mataremos depois."**
    Contexto: Pre-mortem de kill criteria.

29. **"Budget para experimentar, não para escalar. Se o experimento falhar, matamos sem culpa."**
    Contexto: Ring-fencing de investimento experimental.

30. **"Time-box: 6 semanas. Se não mostrar [resultado], paramos. Sem negociação."**
    Contexto: Limitar investimento no tempo.

31. **"Matar uma ideia no papel é grátis. Matar um projeto em andamento custa. Filtre cedo."**
    Contexto: Investir em avaliação prévia rigorosa.

32. **"Quantas coisas estamos fazendo? Se mais de [X], precisamos matar [Y] para focar."**
    Contexto: Portfolio management — kill para liberar foco.

33. **"A melhor hora para matar um projeto ruim é agora. A segunda melhor foi ontem."**
    Contexto: Urgência em decisões de kill.

34. **"Nem toda semente vira árvore. Plantar é fácil. Podar é necessário."**
    Contexto: Metáfora para normalizar kills.

35. **"Dizer 'não' a uma coisa boa é o que permite dizer 'sim' a uma coisa excelente."**
    Contexto: Priorização como disciplina de kill.

---

## Uso e Contexto

Frases de kill são mais eficazes quando:
- Kill criteria são definidos ANTES de começar (não retroativamente)
- A cultura normaliza kill como disciplina, não fracasso
- Há realocação imediata de recursos (pessoas não ficam no limbo)
- Lessons learned são capturadas e compartilhadas
- O líder modela: mata seus próprios projetos quando dados pedem
