# Tarefa: Scan de Tendências de Mercado

> Processo para monitorar e analisar tendências de mercado que impactam
> a estratégia da organização.

---

## Contexto
O scan de tendências permite identificar oportunidades e ameaças antes
que se tornem óbvias, garantindo vantagem competitiva informacional.

**Frequência**: Mensal (scan) + Trimestral (análise profunda)
**Responsável**: CEO / CAIO Architect
**Duração**: 2-3 dias (scan mensal), 1 semana (análise trimestral)

---

## 1. Categorias de Tendências

### 1.1 Tecnológicas
- [ ] Novas tecnologias emergentes no setor (AI, blockchain, edge computing)
- [ ] Mudanças em plataformas dominantes (cloud providers, frameworks)
- [ ] Open source relevante lançado ou abandonado
- [ ] Padrões de adoção tecnológica no mercado-alvo
- [ ] Evolução de APIs e ecossistemas de integração

### 1.2 Mercado e Clientes
- [ ] Mudanças no comportamento de compra do ICP
- [ ] Novos segmentos ou use cases emergentes
- [ ] Evolução de expectativas de clientes
- [ ] Tendências de consolidação ou fragmentação do mercado
- [ ] Mudanças em budget allocation dos clientes

### 1.3 Regulatórias
- [ ] Novas regulamentações em discussão ou aprovadas
- [ ] Mudanças em compliance requirements
- [ ] Regulamentação de AI e dados pessoais
- [ ] Impacto regulatório em mercados adjacentes
- [ ] Tendências regulatórias internacionais relevantes

### 1.4 Econômicas
- [ ] Indicadores macroeconômicos relevantes (juros, câmbio, inflação)
- [ ] Tendências de investimento no setor (VC, PE, M&A)
- [ ] Ciclos econômicos e impacto no setor
- [ ] Mudanças em dinâmicas de pricing do mercado

### 1.5 Sociais e Culturais
- [ ] Mudanças em padrões de trabalho (remoto, híbrido)
- [ ] Evolução de expectativas de sustentabilidade e ESG
- [ ] Tendências de talento e mercado de trabalho
- [ ] Mudanças demográficas relevantes

## 2. Fontes de Informação

| Fonte | Tipo | Frequência |
|-------|------|-----------|
| Newsletters especializadas | Curado | Diário |
| Relatórios de analistas (Gartner, CB Insights) | Profundo | Trimestral |
| Podcasts do setor | Opinião qualificada | Semanal |
| Conferências e eventos | Networking + conteúdo | Trimestral |
| LinkedIn e Twitter de thought leaders | Tendências emergentes | Diário |
| Artigos acadêmicos | Pesquisa fundamental | Mensal |
| Dados de mercado (Crunchbase, PitchBook) | Quantitativo | Mensal |
| Feedback de clientes e prospects | Primeira mão | Contínuo |
| Conversas com investidores | Visão macro | Trimestral |

## 3. Framework de Análise

### 3.1 Classificação de Tendências
Para cada tendência identificada:
- **Relevância**: Alta / Média / Baixa (para nosso negócio)
- **Horizonte**: Curto prazo (< 6m) / Médio (6-18m) / Longo (> 18m)
- **Impacto**: Oportunidade / Ameaça / Neutro
- **Confiança**: Alta / Média / Baixa (na materialização)
- **Ação requerida**: Sim / Monitorar / Não

### 3.2 Análise de Implicações
Para tendências de alta relevância:
- [ ] Qual o impacto direto no nosso negócio?
- [ ] Precisamos ajustar produto, pricing ou posicionamento?
- [ ] Há oportunidade de first-mover advantage?
- [ ] Qual o risco de não agir?
- [ ] Quais competidores já estão se movendo?

## 4. Deliverables

```

Top 3 Tendências para Atenção:
1. [Tendência] - Impacto: [descrição] - Ação: [recomendação]
2. [Tendência] - Impacto: [descrição] - Ação: [recomendação]
3. [Tendência] - Impacto: [descrição] - Ação: [recomendação]

Movimentos de Mercado Notáveis:
- [Movimento 1]
- [Movimento 2]

Watch List (monitorar):
- [Item 1]
- [Item 2]
```

### Análise Trimestral (5-8 páginas)
- Análise profunda de tendências com dados de suporte
- Implicações estratégicas detalhadas
- Recomendações de ação priorizadas
- Atualização do mapa competitivo

## 5. Distribuição e Ação

- [ ] Report mensal distribuído ao C-Level na primeira semana do mês
- [ ] Análise trimestral apresentada na quarterly review
- [ ] Insights relevantes compartilhados com time de produto
- [ ] Ações derivadas adicionadas ao backlog estratégico
- [ ] Tendências de alto impacto discutidas com o board
