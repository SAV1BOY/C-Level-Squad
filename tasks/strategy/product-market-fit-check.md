# Tarefa: Check de Product-Market Fit

> Framework para avaliar continuamente o grau de product-market fit,
> identificando sinais de fortalecimento ou enfraquecimento.

---

**Frequência**: Trimestral
**Responsável**: CEO / Product Lead
**Duração**: 3-5 dias

---

## 1. Métricas Quantitativas de PMF

### 1.1 Retenção
- [ ] Cohort retention curve por mês (achatamento = PMF)
- [ ] D7, D30, D90 retention rates
- [ ] Revenue retention (NRR) > 100%?
- [ ] Logo retention > 90% (mensal)?
- [ ] Trend de retenção: melhorando ou piorando?

### 1.2 Crescimento Orgânico
- [ ] % de novos clientes via referral/word-of-mouth
- [ ] Crescimento orgânico vs. pago
- [ ] Inbound vs. outbound pipeline ratio
- [ ] Viral coefficient (se aplicável)
- [ ] Trend: crescimento orgânico aumentando?

### 1.3 Engajamento
- [ ] DAU/MAU ratio (target: > 25% para B2B SaaS)
- [ ] Frequência de uso por usuário
- [ ] Features core vs. features opcionais uso
- [ ] Time-to-value para novos clientes
- [ ] Profundidade de uso (features/sessão)

### 1.4 Satisfação
- [ ] NPS (target: > 40 para forte PMF)
- [ ] CSAT score
- [ ] Sean Ellis test ("Como você se sentiria se não pudesse mais usar?")
  - Target: > 40% respondem "muito desapontado"
- [ ] Volume de pedidos de feature vs. reclamações
- [ ] Velocidade de resposta a surveys (engajamento)

### 1.5 Monetização
- [ ] Willingness to pay demonstrada (sem descontos excessivos)
- [ ] Expansion revenue crescendo
- [ ] Ciclo de vendas encurtando
- [ ] Objeções de preço diminuindo
- [ ] Clientes pagando mais ao longo do tempo

## 2. Sinais Qualitativos de PMF

### 2.1 Sinais Positivos (PMF forte)
- [ ] Clientes advogam espontaneamente pelo produto
- [ ] Demanda supera capacidade de atendimento
- [ ] Clientes resistem a cancelar mesmo com problemas
- [ ] Uso se espalha organicamente dentro das organizações
- [ ] Time de vendas fecha deals com facilidade crescente
- [ ] Clientes usam o produto de formas não previstas
- [ ] Pull > Push (clientes vêm até nós)

### 2.2 Sinais de Alerta (PMF fraco)
- [ ] Alto churn sem motivos claros
- [ ] Clientes usam apenas features básicas
- [ ] Grande % de trials não converte
- [ ] Feedback genérico ("legal, mas...")
- [ ] Ciclo de vendas longo e dependente de descontos
- [ ] Muito customization pedido por cada cliente
- [ ] Engagement cai significativamente após onboarding

## 3. Sean Ellis Survey

### Perguntas Essenciais
1. "Como você se sentiria se não pudesse mais usar [produto]?"
   - Muito desapontado
   - Um pouco desapontado
   - Não ficaria desapontado
   - N/A - não uso mais

2. "Qual é o principal benefício que você obtém com [produto]?"
   - [Open-ended]

3. "Para quem você recomendaria [produto]?"
   - [Open-ended]

4. "Como podemos melhorar [produto] para você?"
   - [Open-ended]

### Interpretação
| % "Muito desapontado" | Interpretação |
|----------------------|---------------|
| > 40% | PMF forte - foco em crescimento |
| 25-40% | PMF moderado - iterar no produto |
| < 25% | PMF fraco - pivotar ou refinar |

## 4. Análise por Segmento

- [ ] PMF varia entre segmentos? (enterprise vs. SMB)
- [ ] Quais personas têm PMF mais forte?
- [ ] Há segmentos com PMF forte que não estamos priorizando?
- [ ] O ICP deve ser ajustado com base nos dados?
- [ ] Há padrões nos clientes que mais usam e valorizam?

## 5. PMF Scorecard

| Indicador | Score (1-5) | Trend | Peso |
|-----------|------------|-------|------|
| Retenção de cohort | | | 25% |
| NPS / Sean Ellis | | | 20% |
| Crescimento orgânico | | | 20% |
| Engajamento de uso | | | 15% |
| Facilidade de venda | | | 10% |
| Expansion revenue | | | 10% |
| **PMF Score** | | | **100%** |

> Score >= 4.0: PMF forte, acelerar growth
> Score 3.0-3.9: PMF moderado, iterar e testar
> Score < 3.0: PMF fraco, investigar profundamente

## 6. Ações com Base no Resultado

### PMF Forte
- Investir em growth e escala
- Expandir para segmentos adjacentes
- Aumentar preço (capturar mais valor)

### PMF Moderado
- Focar nos segmentos/personas com PMF mais forte
- Investir em features que melhoram retenção
- Refinar ICP e messaging

### PMF Fraco
- Conduzir customer development profundo
- Considerar pivot de produto ou mercado
- Reduzir burn e estender runway para iteração
