# Tarefa: Review de Diversidade e Inclusão (D&I)

## Objetivo
Avaliar o estado atual de diversidade e inclusão na organização, identificar gaps e definir ações concretas para criar um ambiente mais diverso, equitativo e inclusivo.

---

## 1. Coleta de Dados

### Dados Quantitativos
- [ ] Compilar dados demográficos da força de trabalho (gênero, raça/etnia, idade, PcD)
- [ ] Segmentar por nível hierárquico (IC, gestão, diretoria, C-Level)
- [ ] Segmentar por área funcional (engenharia, produto, vendas, etc.)
- [ ] Analisar dados de contratação por demografia (último 12 meses)
- [ ] Analisar dados de promoção por demografia (último 12 meses)
- [ ] Analisar dados de turnover por demografia (último 12 meses)
- [ ] Comparar compensação por grupo demográfico para mesma função/nível
- [ ] Benchmarkar dados contra mercado e indústria

### Dados Qualitativos
- [ ] Revisar resultados de pesquisa de engajamento com filtro de diversidade
- [ ] Conduzir grupos focais com grupos sub-representados (5-8 pessoas, facilitador externo)
- [ ] Entrevistar individualmente 10-15 pessoas de diferentes backgrounds
- [ ] Revisar comentários de Glassdoor e redes sociais sobre inclusão
- [ ] Analisar feedbacks de candidatos sobre processo seletivo
- [ ] Revisar incidentes reportados de discriminação ou assédio

## 3. Áreas de Ação

### 3.1 Recrutamento Inclusivo
- [ ] Revisar job descriptions para linguagem inclusiva (ferramentas como Textio)
- [ ] Diversificar canais de recrutamento (comunidades, universidades, bootcamps)
- [ ] Implementar blind resume screening (remover nome, foto, universidade)
- [ ] Treinar entrevistadores em viés inconsciente
- [ ] Garantir painel diverso de entrevistadores
- [ ] Definir metas de diversidade no pipeline (não cotas, mas metas de pipeline)
- [ ] Parcerias com organizações de recrutamento de grupos sub-representados
- [ ] Programa de estágio/aprendizagem focado em diversidade

### 3.2 Cultura Inclusiva
- [ ] Treinamento de viés inconsciente para toda a empresa (não one-shot, contínuo)
- [ ] Workshop de ally-ship para líderes (como ser aliado ativo)
- [ ] Criar ou fortalecer ERGs (Employee Resource Groups)
- [ ] Estabelecer calendário de datas de diversidade (com ações, não apenas posts)
- [ ] Incluir inclusão como critério em avaliações de liderança
- [ ] Garantir acessibilidade de espaços físicos e digitais para PcD
- [ ] Política clara de tolerância zero para discriminação e assédio

### 3.3 Equidade de Carreira
- [ ] Realizar pay equity audit anual e corrigir disparidades
- [ ] Garantir que promoções são proporcionais à representatividade
- [ ] Programa de mentoria para grupos sub-representados
- [ ] Sponsorship (não apenas mentoria) de talentos diversos por líderes senior
- [ ] Monitorar participação em projetos de alta visibilidade por demografia
- [ ] Flexibilidade de trabalho que considere necessidades diversas
- [ ] Benefícios inclusivos (licença parental equitativa, plano de saúde inclusivo)

### 3.4 Liderança e Accountability
- [ ] Definir metas de D&I para cada líder como parte dos OKRs
- [ ] Reportar métricas de diversidade trimestralmente para C-Level
- [ ] Incluir D&I como tema em reuniões de board
- [ ] CEO comunicar compromisso publicamente e regularmente
- [ ] Publicar relatório de diversidade anualmente (transparência)
- [ ] Vincular parcela de bônus de líderes a metas de D&I

- Budget dedicado para eventos e atividades
- Tempo de trabalho alocado para atividades do ERG (2-4h/mês)

- Canal de comunicação dedicado (Slack channel)
- Participação em decisões que afetam o grupo representado
