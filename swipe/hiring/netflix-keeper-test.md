# Netflix Keeper Test - Análise Completa

## O Que É o Keeper Test

O Keeper Test é a ferramenta central de gestão de talentos da Netflix.
A pergunta é simples:

> "Se [pessoa] me dissesse que está saindo para outra empresa, eu lutaria
> fortemente para mantê-la? Ou ficaria aliviado?"

Se a resposta é "não lutaria" ou "ficaria aliviado", a Netflix recomenda oferecer
um pacote de desligamento generoso imediatamente, em vez de esperar que a performance
naturalmente decline ou que a pessoa saia por conta própria.

## Origem e Filosofia

### Contexto de Criação
Patty McCord, VP de Talentos da Netflix de 1998 a 2012, desenvolveu o conceito junto
com Reed Hastings. Nasceu de uma observação durante os layoffs de 2001:

Após demitir 1/3 da empresa por necessidade financeira, a Netflix descobriu que
a produtividade aumentou. Os funcionários restantes, todos "keepers", eram mais
eficientes e felizes. A conclusão: talent density é mais importante que talent volume.

### Filosofia Subjacente
- Uma empresa não é uma família (famílias não demitem membros)
- Uma empresa é um time esportivo profissional
- Jogadores adequados são substituídos por jogadores excelentes
- Performance "adequada" não justifica uma posição em times de elite

## Como Funciona na Prática

### Aplicação pelo Gestor
1. O gestor se faz a pergunta do Keeper Test para cada membro do time
2. Para quem a resposta é "não", o gestor inicia uma conversa honesta
3. Se após coaching a resposta não muda, oferece pacote de desligamento
4. Pacote padrão: 4-9 meses de salário (generoso por design)

### Aplicação Reversa pelo Funcionário
Netflix encoraja funcionários a perguntarem ao gestor:
"Se eu te dissesse que estou saindo, você lutaria para me manter?"
O gestor é obrigado a responder honestamente.

### Frequência
- Não é um evento anual; é um mindset contínuo
- Gestores devem se fazer a pergunta regularmente
- Qualquer mudança significativa de contexto (nova estratégia, novos skills necessários)
  deve triggar uma reavaliação

## Critérios de Avaliação

O Keeper Test não é sobre "a pessoa é legal?" ou "trabalha muitas horas?"
Os critérios são:

### 1. Impacto no Resultado
- A pessoa está gerando resultados mensuráveis?
- Os resultados são proporcionais à compensação?
- Outro profissional no mercado geraria mais impacto na mesma posição?

### 2. Skills para o Futuro
- A pessoa tem as competências necessárias para onde a empresa está indo?
- Está se adaptando à evolução do negócio?
- O gap entre skills atuais e necessários é bridgeable?

### 3. Colaboração e Cultura
- A pessoa torna o time ao redor melhor?
- Feedback dos pares é consistentemente positivo?
- Comportamento é alinhado com os valores da empresa?

### 4. Substituibilidade
- Se a pessoa saísse amanhã, qual seria o impacto real?
- Quanto tempo levaria para contratar alguém equivalente ou melhor?
- O conhecimento da pessoa está documentado ou é single point of failure?

## Argumentos a Favor

### 1. Elimina Procrastinação em Decisões Difíceis
- Gestores naturalmente evitam conversas difíceis
- O framework dá "permissão" para agir
- Melhor para a pessoa: sair com dignidade e pacote generoso

### 2. Eleva o Bar de Performance
- Quando todos sabem que o teste existe, performance mediana é rara
- Auto-seleção: quem quer ambientes de alta performance vem; quem não quer sai
- O padrão do time sobe continuamente

### 3. Honestidade Sobre Expectativas
- Sem surpresas: funcionários sabem onde estão
- Feedback contínuo, não "surpresa no annual review"
- Relação profissional baseada em clareza, não em conforto

### 4. Alocação Eficiente de Capital
- Cada posição deve maximizar valor para o negócio
- Compensação alta + Keeper Test = só os melhores ficam
- ROI de cada hire é monitorado implicitamente

## Argumentos Contra

### 1. Gera Ansiedade Crônica
- Funcionários em ambiente de "julgamento constante" podem desenvolver ansiedade
- Fear of failure inibe risk-taking (paradoxo com cultura de inovação)
- Burnout é um risco em ambientes de pressão contínua

**Contra-argumento Netflix:** A generosidade do pacote reduz o medo.
Saber que sair não é catastrófico (4-9 meses de salário) permite correr riscos.

### 2. Viés do Gestor
- O Keeper Test depende 100% do julgamento do gestor
- Gestores podem manter "favoritos" e demitir "diferentes"
- Sem calibração formal, vieses se multiplicam

**Contra-argumento Netflix:** O feedback 360 e a transparência criam checks.
Se um gestor consistentemente perde talentos, o gestor falha no Keeper Test também.

### 3. Desincentiva Trabalho de Longo Prazo
- Se valor é medido por impacto visível, trabalho invisível é penalizado
- Infraestrutura, documentação e mentoria são subvalorizados
- Profissionais otimizam para "parecer impactante" ao invés de "ser impactante"

**Contra-argumento Netflix:** Gestores bons avaliam todo tipo de contribuição.
O problema é de calibração, não do framework.

### 4. Não Funciona para Todas as Culturas
- Mercados com leis trabalhistas rígidas (Brasil, Europa) limitam a aplicação
- Culturas que valorizam lealdade e pertencimento veem o teste como frio
- Em mercados com escassez de talentos, o custo de rotatividade é proibitivo

## Adaptação para o Contexto Brasileiro

### Limitações Legais
- CLT protege contra demissão sem justa causa (mas permite com pagamento)
- FGTS e multa rescisória encarecem desligamentos
- Estabilidade em certas condições (gestante, CIPA, acidentados)

### Adaptação Prática
Em vez de demissão rápida, adaptar para:

1. **Keeper Conversation:** Conversa trimestral honesta sobre performance
2. **Development Plan:** Para quem "não passa" no teste, plano de 90 dias
3. **Mutual Agreement:** Se o plano não funciona, acordo mútuo de saída
4. **Pacote Generoso:** Além do legal, oferecer bônus de transição

### Diferenças Culturais
- Brasileiros valorizam relacionamento pessoal no trabalho
- "Team, not family" pode ser visto como frieza excessiva
- Adaptar mensagem: "Time de alta performance que se cuida mutuamente"

## Checklist de Implementação

### Pré-Requisitos
- [ ] Cultura de feedback já estabelecida (não introduzir Keeper Test sem isso)
- [ ] Gestores treinados em conversas difíceis
- [ ] Compensação acima do mercado (atrai talento que aceita o trade-off)
- [ ] Pacotes de desligamento definidos e generosos
- [ ] Jurídico alinhado com regulamentação local

### Implementação
- [ ] Comunicar o conceito a toda a empresa com transparência
- [ ] Treinar gestores na aplicação justa e sem viés
- [ ] Estabelecer cadência de revisão (trimestral recomendado)
- [ ] Criar mecanismo de feedback reverso (funcionário avalia gestor)
- [ ] Documentar critérios de avaliação para evitar subjetividade excessiva

### Monitoramento
- [ ] Tracking de turnover voluntário vs involuntário
- [ ] Employee NPS antes e depois da implementação
- [ ] Diversidade das saídas (o teste está afetando grupos desproporcionalmente?)
- [ ] Tempo médio para backfill de posições
- [ ] Performance do time 6 meses após desligamentos
