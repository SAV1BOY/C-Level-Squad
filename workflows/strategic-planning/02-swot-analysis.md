# Workflow: Análise SWOT

## Objetivo
Estruturar a análise de Forças, Fraquezas, Oportunidades e Ameaças como base para definição de escolhas estratégicas, integrando dados do environmental scan.

---

## 1. Framework SWOT

### Definições
- **Strengths (Forças)**: Capacidades internas que nos dão vantagem
- **Weaknesses (Fraquezas)**: Limitações internas que nos prejudicam
- **Opportunities (Oportunidades)**: Fatores externos favoráveis que podemos explorar
- **Threats (Ameaças)**: Fatores externos desfavoráveis que podem nos prejudicar

### Regras para um Bom SWOT
- Ser específico: "boa equipe" não é uma força útil; "time de ML com 3 PhDs e experiência em NLP" é
- Usar dados e evidências para cada item
- Limitar a 5-7 itens por quadrante (foco nos mais relevantes)
- Garantir que forças e fraquezas são INTERNAS (sob nosso controle)
- Garantir que oportunidades e ameaças são EXTERNAS (fora do nosso controle)

---

## 2. Processo de Construção

### Passo 1: Coleta Individual (Assíncrono, 1 semana)
- Cada membro do C-Level preenche seu SWOT individualmente
- Usar dados do environmental scan como base
- Incluir perspectiva da própria área de responsabilidade
- Máximo 7 itens por quadrante
- Cada item com breve justificativa

### Passo 2: Consolidação (RH/Estratégia)
- Compilar todos os SWOTs individuais
- Identificar itens mencionados por múltiplos líderes (alto consenso)
- Identificar itens mencionados por apenas uma pessoa (perspectiva única)
- Agrupar itens similares em temas
- Preparar SWOT consolidado para discussão

### Passo 3: Workshop de SWOT (Sessão de 3h)
- Apresentar SWOT consolidado para o grupo
- Debater e ajustar cada quadrante com evidências
- Votar nas prioridades dentro de cada quadrante (dot voting)
- Selecionar top 5 de cada quadrante para análise cruzada
- Documentar SWOT final aprovado pelo grupo

|---|-------|-----------|-------------------|

| # | Fraqueza | Evidência | Impacto Estratégico |
|---|---------|-----------|-------------------|

## 4. Análise Cruzada (TOWS Matrix)

### Estratégias Baseadas no Cruzamento

| Cruzamento | Estratégia | Exemplos |
|-----------|-----------|---------|
| **S+O** (Maxi-Maxi) | Usar forças para capitalizar oportunidades | Usar time de ML (S2) para capturar mercado de AI (O1) |
| **S+T** (Maxi-Mini) | Usar forças para mitigar ameaças | Usar brand forte (S5) para reter clientes vs big tech (T1) |
| **W+O** (Mini-Maxi) | Superar fraquezas para explorar oportunidades | Resolver debt técnico (W2) para acelerar produto de AI (O1) |
| **W+T** (Mini-Mini) | Minimizar fraquezas e evitar ameaças | Diversificar base de clientes (W1) antes de recessão (T3) |

| 2 | S+T | [Descrição da estratégia] | [S3, S5] | [T1] | Alta |

---

## 5. Priorização

### Critérios de Priorização
Para cada estratégia identificada na TOWS, avaliar:

| Critério | Peso | Escala |
|----------|------|--------|
| Impacto potencial em receita | 30% | 1-5 |
| Urgência (janela de oportunidade) | 25% | 1-5 |
| Viabilidade (temos recursos?) | 25% | 1-5 |
| Alinhamento com visão de longo prazo | 20% | 1-5 |

### Resultado
- Selecionar top 3-5 estratégias priorizadas
- Estas alimentam o próximo workflow: 03 (Escolhas Estratégicas)

---

## 6. Validação e Revisão

### Checklist de Qualidade
- [ ] Cada item do SWOT é específico e baseado em evidências
- [ ] Forças e fraquezas são realmente internas
- [ ] Oportunidades e ameaças são realmente externas
- [ ] Análise cruzada TOWS gerou estratégias acionáveis
- [ ] Priorização é baseada em critérios objetivos
- [ ] Time de liderança validou e concorda com a análise
- [ ] SWOT é revisado pelo menos semestralmente
