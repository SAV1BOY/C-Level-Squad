# Traction — Gino Wickman (2011)

## Resumo Executivo

Gino Wickman apresenta o Entrepreneurial Operating System (EOS), um sistema completo para
gerir empresas de 10 a 250 funcionários. O EOS fortalece seis componentes-chave de qualquer
organização: Vision, People, Data, Issues, Process e Traction. O livro é extremamente prático,
com ferramentas implementáveis imediatamente.

A premissa: a maioria das empresas sofre não por falta de visão, mas por falta de tração —
a disciplina de executar consistentemente. EOS fornece o sistema operacional para isso.

## Conceitos-Chave

### Six Key Components (EOS)
1. **Vision**: Todos 100% na mesma página sobre onde a empresa vai
2. **People**: Pessoas certas nos assentos certos (GWC: Get it, Want it, Capacity)
3. **Data**: Scorecard semanal com 5-15 números que dirigem o negócio
4. **Issues**: Identificar, discutir e resolver issues sistematicamente (IDS)
5. **Process**: Documentar e seguir os core processes da empresa
6. **Traction**: Rocks (prioridades de 90 dias) + Level 10 Meetings

### Vision/Traction Organizer (V/TO)
- Core Values (3-7 valores que definem a cultura)
- Core Focus (purpose + niche)
- 10-Year Target (BHAG)
- Marketing Strategy (target market, 3 uniques, proven process, guarantee)
- 3-Year Picture (como a empresa será em 3 anos)
- 1-Year Plan (goals para este ano)
- Rocks (prioridades dos próximos 90 dias)
- Issues List (problemas a resolver)

### Rocks (Prioridades de 90 Dias)
- 3-7 Rocks por pessoa/trimestre — prioridades absolutas
- SMART: Specific, Measurable, Attainable, Realistic, Time-bound
- Revisados semanalmente na Level 10 Meeting
- 80%+ completion rate é o target mínimo
- Rocks criam ritmo e disciplina de execução

### Level 10 Meeting (L10)
- Reunião semanal de 90 minutos, mesma hora, mesmo dia
- Agenda fixa: Segue IDS, check-in, scorecard review, rock review, to-do review, IDS, conclude
- IDS: Identify → Discuss → Solve (resolver, não debater indefinidamente)
- Avaliada de 1-10 pelos participantes ao final (meta: 8+)

### People Analyzer (GWC + Core Values)
- **Get it**: Entende o papel e suas responsabilidades intuitivamente
- **Want it**: Deseja genuinamente fazer aquele trabalho
- **Capacity**: Tem capacidade intelectual, emocional e física
- Cruza com aderência aos Core Values da empresa
- Ferramenta clara para decisões de pessoal — hire, fire, promote

### Accountability Chart
- Substitui o organograma tradicional por um mapa de responsabilidades
- Cada "seat" tem 5 papéis/responsabilidades claras
- Uma pessoa por seat (sem co-ownership)
- Permite identificar "right person, wrong seat" e vice-versa

## Frameworks e Modelos

### IDS — Processo de Resolução
1. **Identify**: Qual é o real issue? (frequentemente o problema apresentado não é o real)
2. **Discuss**: Debater por tempo limitado — todos contribuem
3. **Solve**: Decidir ação concreta com owner e deadline — mover para to-do list

### Scorecard Semanal
- 5-15 números que mostram o pulso do negócio
- Cada número tem um owner e um goal
- Revisado semanalmente na L10 — tendência > número absoluto
- Exemplos: revenue semanal, leads, conversion rate, NPS, cash balance

## Aplicação ao C-Level Squad

### Para o CEO Agent
- Implementar o V/TO como documento vivo de alinhamento estratégico
- Facilitar sessões de Rocks trimestrais com o C-Level Squad
- Liderar a Level 10 Meeting semanal com disciplina

### Para o CTO Agent
- Definir 3-5 Rocks técnicos por quarter alinhados com V/TO
- Contribuir para o Scorecard com métricas técnicas (uptime, velocity, bugs)
- Usar Accountability Chart para estruturar engineering organization

### Para o CFO Agent
- Definir métricas financeiras do Scorecard semanal (cash, AR, burn rate)
- Usar Rocks para projetos financeiros (implementar novo ERP, melhorar forecast)
- Aplicar People Analyzer nas decisões de contratação do time financeiro

### Para o CMO Agent
- Definir Rocks de marketing alinhados com Marketing Strategy do V/TO
- Contribuir com métricas de marketing ao Scorecard (MQLs, CAC, pipeline)
- Usar IDS para resolver issues de marketing sistematicamente

### Para o COO Agent
- Liderar documentação de Core Processes (Process component)
- Definir Rocks operacionais focados em eficiência e qualidade
- Usar Scorecard para monitorar indicadores operacionais semanalmente

## Takeaways Acionáveis (top 5)

1. **Implemente Level 10 Meetings** — Reunião semanal de 90 min com agenda fixa.
   É a ferramenta mais impactante do EOS. Comece na próxima semana.

2. **Defina Rocks trimestrais** — 3-7 prioridades absolutas por pessoa para os próximos
   90 dias. Se não cabe, não é prioridade. Revise progresso semanalmente.

3. **Crie o Scorecard** — 5-15 números que mostram a saúde do negócio semanalmente.
   Se você só vê financeiro mensal, está dirigindo olhando pelo retrovisor.

4. **Use IDS para issues** — Pare de debater sem resolver. Identifique o issue real,
   discuta com time-box, resolva com ação concreta, owner e deadline.

5. **Aplique People Analyzer** — Para cada pessoa no time, avalie GWC + Core Values.
   Decisões difíceis de pessoal ficam mais claras com ferramenta objetiva.

## Quando Consultar

- Ao implementar ritmo operacional (cadência de reuniões e planejamento)
- Na definição de prioridades trimestrais (Rocks)
- Quando reuniões são improdutivas (implementar L10)
- Para decisões de pessoal (People Analyzer + GWC)
- Ao documentar processos core da empresa
- Quando a empresa está crescendo e perdendo alinhamento

## Referências Cruzadas

- **Grove — High Output Management**: Princípios de produção que o EOS sistematiza
- **Doerr — Measure What Matters**: OKRs como alternativa mais flexível ao Rocks
- **McChesney — 4 Disciplines**: WIG + lead measures como complemento ao Scorecard
- **Collins — Good to Great**: BHAG como 10-Year Target, First Who Then What → People
- **Lencioni — The Advantage**: Organizational health como fundação para o EOS funcionar
- **Bezos 6-Pager**: Estrutura de meetings como paralelo da L10
