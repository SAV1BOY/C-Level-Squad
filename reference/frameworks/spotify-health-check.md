# Framework: Spotify Squad Health Check

## Descrição

O Squad Health Check Model foi criado por Henrik Kniberg e outros na Spotify para avaliar a saúde de equipes (squads) de forma visual e acionável. Em vez de medir apenas resultados, o modelo avalia como a equipe se sente em relação a múltiplas dimensões do trabalho. Cada dimensão usa uma escala de semáforo (verde/amarelo/vermelho) com indicadores qualitativos. O objetivo não é comparar equipes, mas facilitar conversas sobre melhorias e identificar padrões organizacionais.

## Quando Usar

### Situações Ideais
- Retrospectivas de equipe trimestrais ou semestrais
- Diagnóstico de saúde organizacional por liderança
- Identificação de padrões sistêmicos que afetam múltiplas equipes
- Acompanhamento de progresso em transformação organizacional
- Onboarding de novo líder em equipe existente
- Conversas de 1:1 entre gestor e equipe sobre ambiente de trabalho

### Quando NÃO Usar
- Como ferramenta de avaliação de desempenho individual
- Para ranking ou comparação competitiva entre equipes
- Quando a organização não está disposta a agir sobre os resultados
- Como substituto para métricas de entrega e resultado

## Como Aplicar

### Passo 1: Definir as Dimensões
```
Dimensões originais do Spotify (adaptar conforme contexto):

1. Entregando Valor
   🟢 Entregamos coisas incríveis, estamos orgulhosos
   🔴 Entregamos lixo, temos vergonha

2. Facilidade de Deploy
   🟢 Deploy é simples, seguro e frequente
   🔴 Deploy é arriscado, doloroso e raro

3. Diversão
   🟢 Adoro vir trabalhar, é divertido
   🔴 Que tédio/frustração, não quero vir

4. Saúde do Código
   🟢 Código limpo, orgulho, bem testado
   🔴 Código é uma bagunça, medo de mexer

5. Aprendizado
   🟢 Estamos aprendendo coisas interessantes o tempo todo
   🔴 Nunca temos tempo para aprender

6. Missão
   🟢 Sabemos por que estamos aqui e estamos motivados
   🔴 Sem direção clara, desconectados

7. Patas (Pawns) vs. Jogadores
   🟢 Controlamos nosso destino, decidimos o que construir
   🔴 Somos peões, só recebemos ordens

8. Velocidade
   🟢 Entregamos rápido, sem esperas
   🔴 Tudo demora uma eternidade

9. Processo Adequado
   🟢 Nosso processo funciona bem para nós
   🔴 Nosso processo é burocrático ou caótico

10. Suporte
    🟢 Temos ajuda quando precisamos
    🔴 Somos bloqueados por outros frequentemente

11. Trabalho em Equipe
    🟢 Somos um time coeso, confiamos uns nos outros
    🔴 Cada um por si, silos e desconfiança
```

### Passo 2: Conduzir a Sessão
```
Formato:
- 60-90 minutos com a equipe inteira
- Facilitador (preferencialmente não o gestor direto)

Para cada dimensão:
1. Apresentar a dimensão com exemplos de verde e vermelho
2. Cada pessoa vota: verde, amarelo ou vermelho
3. Votos simultâneos (sem influência — uso de cartões ou app)
4. Discussão sobre divergências (por que votos diferentes?)
5. Capturar: tendência (melhorando ↑ / estável → / piorando ↓)

Regras:
- Sem julgamento sobre votos
- Foco em discussão, não apenas no voto
- Actionable: o que podemos fazer sobre os vermelhos?
```

### Passo 3: Visualizar e Agir
```
Criar quadro visual:
         Squad A   Squad B   Squad C   Squad D
Valor      🟢        🟡        🟢        🔴
Deploy     🟡        🟢        🔴        🟡
Diversão   🟢        🟡        🟡        🔴
Código     🟡        🟢        🔴        🟡
...

Análise:
- Padrões verticais: problemas específicos de um squad
- Padrões horizontais: problemas sistêmicos da organização
- Tendências: melhorando ou piorando ao longo do tempo?

Ações:
- Squad escolhe 1-2 dimensões vermelhas para trabalhar
- Organização endereça padrões horizontais sistêmicos
- Revisar progresso no próximo health check (3-6 meses)
```

## Exemplos

### Exemplo: Health Check do C-Level Squad
```
Dimensões adaptadas para time executivo:
1. Alinhamento Estratégico: estamos alinhados sobre direção?
2. Qualidade de Decisão: nossas decisões são boas e rápidas?
3. Confiança: confiamos uns nos outros vulneravelmente?
4. Conflito Saudável: debatemos ideias com vigor?
5. Comunicação: informação flui bem entre nós?
6. Execução: traduzimos decisões em ação efetivamente?
7. Visibilidade: sabemos o que está acontecendo na organização?
8. Energia: estamos energizados ou esgotados?
9. Foco: temos clareza sobre prioridades?
10. Diversão: gostamos de trabalhar juntos?
```

## Limitações

- **Subjetividade** - Percepções variam e podem não refletir realidade objetiva
- **Não comparável** - Escalas de diferentes equipes não são equivalentes
- **Social desirability** - Pessoas podem votar para parecer bem, não honestamente
- **Snapshot** - Captura um momento, humor do dia pode influenciar
- **Sem impacto se não agir** - Health check sem follow-up gera cinismo
- **Fadiga** - Se feito com muita frequência, perde significado
- **Não substitui métricas** - Saúde percebida e resultados reais podem divergir
- **Cultural bias** - Culturas diferentes têm diferentes normas de expressão
