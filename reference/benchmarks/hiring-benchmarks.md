# Benchmarks: Métricas de Hiring e Recrutamento

## Visão Geral

Este documento compila benchmarks para processos de recrutamento e contratação em empresas de tecnologia. Os ranges são baseados em dados de mercado de fontes como Greenhouse, Lever, LinkedIn, SHRM, e relatórios de consultorias especializadas. Use como referência para avaliar a eficiência e eficácia do processo de hiring e identificar gargalos.

## Métricas de Funil de Recrutamento

### Taxa de Conversão por Etapa
```
Funil típico de contratação em tech:
1. Candidatos aplicados/sourced: 100%
2. Triagem (CV/perfil): 15-25% passam
3. Phone screen: 40-60% passam
4. Entrevista técnica/case: 25-40% passam
5. Entrevista final/cultura: 50-70% passam
6. Oferta: 70-90% aceitam

Conversão total (aplicação → hire):
- Engineering: 1-3%
- Product: 2-5%
- Sales: 3-8%
- General: 2-5%
```

### Volume de Candidatos por Vaga
| Canal | Volume Médio | Qualidade |
|-------|-------------|-----------|
| Job boards (LinkedIn, Indeed) | 100-300/vaga | Baixa-Média |
| Indicação (referral) | 5-20/vaga | Alta |
| Outbound sourcing | 20-50 abordados/vaga | Média-Alta |
| Inbound orgânico (marca) | 10-50/vaga | Média |

### Source of Hire (Origem das Contratações)
```
Benchmarks para tech:
- Referral/Indicação: 30-50% (melhor qualidade, menor custo)
- Outbound sourcing: 20-35%
- Job boards: 10-20%
- Inbound orgânico: 10-15%
- Agências/headhunters: 5-15%

Meta: >40% das contratações via referral
```

## Métricas de Velocidade

### Time to Fill (Tempo para Preencher Vaga)
| Nível/Função | Mediana | Top Quartile |
|--------------|---------|-------------|
| Engenheiro Júnior | 30-45 dias | <25 dias |
| Engenheiro Sênior | 45-75 dias | <40 dias |
| Staff/Principal | 60-120 dias | <60 dias |
| Product Manager | 45-75 dias | <40 dias |
| Designer | 40-60 dias | <35 dias |
| VP/Director | 60-120 dias | <60 dias |
| C-Level | 90-180 dias | <90 dias |

**Como medir:** Data de abertura da vaga até data de aceite da oferta

### Time to Start
```
Time to Start = Time to Fill + Notice Period

Notice periods típicos:
- Júnior/Pleno: 15-30 dias
- Sênior/Staff: 30-60 dias
- Diretores/VP: 30-90 dias
- C-Level: 60-90 dias

Impacto: cada dia sem preencher a vaga = custo de oportunidade
```

### Speed por Etapa
```
Benchmarks de tempo por etapa:
- Triagem de CV: <48 horas
- Agendamento de screen: <3 dias úteis
- Feedback pós-entrevista: <48 horas
- Decisão de oferta: <5 dias úteis após final round
- Envio de oferta: <2 dias úteis após decisão

Total do processo (primeira interação → oferta): 2-4 semanas ideal
Cada dia a mais = risco de perder candidato para concorrente
```

## Métricas de Custo

### Cost per Hire
| Método | Custo Médio por Contratação |
|--------|---------------------------|
| Referral | R$1.000-5.000 (bônus de indicação) |
| Inbound/orgânico | R$2.000-8.000 |
| Outbound sourcing | R$5.000-15.000 |
| Agência/headhunter | R$15.000-50.000 (15-25% do salário anual) |

```
Cost per Hire total = (custos internos + custos externos) / total de contratações

Benchmarks:
- Tech startup (<100 pessoas): R$5.000-15.000/hire
- Scale-up (100-500): R$8.000-20.000/hire
- Enterprise (>500): R$10.000-30.000/hire

Custos internos: salário recrutadores, ferramentas, tempo de entrevistadores
Custos externos: agências, job boards, employer branding, eventos
```

### Recruiting Efficiency Ratio
```
Custo total de recruiting / Total de compensation dos contratados

Benchmarks:
- Eficiente: <10%
- Médio: 10-15%
- Caro: >15%
```

### Recrutadores por Headcount
```
Ratio recruiter : total employees:
- Startup (<50): 1:30-50 (ou terceirizado)
- Growth (50-200): 1:40-60
- Scale (200-1000): 1:50-75
- Enterprise (>1000): 1:60-100

Ratio recruiter : vagas abertas simultaneamente:
- Eficiente: 1 recruiter para 15-20 vagas
- Mediano: 1 recruiter para 10-15 vagas
- Sobrecarregado: 1 recruiter para >25 vagas
```

## Métricas de Qualidade

### Quality of Hire
```
Métricas proxy (medidas após 6-12 meses):
- Performance rating: % de novas contratações com avaliação "meets" ou acima
  Benchmark: >85%
- Retention rate (1 ano): % de novas contratações ainda na empresa após 12 meses
  Benchmark: >85%
- Time to productivity: tempo até contribuição plena
  Benchmark: 2-4 meses para IC, 3-6 meses para gestores
- Hiring manager satisfaction: NPS ou rating do gestor sobre a contratação
  Benchmark: >4.0/5.0

Bad hire rate (terminados/saíram em <12 meses):
- Bom: <10%
- Aceitável: 10-15%
- Preocupante: >15%
```

### Offer Acceptance Rate
```
Benchmarks:
- Excelente: >90%
- Bom: 80-90%
- Aceitável: 70-80%
- Preocupante: <70%

Se <70%, investigar: compensação, processo, employer brand, candidate experience
```

### Candidate Experience (NPS)
```
Medir NPS de todos os candidatos (incluindo rejeitados):
- Excelente: >50
- Bom: 30-50
- Aceitável: 10-30
- Ruim: <10

Impacto: candidatos com boa experiência indicam outros, mesmo se rejeitados
```

## Métricas de Diversidade

### Pipeline de Diversidade
```
Benchmarks para tech (varia muito por mercado):
- % de mulheres no funil: meta >30% para funções não-técnicas, >20% para técnicas
- % de pessoas negras/pardas no funil: proporcional à população local
- Conversão por grupo: deve ser equivalente entre grupos demográficos
- Diferenças significativas de conversão indicam viés no processo
```

### Composição da Equipe
```
Benchmarks para empresas de tech no Brasil:
- Mulheres na empresa: meta >35-40%
- Mulheres em engenharia: meta >20-25%
- Mulheres em liderança: meta >30%
- Diversidade racial: proporcional ao mercado/região
```

## Métricas de Employer Brand

### Indicadores de Marca Empregadora
```
- Glassdoor rating: >4.0 é bom, >4.5 é excelente
- LinkedIn followers/engagement: crescimento >10% trimestral
- Referral rate: >40% das contratações por indicação
- Application rate: candidaturas espontâneas crescendo
- Offer acceptance rate: >85%
- Inbound vs. outbound ratio: mais inbound indica marca forte
```
