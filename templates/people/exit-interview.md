# Template: Exit Interview (Entrevista de Desligamento)

## Propósito
Este template estrutura a entrevista de desligamento para capturar insights honestos sobre a experiência do colaborador, identificar padrões de turnover, e gerar ações de melhoria para retenção. Aplica-se a saídas voluntárias e, quando apropriado, involuntárias.

## Instruções de Uso
1. Conduzida por RH (não pelo gestor direto) para maior abertura
2. Realize na última semana de trabalho — não no último dia
3. Garanta confidencialidade — dados agregados, não nominais
4. Compartilhe insights (anonimizados) com liderança trimestralmente
5. Duração recomendada: 45-60 minutos

## Dicas de Uso
- Não tente convencer a pessoa a ficar durante a exit interview — esse momento já passou
- Crie ambiente seguro — garantia de confidencialidade é essencial
- Faça perguntas abertas e escute mais do que fala
- Agregue dados trimestralmente — 1 exit interview é anedota, 10 são tendência
- Aja sobre os padrões identificados — senão a exit interview é só burocracia
- Mantenha canal aberto com ex-colaboradores — alumni network gera valor
