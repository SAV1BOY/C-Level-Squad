# Template de Atualização para Stakeholders

## Propósito
Fornecer atualizações periódicas e estruturadas a stakeholders externos (investidores,
Board members, parceiros estratégicos), comunicando progresso, resultados e próximos
passos de forma concisa e profissional.

## Quando Usar
- Mensalmente ou trimestralmente para investidores
- Antes de reuniões com Board members individuais
- Para atualizações a parceiros estratégicos
- Em momentos significativos (fechamento de rodada, grande conquista, pivô)

## Agente Responsável
- **Autor primário:** CEO Agent
- **Contribuidores:** CFO Agent (números), CoS Agent (consolidação)
- **Revisor:** Chief of Staff Agent
- **Aprovador:** CEO Agent

## Instruções de Preenchimento

1. **TL;DR:** Se o stakeholder ler apenas esses 3 bullets, deve ter 80% da informação necessária.
2. **Honestidade:** Stakeholders respeitam transparência. Não esconda problemas; mostre como está lidando.
3. **Pedidos:** Stakeholders querem ajudar. Seja específico sobre como podem contribuir (intros, conselho, etc.).
4. **Brevidade:** Máximo 2 páginas. Detalhes vão em anexos se necessário.
5. **Consistência:** Use as mesmas métricas em toda atualização para facilitar comparação.
6. **Frequência:** Melhor enviar atualizações curtas e frequentes do que longas e esporádicas.

## Checklist de Qualidade

- [ ] TL;DR captura 80% da mensagem em 3 bullets
- [ ] Métricas são consistentes com atualizações anteriores
- [ ] Conquistas são concretas e mensuráveis
- [ ] Desafios são apresentados com plano de ação (não apenas problemas)
- [ ] Cash position está atualizado
- [ ] Pedidos ao stakeholder são específicos e acionáveis
- [ ] O tom é honesto, profissional e confiante (sem arrogância)
- [ ] O documento tem no máximo 2 páginas
- [ ] CEO Agent revisou e aprovou antes do envio
- [ ] Classificação "Confidencial" está indicada
