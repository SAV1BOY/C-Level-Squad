## Boas Práticas para Notas de Reunião

### Antes da Reunião
- Distribuir pauta com pelo menos 24h de antecedência
- Definir facilitador e escriba antes de começar
- Compartilhar materiais de pré-leitura se necessário
- Confirmar participação de stakeholders essenciais

### Durante a Reunião
- Registrar pontos-chave, não transcrição literal
- Focar em decisões e ações com owners claros
- Confirmar entendimento de decisões antes de avançar
- Usar parking lot para temas fora de escopo
- Respeitar tempo alocado para cada tópico

### Após a Reunião
- Enviar notas em até 24h após a reunião
- Usar canal compartilhado (email, Slack, wiki) para distribuição
- Confirmar action items com responsáveis
- Criar lembretes para ações com prazo definido
- Arquivar notas em local acessível para referência futura

### Formato Recomendado
- Notas devem ser compreensíveis por quem não participou
- Evitar jargão sem explicação
- Incluir links para documentos referenciados
- Marcar claramente o que é decisão vs discussão vs ação
- Usar bullet points para facilitar leitura rápida
