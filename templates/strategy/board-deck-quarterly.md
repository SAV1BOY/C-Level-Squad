# Template: Board Deck Trimestral

## Propósito
Este template estrutura a apresentação trimestral para o conselho de administração (board). Cobre performance financeira, métricas operacionais, progresso estratégico, riscos e pedidos de aprovação. Projetado para comunicar status de forma objetiva e suportar tomada de decisão.

## Instruções de Uso
1. Preencha com dados do trimestre fechado e projeções atualizadas
2. Envie ao board com 5 dias de antecedência da reunião
3. Priorize dados sobre narrativa — board members querem fatos
4. Prepare appendix com detalhes para perguntas aprofundadas

## Dicas de Uso
- Máximo 12 slides no corpo principal — use appendix para detalhes
- Primeiro slide depois da capa deve ser o TL;DR — board members são ocupados
- Nunca surpreenda o board com más notícias na reunião — comunique antes
- Use dados comparativos (QoQ, YoY) sempre — números absolutos sem contexto são inúteis
- Envie materials com 5 dias de antecedência — respeite o tempo de preparação
- Tenha 3x mais slides de backup do que slides no deck principal
