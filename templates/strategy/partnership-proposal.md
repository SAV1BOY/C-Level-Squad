# Template: Proposta de Parceria Estratégica

## Propósito
Este template estrutura propostas de parceria entre organizações, cobrindo racional estratégico, modelo de operação, termos comerciais e governança. Ideal para parcerias de tecnologia, distribuição, co-desenvolvimento ou go-to-market conjunto.

## Instruções de Uso
1. Adapte as seções ao tipo de parceria (tecnológica, comercial, etc.)
2. Preencha a perspectiva de ambos os lados — parceria é via de mão dupla
3. Valide com jurídico e finanças antes de enviar ao parceiro
4. Use como base para negociação — espere iterações

## Dicas de Uso
- Lidere com o valor para o PARCEIRO, não para você — mostre que entende o lado deles
- Inclua métricas claras de sucesso — parceria sem métrica morre
- Comece com piloto pequeno — prove valor antes de pedir compromisso grande
- Documente tudo em contrato — confiança é bom, contrato é melhor
- Tenha um exit plan desde o início — evita desgaste se não funcionar
