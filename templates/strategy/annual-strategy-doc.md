# Template: Documento de Estratégia Anual

## Propósito

Este template orienta a construção do documento de estratégia anual da organização. Ele serve como referência central para alinhar todas as áreas em torno de objetivos comuns, definir prioridades de investimento e estabelecer métricas de sucesso para o período.

## Instruções de Uso

1. Preencha cada seção substituindo os placeholders `[...]` pelas informações específicas da sua organização.
2. Revise com o comitê executivo antes de finalizar.
3. Distribua para líderes de área após aprovação do board.
4. Atualize trimestralmente com status de progresso.

## Dicas de Uso

- Mantenha o documento vivo — atualize a cada trimestre com dados reais vs. planejado.
- Use cores de semáforo (verde/amarelo/vermelho) para status de iniciativas.
- Limite a 3-5 pilares estratégicos para manter foco.
- Vincule cada iniciativa a um OKR mensurável.
- Compartilhe versões resumidas para toda a empresa, mantendo detalhes financeiros restritos ao C-Level.
