# Template: Documento de Estratégia Anual

## Propósito
Este template estrutura o planejamento estratégico anual da organização, consolidando visão, metas, iniciativas prioritárias e métricas de sucesso para o ciclo fiscal. Serve como documento-base para alinhamento entre liderança executiva, board e times operacionais.

## Instruções de Uso
1. Preencha todas as seções substituindo os placeholders `[...]` pelos dados reais
2. Revise com o C-Level antes de apresentar ao board
3. Atualize trimestralmente com status das iniciativas
4. Use como referência para decisões de alocação de recursos

## Dicas de Uso
- Mantenha o documento vivo — atualize status de iniciativas pelo menos mensalmente
- Use cores (verde/amarelo/vermelho) para sinalizar status nos roadmaps
- Vincule cada iniciativa a um OKR específico para garantir rastreabilidade
- Compartilhe versão resumida (2 páginas) com toda a empresa para alinhamento
- Revise os riscos estratégicos a cada trimestre — novos riscos surgem constantemente
- Tenha um "plano B" documentado para cada pilar estratégico
