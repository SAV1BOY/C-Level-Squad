# Plano Operacional Anual (AOP)

## Propósito
Consolidar as metas anuais da empresa com orçamento, headcount, iniciativas
estratégicas e métricas de sucesso, servindo como contrato operacional entre
o C-Level e a organização para o ano fiscal.

## Quando Usar
- No planejamento anual (Q4 do ano anterior ou início do ano fiscal)
- Como referência-mestre para todos os planos trimestrais
- Para aprovação do Board de Diretores
- Quando necessário revisar o plano mid-year por mudança significativa de contexto

## Agente Responsável
- **Autor primário:** CFO Agent (números) + CEO Agent (estratégia)
- **Colaboradores:** Todos os agentes C-Level
- **Facilitador:** Chief of Staff Agent (CoS)
- **Aprovador:** CEO Agent + Board

## Instruções de Preenchimento

1. **Metas Anuais:** 3-5 metas company-level. Devem ser SMART e ter owner individual.
2. **Budget:** Valide com o CFO Agent. Use premissas conservadoras (base case) como padrão.
3. **Headcount:** Inclua contratações por trimestre para planejamento de cash flow.
4. **Iniciativas:** Vincule cada iniciativa a uma aposta estratégica do one-pager.
5. **Cenários:** Defina triggers claros para pivotar entre cenários.
6. **Premissas:** Liste as premissas mais críticas. Se uma premissa falhar, o plano precisa ser revisado.

### PLANO OPERACIONAL ANUAL — 2026

**Empresa:** TechCo SaaS
**Visão para o ano:** Atingir R$ 50M ARR com path to profitability

| # | Meta | Métrica | Baseline | Target | Owner |

| G1 | Crescimento de receita | ARR | R$ 25M | R$ 50M | CEO Agent |
| G2 | Eficiência de capital | Burn Multiple | 2.1x | 1.3x | CFO Agent |
| G3 | Retenção de receita | NRR | 105% | 120% | CCO Agent |
| G4 | Velocidade de produto | Deploy frequency | 2x/semana | Daily | CTO Agent |
| G5 | Engajamento de equipe | eNPS | 42 | 60 | CHRO Agent |

## Checklist de Qualidade

- [ ] Metas anuais são SMART e possuem owner
- [ ] Budget está equilibrado (receita >= OPEX + CAPEX ou runway > 18 meses)
- [ ] Headcount plan é realista dado o mercado e timeline de hiring
- [ ] Cada iniciativa está vinculada a uma aposta estratégica
- [ ] Cenários Bear/Base/Bull estão definidos com triggers
- [ ] Premissas críticas estão explícitas e monitoráveis
- [ ] Cadência de revisão está definida
- [ ] CFO Agent validou todos os números financeiros
- [ ] Board aprovou (ou está agendado para aprovar) o plano
- [ ] Contingência de pelo menos 10% do OPEX está reservada
