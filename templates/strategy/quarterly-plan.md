# Plano Trimestral (Quarterly Plan)

## Propósito
Definir o plano operacional do trimestre com apostas prioritárias, OKRs, milestones,
alocação de recursos e critérios de gating para cada iniciativa, garantindo que a
estratégia se traduza em execução concreta.

## Quando Usar
- No início de cada trimestre (idealmente 2 semanas antes do início)
- Durante o QBR para apresentar o plano do próximo trimestre
- Quando é necessário realinhar prioridades mid-quarter
- Como referência para decisões de alocação de recursos intra-trimestre

## Agente Responsável
- **Autor primário:** Chief of Staff Agent (CoS)
- **Contribuidores:** Todos os agentes C-Level
- **Aprovador:** CEO Agent

## Instruções de Preenchimento

1. **Tema:** Uma frase que capture a essência do trimestre. Ajuda no alinhamento e comunicação.
2. **Apostas:** Máximo de 3-5. Cada aposta consome recursos significativos e tem resultado incerto.
3. **OKRs:** 2-4 objectives com 2-4 key results cada. Key results devem ser mensuráveis.
4. **Milestones:** Distribua ao longo das 13 semanas. Cada milestone deve ser binário (feito/não feito).
5. **Gating Criteria:** Defina upfront o que precisa ser verdade para continuar cada aposta.
   Isso evita o viés de "sunk cost".
6. **Alocação:** Garanta que o total não excede 100% da capacidade. Reserve 20-30% para BAU.
7. **Dependências:** Identifique e tenha plano B para cada dependência externa.

## Checklist de Qualidade

- [ ] Tema do trimestre é claro e memorável
- [ ] Máximo de 5 apostas com owners definidos
- [ ] OKRs são mensuráveis e têm baseline documentado
- [ ] Milestones estão distribuídos ao longo das 13 semanas
- [ ] Gating criteria foram definidos antes do início do trimestre
- [ ] Alocação de recursos não excede 100% da capacidade
- [ ] Dependências externas têm plano B
- [ ] Cadência de acompanhamento está definida
- [ ] O plano foi aprovado pelo CEO Agent
- [ ] Todos os owners confirmaram compromisso com suas entregas
