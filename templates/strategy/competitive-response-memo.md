# Memo de Resposta Competitiva

## Propósito
Analisar um movimento competitivo significativo e definir o plano de resposta da empresa,
avaliando impacto, urgência e opções de reação com base em dados concretos.

## Quando Usar
- Quando um competidor faz um movimento significativo (lançamento, aquisição, pricing)
- Ao identificar um novo entrante relevante no mercado
- Quando perdemos deals importantes para o mesmo competidor repetidamente
- Para revisar posicionamento competitivo periodicamente

## Agente Responsável
- **Autor primário:** CEO Agent ou CMO Agent
- **Contribuidores:** CTO Agent (tecnologia), CFO Agent (impacto financeiro), CRO Agent (vendas)
- **Revisor:** Chief of Staff Agent (CoS)

## Instruções de Preenchimento

1. **Velocidade:** Este memo deve ser produzido em 24-48h após o evento competitivo.
2. **Fontes:** Use múltiplas fontes para validar a informação. Nunca reaja a rumor não confirmado.
3. **Impacto:** Quantifique sempre que possível. "Pode impactar receita" é fraco. "Pode reduzir
   pipeline em 15% no segmento mid-market" é forte.
4. **Opções:** Sempre inclua "não reagir" como opção. Às vezes a melhor resposta é não responder.
5. **Resposta assimétrica:** Considere responder em uma dimensão diferente. Se o competidor
   reduziu preço, talvez a resposta seja adicionar funcionalidade em vez de reduzir preço.
6. **Battle Cards:** Atualize o material de vendas imediatamente.

## Exemplo Preenchido

---

### MEMO DE RESPOSTA COMPETITIVA

**Competidor:** AutomaTech
**Evento:** Lançamento de plano gratuito com funcionalidades premium
**Urgência:** Alta

#### 6. Recomendação

**Opção recomendada:** Resposta assimétrica — Lançar programa de certificação gratuito

**Justificativa:**
Em vez de entrar em guerra de preços, lançar programa de certificação cria lock-in
por capacitação. Profissionais certificados na nossa plataforma têm incentivo para
recomendar e defender a escolha. Custo de R$ 150K vs. R$ 800K de redução de preço.

## Checklist de Qualidade

- [ ] Informação do movimento competitivo é verificada por múltiplas fontes
- [ ] Impacto está quantificado (não apenas qualitativo)
- [ ] Pelo menos 3 opções de resposta foram avaliadas (incluindo "não reagir")
- [ ] Recomendação é clara com plano de ação detalhado
- [ ] Battle cards de vendas foram atualizados
- [ ] Monitoramento contínuo está definido
- [ ] O memo foi produzido em menos de 48h
- [ ] CFO Agent validou o impacto financeiro
- [ ] Sales team foi informado das atualizações de posicionamento
- [ ] Próxima revisão está agendada
