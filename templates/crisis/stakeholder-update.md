# Template: Update para Stakeholders

## Propósito
Este template padroniza atualizações de status para stakeholders durante situações críticas, projetos de alto risco ou períodos de mudança organizacional. Garante comunicação consistente, com frequência previsível e nível de detalhe adequado a cada audiência.

## Instruções de Uso
1. Defina a lista de stakeholders e frequência no início da situação
2. Mantenha a cadência prometida — mesmo se não houver novidades
3. Adapte o nível de detalhe à audiência (board vs operacional)
4. Use formato consistente para que stakeholders saibam onde encontrar informação

## Dicas de Uso
- TL;DR no topo — muitos stakeholders só leem os primeiros 3 bullets
- Mantenha cadência mesmo sem novidade — "sem mudanças" é uma informação valiosa
- Destaque o que MUDOU desde o último update — não repita o que já foi dito
- Inclua decisões necessárias com prazo — force accountability
- Numere os updates sequencialmente — facilita referência
- Adapte profundidade: board quer impacto em negócio, time quer detalhes operacionais
