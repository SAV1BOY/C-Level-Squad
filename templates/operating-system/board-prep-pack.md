# Board Preparation Pack

## Propósito
Consolidar todas as informações necessárias para a reunião de Board/Conselho em um
pacote estruturado, cobrindo performance financeira, progresso estratégico, riscos,
pedidos de aprovação e tópicos de discussão.

## Quando Usar
- 2 semanas antes de cada reunião de Board/Conselho
- Para reuniões extraordinárias do Board quando convocadas
- Como base para o CFO e CEO prepararem suas apresentações
- Para alinhar o C-Level sobre a narrativa antes do Board

## Agente Responsável
- **Autor primário:** Chief of Staff Agent (CoS)
- **Contribuidor financeiro:** CFO Agent
- **Contribuidor estratégico:** CEO Agent
- **Revisores:** Todos os agentes C-Level
- **Aprovador final:** CEO Agent

## Instruções de Preenchimento

1. **Timeline:** Pack deve estar pronto 5 dias úteis antes do Board. Enviar aos membros 3 dias antes.
2. **CEO Update:** Seja transparente. Boards respeitam honestidade mais que otimismo infundado.
3. **Financeiro:** Números devem ser auditáveis. Não use estimativas "otimistas".
4. **Aprovações:** Liste tudo que precisa de voto formal. Cada item com contexto suficiente.
5. **Discussão:** Formule perguntas específicas. "O que acham?" é fraco. "Devemos investir R$ 2M em
   AI dado o cenário X?" é forte.
6. **Materiais:** Envie tudo junto. Não envie materiais na véspera.
7. **Tom:** Profissional, direto, orientado a dados. Sem jargão desnecessário.

## Checklist de Qualidade

- [ ] Pack completo enviado 3+ dias úteis antes da reunião
- [ ] Dados financeiros auditados e consistentes
- [ ] CEO Update é honesto sobre conquistas E desafios
- [ ] KPIs incluem comparação com período anterior e target anual
- [ ] Riscos estão atualizados e não omitidos
- [ ] Itens de aprovação têm contexto suficiente para decisão informada
- [ ] Perguntas para discussão são específicas e acionáveis
- [ ] Compliance e governança estão em dia
- [ ] Materiais anexos estão completos e referenciados
- [ ] Narrativa é consistente entre todas as seções do pack
