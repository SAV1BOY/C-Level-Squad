# Template: Report Financeiro Mensal

## Propósito

Este template estrutura o report financeiro mensal que consolida P&L, balanço patrimonial
(highlights), KPIs operacionais, análise de variações e forecast atualizado. É o documento
central de comunicação financeira para C-level, gestores e board, transformando dados contábeis
em inteligência acionável.

## Quando Usar

- Todo mês, até D+10 do mês subsequente, como output do fechamento mensal
- Adaptado para board reports (trimestral, com visão mais estratégica)
- Como base para investor updates (com ajustes de formato e conteúdo)
- Em reuniões de MBR (Monthly Business Review)

## Agente Responsável

**CFO Strategist** como DRI de produção e accuracy. Controller/FP&A como executor.
CEO como reviewer e distribuidor para board (quando aplicável).

## Instruções de Preenchimento

1. **Executive Summary primeiro** — Se a audiência ler apenas esta seção, deve entender a situação financeira completa.
2. **Dados devem ser reconciliados** — Nunca publicar report com dados preliminares sem disclaimer.
3. **Variações precisam de causa raiz** — "Variação de +15%" sem explicação não é informação, é ruído.
4. **KPIs com status visual** — Leitores devem identificar problemas em 5 segundos.
5. **Forecast honesto** — Se o forecast piorou, diga. Esconder bad news destrói credibilidade.
6. **Ações anteriores primeiro** — Antes de criar novas ações, fechar as antigas (accountability).
7. **Adaptar para audiência** — Board precisa de visão estratégica; gestores precisam de detalhe operacional.

## Exemplo Preenchido (Executive Summary)

```
RESUMO EXECUTIVO — FEVEREIRO/2026

RESULTADO:
  Receita: R$ 680K (budget: R$ 650K | +4.6%) ✅
  Margem Bruta: 72% (budget: 70% | +2pp) ✅
  EBITDA: R$ -180K (budget: R$ -200K | melhor que plan) ✅
  Net Burn: R$ 290K (budget: R$ 320K | -9.4%) ✅
  Caixa: R$ 3.500K | Runway: 12.1 meses ⚠️

HIGHLIGHTS:
  1. MRR cresceu 5.2% MoM — melhor mês desde lançamento
  2. CAC paid caiu 12% com otimização de criativos
  3. 3 novos clientes enterprise (ACV médio R$ 96K)

LOWLIGHTS:
  1. Churn subiu de 2.8% para 3.5% — 2 clientes mid-market saíram (concorrente)
     Ação: CS deep-dive + win-back campaign | DRI: Head CS | Deadline: 15/Mar
  2. Runway de 12.1 meses — abaixo do threshold de conforto (12 meses)
     Ação: Iniciar preparação para Series A | DRI: CEO + CFO | Deadline: 30/Mar
  3. Contratação de Engineering 2 meses atrasada — 3 posições abertas
     Ação: Ativar headhunter para posições senior | DRI: VP Eng | Deadline: 10/Mar

OUTLOOK: Março deve ser positivo com onboarding dos 3 enterprise clients.
Foco em estabilizar churn e iniciar processo de fundraising.
```
