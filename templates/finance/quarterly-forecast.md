# Template: Forecast Trimestral

## Propósito
Este template estrutura a projeção financeira trimestral, atualizando estimativas de receita, custos e métricas operacionais com base em dados reais do período corrente. O forecast é a ferramenta principal de gestão financeira entre ciclos de budget.

## Instruções de Uso
1. Finance lidera o processo com input de todas as áreas
2. Atualize mensalmente durante o trimestre (rolling forecast)
3. Compare com budget original para identificar variações
4. Use como base para decisões de ajuste de investimento

## Dicas de Uso
- Forecast é mais importante que budget — reflete realidade, não aspiração
- Atualize mensalmente — forecast trimestral desatualizado não serve para decisões
- Explique VARIAÇÕES, não números — liderança quer saber o "por quê"
- Separe o que é previsível (recorrência) do que é incerto (new business)
- Inclua riscos e oportunidades para dar range, não apenas um número
- Compare forecast atual com forecasts anteriores — melhore a acurácia ao longo do tempo
