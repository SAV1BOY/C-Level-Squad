# Template: Análise de Custo-Benefício

## Propósito
Este template estrutura a comparação sistemática de custos e benefícios de diferentes alternativas para suportar decisões de investimento. Diferente do ROI (que avalia um investimento específico), a análise custo-benefício compara múltiplas opções para encontrar a melhor relação.

## Instruções de Uso
1. Defina claramente as alternativas a serem comparadas (mínimo 2 + status quo)
2. Quantifique custos e benefícios no mesmo horizonte temporal
3. Inclua custos tangíveis e intangíveis
4. Apresente a recomendação com justificativa clara

## Dicas de Uso
- Sempre inclua "não fazer nada" como alternativa — é o baseline real
- Quantifique o máximo possível — "melhor experiência" vale R$ quanto em retenção?
- Custos intangíveis (custo de oportunidade, switching cost) frequentemente são os maiores
- Use a mesma base temporal para todos os cálculos — não compare custo anual com benefício de 3 anos
- A razão custo-benefício > 1 é condição mínima, não suficiente — considere risco
- Revise a análise se qualquer premissa-chave mudar mais de 20%
