# Brief de Planejamento de Sucessão

## Propósito
Mapear a prontidão de sucessão para posições críticas da organização, identificando
potenciais sucessores internos, gaps de desenvolvimento e planos de contingência
para garantir continuidade de liderança.

## Quando Usar
- Anualmente como exercício de planejamento de talentos
- Quando um executivo anuncia saída ou transição
- Como parte do planejamento estratégico de pessoas
- Para preparar discussões de talent review com o Board

## Agente Responsável
- **Autor primário:** CHRO Agent
- **Contribuidores:** CEO Agent + gestores diretos das posições mapeadas
- **Revisor:** Chief of Staff Agent (CoS)
- **Aprovador:** CEO Agent

## Instruções de Preenchimento

1. **Confidencialidade:** Este é um dos documentos mais sensíveis da organização. Acesso restrito.
2. **Prontidão:** "Pronto agora" = pode assumir imediatamente. "1-2 anos" = precisa de desenvolvimento.
3. **Múltiplos sucessores:** Identifique pelo menos 2 possíveis sucessores por posição crítica.
4. **Contingência:** O plano de emergência é diferente do plano de desenvolvimento. Contingência é
   para o cenário "e se a pessoa sair amanhã?".
5. **Diversidade:** Monitore a diversidade do pipeline para evitar homogeneidade na liderança.
6. **Revisão:** Atualize semestralmente no mínimo, ou quando houver mudança significativa.

## Checklist de Qualidade

- [ ] Todas as posições C-Level e VP estão mapeadas
- [ ] Cada posição tem pelo menos 2 sucessores potenciais identificados
- [ ] Prontidão está classificada com base em evidências (não intuição)
- [ ] Gaps de desenvolvimento são específicos e acionáveis
- [ ] Plano de contingência (emergency) está definido para posições críticas
- [ ] Diversidade do pipeline está monitorada
- [ ] Ações prioritárias têm owners e prazos
- [ ] O documento é estritamente confidencial e com acesso restrito
- [ ] Revisão está agendada para o próximo ciclo
- [ ] CEO e Board foram informados sobre o status geral
