# Plano 30-60-90 Dias de Onboarding

## Propósito
Estruturar o onboarding de novos executivos e líderes com metas claras para cada fase
(30, 60 e 90 dias), garantindo integração rápida, construção de relacionamentos e
entregas iniciais que gerem credibilidade e impacto.

## Quando Usar
- Para onboarding de qualquer contratação VP+ ou C-Level
- Para promoções internas a posições de liderança sênior
- Como referência para o Hiring Manager acompanhar o progresso
- Adaptável para onboarding de gestores em geral

## Agente Responsável
- **Autor primário:** CHRO Agent (estrutura) + Hiring Manager (conteúdo)
- **Revisores:** CEO Agent, Chief of Staff Agent
- **Executante:** Novo executivo contratado

## Instruções de Preenchimento

1. **Customize por posição:** Os objetivos devem ser específicos para o papel, não genéricos.
2. **Reuniões 1:1:** Inclua pessoas de fora da área direta para construir visão cross-functional.
3. **Quick wins:** Identifique 2-3 vitórias rápidas que gerem credibilidade nos primeiros 90 dias.
4. **Checkpoints:** Realize conversas formais nos dias 30, 60 e 90 com o Hiring Manager.
5. **Flexibilidade:** O plano é um guia, não uma camisa de força. Ajuste conforme contexto muda.
6. **Buddy:** Designe alguém de outra área que pode dar contexto cultural e histórico.

**Entregáveis:**

- [ ] Lista priorizada de "coisas que me surpreenderam"

- [ ] Objetivos são específicos para a posição (não genéricos)

- [ ] Documentos essenciais estão listados e acessíveis

- [ ] Buddy/Mentor foi designado e informado

- [ ] O plano foi revisado pelo Hiring Manager e CHRO
- [ ] Entregáveis são mensuráveis e verificáveis
- [ ] Avaliação formal dos 90 dias tem critérios definidos
