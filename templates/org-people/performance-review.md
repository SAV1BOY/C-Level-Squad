# Template de Performance Review Pragmático

## Propósito
Conduzir avaliações de desempenho de forma objetiva, orientada a resultados e
desenvolvimento, evitando burocracia excessiva enquanto garante feedback acionável
e decisões justas sobre compensação e carreira.

## Quando Usar
- Nos ciclos de performance review (semestral ou anual)
- Para avaliações de período probatório
- Como base para discussões de promoção
- Para documentar feedback formal de desempenho

## Agente Responsável
- **Processo:** CHRO Agent
- **Avaliador:** Gestor direto do avaliado
- **Calibração:** CEO Agent + CHRO Agent
- **Revisão final:** Nível N+2 (gestor do gestor)

## Instruções de Preenchimento

1. **Classificação:** Use dados, não impressões. A classificação deve ser sustentável com evidências.
2. **Resultados vs. Objetivos:** Os objetivos devem ter sido definidos no início do período.
3. **Competências:** Avalie o nível demonstrado consistentemente, não em momentos isolados.
4. **Feedback 360:** Resuma temas recorrentes, não cite verbatim sem autorização.
5. **Auto-avaliação:** Peça ao avaliado para preencher antes da conversa. Use como input.
6. **Tom:** Direto e construtivo. Não amenize feedback negativo a ponto de torná-lo inaudível.
7. **PDI:** Foque em 2-3 áreas de desenvolvimento, não mais. Menos é mais.
8. **Calibração:** Compare classificações entre pares para garantir consistência.

## Checklist de Qualidade

- [ ] Classificação é sustentada por evidências concretas
- [ ] Objetivos do período foram definidos no início (não retroativamente)
- [ ] Competências avaliadas com exemplos específicos
- [ ] Auto-avaliação do colaborador foi considerada
- [ ] Feedback 360 resumido sem exposição indevida
- [ ] PDI é focado (2-3 áreas) e com ações concretas
- [ ] Decisões de compensação são consistentes com a classificação
- [ ] Objetivos do próximo período estão definidos e acordados
- [ ] Calibração foi realizada com o grupo de pares
- [ ] A conversa foi conduzida de forma respeitosa e construtiva
