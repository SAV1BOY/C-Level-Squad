# Market Analysis Blocks — Blocos Reutilizáveis para Análise de Mercado

> Blocos padronizados para análises de mercado em documentos estratégicos.
> Use em planejamentos anuais, board decks, pitches e análises competitivas.

---

## 1. Bloco: Panorama de Mercado

```markdown

| TAM (Brasil/Região) | [US$/R$ X bilhões] | [Fonte, ano] |
| CAGR (5 anos) | [X%] | [Fonte] |
| Estágio de maturidade | [Emergente / Crescimento / Maduro / Declínio] | [Análise] |
| Número de players | [~N relevantes] | [Análise] |
| Concentração | [Fragmentado / Moderado / Concentrado] | [Top 3 = X% share] |
| Barreira de entrada | [Alta / Média / Baixa] | [Justificativa] |
```

## Exemplos de Uso

### Análise de Mercado para Pitch de Investimento
```markdown
## Mercado — SaaS de RH para PMEs no Brasil

- **TAM:** R$ 12B (gestão de RH global) | **SAM:** R$ 2.1B (Brasil, PMEs 50-500)
- **CAGR:** 18% (impulsionado por digitalização pós-COVID e regulação eSocial)
- **Share atual:** 2.3% do SAM (~R$ 48M ARR)
- **Meta 3 anos:** 8% do SAM (R$ 168M ARR)
- **Dinâmica:** Mercado fragmentado, top 3 players = 25% share, oportunidade de consolidação
```

---

## Dicas de Uso
- Use dados de mercado de fontes confiáveis — e CITE as fontes
- TAM inflado perde credibilidade — seja honesto sobre limitações
- Análise PESTEL e Porter são ferramentas, não fins — extraia insights acionáveis
- Atualize análises de mercado pelo menos anualmente — mercados mudam
- Segmentação define estratégia — não tente ser tudo para todos
- Combine dados quantitativos com qualitativos (entrevistas com clientes)
