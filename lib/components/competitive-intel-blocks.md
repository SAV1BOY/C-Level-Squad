# Competitive Intelligence Blocks — Blocos de Inteligência Competitiva

> Blocos reutilizáveis para documentar e analisar inteligência competitiva.
> Use em análises competitivas, board decks, planejamento de produto e sales enablement.

---

## 1. Bloco: Perfil de Concorrente

### Template
```markdown
## Concorrente: [Nome]

| Dimensão | Dados |
|----------|-------|
| **Descrição** | [O que faz, posicionamento em 1-2 frases] |
| **Fundação** | [Ano] |
| **HQ** | [Localização] |
| **Funding** | [Total: US$/R$ X — última rodada: Série X de US$/R$ Y em MM/AAAA] |
| **Receita estimada** | [US$/R$ X ARR — fonte da estimativa] |
| **Headcount** | [N funcionários — fonte: LinkedIn/Glassdoor] |
| **Clientes** | [N clientes estimados — logos relevantes] |
| **Mercados** | [Geográficos e segmentos] |
| **Produto principal** | [Descrição breve] |
| **Diferencial** | [Principal razão pela qual clientes os escolhem] |
| **Fraqueza** | [Principal vulnerabilidade] |
| **CEO/Founder** | [Nome — background relevante] |
```

- [Vantagem 2 — com talking point]
- [Vantagem 3 — com talking point]

| Objeção do Cliente | Nossa Resposta |

## Exemplos de Uso

### Para Board Deck
```markdown
## Cenário Competitivo

- **Win rate competitivo:** 52% (meta: 55%) — estável vs Q anterior
- **Principal ameaça:** CompetitorX fechou Série C de US$ 50M — esperar agressividade em pricing
- **Nossa vantagem:** UX e velocidade de implementação continuam como top motivos de win
- **Gap a fechar:** Integrações com ERPs (motivo #2 de loss) — parceria com SAP em negociação
```

---

## Dicas de Uso
- Battle cards devem ser curtas (1 página) e atualizadas mensalmente
- Win/loss analysis é o dado mais valioso — invista em coleta estruturada
- Monitorar hiring dos concorrentes revela estratégia antes de anúncios públicos
- Não subestime concorrentes — analisar com respeito gera melhores insights
- Compartilhe intel competitiva ativamente com sales — informação parada não gera valor
- Scorecard trimestral evita tanto complacência quanto paranoia
