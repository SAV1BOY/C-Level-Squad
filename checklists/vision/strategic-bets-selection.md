# Strategic Bets Selection

## Propósito
Garantir que a organização mantém no máximo 1 a 3 apostas estratégicas ativas, seguindo a lógica de power-law (poucas apostas de alto impacto vs. muitas apostas diluídas). Inclui a revisão da kill list — o que decidimos não fazer é tão importante quanto o que decidimos fazer.

## Quando Aplicar
- No início de cada ciclo de planejamento estratégico (anual e semestral)
- Quando surgir uma nova oportunidade que demande recursos significativos
- Quando uma aposta ativa mostrar sinais de underperformance por 2 ciclos consecutivos
- Antes de alocar mais de 20% do budget em qualquer iniciativa nova
- Durante QBRs para revalidação das apostas vigentes

## Agente Responsável
**Agente de Visão (Vision Agent)** — responsável por curar e defender o portfolio de apostas estratégicas, garantindo foco e coerência com a visão.

## Checklist

### Seção 1: Inventário de Apostas Ativas
- [ ] Todas as apostas estratégicas ativas estão listadas e numeradas (máximo 3)
- [ ] Cada aposta tem um owner do C-Level designado como sponsor
- [ ] Cada aposta tem uma tese de investimento documentada em no máximo 1 página
- [ ] O horizonte temporal de cada aposta está definido (12, 24 ou 36 meses)
- [ ] Os recursos alocados para cada aposta estão quantificados (budget, headcount, atenção)
- [ ] A interdependência entre apostas está mapeada (conflitos, sinergias)
- [ ] Cada aposta tem métricas de sucesso claras e mensuráveis
- [ ] A data da próxima revisão formal de cada aposta está agendada

### Seção 2: Aplicação do Power-Law
- [ ] A maior aposta recebe proporcionalmente mais recursos que as demais combinadas
- [ ] A distribuição de recursos segue lógica 70/20/10 ou equivalente justificada
- [ ] A aposta principal está diretamente conectada ao core business ou ao next S-curve
- [ ] Não há mais de 3 apostas consumindo recursos significativos simultaneamente
- [ ] Apostas exploratórias (10%) têm critérios de promoção para a faixa de 20%
- [ ] A lógica de power-law foi explicada e aceita por todo o C-Level
- [ ] Existe um mecanismo para rebalancear recursos entre apostas a cada quarter
- [ ] O custo de dispersão (ter apostas demais) foi quantificado e comunicado

### Seção 3: Qualidade da Tese de Cada Aposta
- [ ] A tese responde: "Se tivermos razão, o que acontece em 3 anos?"
- [ ] A tese responde: "Se estivermos errados, qual é o downside máximo?"
- [ ] O tamanho do mercado endereçável (TAM/SAM/SOM) está validado
- [ ] O diferencial competitivo da aposta está articulado (moat, unfair advantage)
- [ ] Os pressupostos críticos estão listados com indicadores de invalidação
- [ ] Existe um plano de testes rápidos para validar pressupostos antes de escalar
- [ ] A aposta foi avaliada contra alternativas descartadas (why this, not that?)
- [ ] O retorno esperado justifica o risco assumido (expected value positivo)

### Seção 4: Kill List — O Que Não Fazer
- [ ] A kill list está documentada e atualizada nos últimos 90 dias
- [ ] Cada item da kill list tem justificativa explícita de por que foi descartado
- [ ] A kill list foi comunicada a todos os líderes de squad
- [ ] Não há projetos ativos que conflitem com itens da kill list
- [ ] A kill list inclui oportunidades que parecem boas mas diluem o foco
- [ ] Existe um processo para revisitar itens da kill list (não é permanente)
- [ ] A kill list é referenciada em toda decisão de alocação de recursos
- [ ] O time entende que a kill list é uma ferramenta de foco, não de rejeição

### Seção 5: Governança e Revisão
- [ ] Existe um fórum específico para revisão de apostas (não misturado com operação)
- [ ] A frequência de revisão está definida (mínimo: trimestral)
- [ ] Critérios de go/no-go para cada aposta estão pré-definidos
- [ ] O processo de escalar ou matar uma aposta está documentado
- [ ] Decisões de portfolio são registradas com data, contexto e participantes
- [ ] Existe um mecanismo de dissent (alguém pode discordar formalmente)
- [ ] O board ou advisory tem visibilidade sobre as apostas e a kill list
- [ ] Lições aprendidas de apostas anteriores (vivas e mortas) estão documentadas

## Critérios de Aprovação
- Máximo de 3 apostas ativas com teses documentadas e validadas
- Kill list atualizada nos últimos 90 dias com pelo menos 5 itens justificados
- Distribuição de recursos segue lógica de power-law documentada
- Todos os itens da Seção 1 devem estar 100% concluídos
- Pelo menos 80% dos itens das demais seções concluídos
- C-Level alinhado e com registro formal de concordância

## O que Fazer se Falhar
1. Congelar novas alocações de recursos até que o portfolio seja racionalizado
2. Forçar ranking das apostas ativas — qual morre primeiro se precisarmos cortar?
3. Realizar sessão de kill list com todo o C-Level (duração máxima: 3 horas)
4. Reduzir para no máximo 2 apostas se não houver clareza sobre a terceira
5. Consultar advisors externos para validação independente das teses
6. Documentar o custo acumulado de dispersão e apresentar ao board
7. Re-agendar auditoria em 30 dias com plano de correção definido
8. Comunicar decisões de corte com transparência e contexto para a organização
