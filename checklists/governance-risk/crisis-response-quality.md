# Checklist de Qualidade de Resposta a Crises (Crisis Response Quality)

## Propósito
Garantir que a organização tenha um protocolo claro e testado para resposta a crises,
com ações definidas para as primeiras 24 e 72 horas, plano de comunicação preparado
e retrospectiva agendada. Este checklist minimiza danos e acelera a recuperação
quando crises inevitavelmente ocorrem.

## Quando Aplicar
- Quando uma crise é declarada (qualquer evento que ameace operação, reputação ou segurança)
- No drill trimestral de simulação de crise (table-top exercise)
- Na revisão anual do plano de resposta a crises
- Após o encerramento de uma crise real (para avaliar efetividade da resposta)
- Quando novos tipos de crise são identificados como potenciais ameaças

## Agente Responsável
- **Primário:** Crisis Manager designado (geralmente CEO ou COO)
- **Secundário:** Head of Communications para comunicação de crise
- **Revisor:** Chief of Staff para coordenação logística e follow-up

## Checklist

### Seção 1 — Protocolo de Primeiras 24 Horas (First 24h Protocol)
- [ ] Item 1: O critério de declaração de crise está claro (quando ativar o protocolo)
- [ ] Item 2: A cadeia de notificação (call tree) está atualizada com contatos corretos
- [ ] Item 3: O Crisis Manager foi ativado e está liderando a resposta
- [ ] Item 4: War room (físico ou virtual) foi estabelecido dentro de 1 hora
- [ ] Item 5: Situational assessment inicial foi conduzido (o que sabemos, o que não sabemos)
- [ ] Item 6: Stakeholders internos críticos foram notificados dentro de 2 horas
- [ ] Item 7: Stakeholders externos críticos (clientes, reguladores) foram notificados conforme protocolo
- [ ] Item 8: Ações imediatas de contenção foram identificadas e executadas
- [ ] Item 9: Single source of truth para informações está estabelecida (não múltiplas versões)
- [ ] Item 10: Comunicação interna inicial foi enviada a todos os colaboradores
- [ ] Item 11: Spokesperson oficial está designado (ninguém mais fala externamente)
- [ ] Item 12: Holding statement para mídia e clientes está preparada

### Seção 2 — Protocolo de 24h a 72h (24-72h Protocol)
- [ ] Item 13: Root cause analysis preliminar está em andamento
- [ ] Item 14: Plano de ação de curto prazo (short-term remediation) está definido
- [ ] Item 15: Cadência de update ao C-Level está estabelecida (mínimo a cada 6 horas)
- [ ] Item 16: Comunicação externa atualizada foi emitida com informações substantivas
- [ ] Item 17: Impacto financeiro preliminar foi estimado
- [ ] Item 18: Impacto em clientes foi quantificado (número de afetados, severidade)
- [ ] Item 19: Recursos adicionais foram mobilizados conforme necessidade
- [ ] Item 20: Assessoria jurídica foi consultada sobre implicações legais
- [ ] Item 21: Reguladores foram notificados conforme exigências legais aplicáveis
- [ ] Item 22: Plano de recuperação (recovery plan) está sendo elaborado com timeline

### Seção 3 — Plano de Comunicação de Crise (Crisis Communication Plan)
- [ ] Item 23: Mensagens-chave para cada audiência estão definidas (colaboradores, clientes, mídia, reguladores)
- [ ] Item 24: Tom da comunicação é empático, transparente e factual
- [ ] Item 25: Canais de comunicação por audiência estão definidos (email, press release, social media)
- [ ] Item 26: FAQ para equipes de atendimento ao cliente está preparado
- [ ] Item 27: Monitoramento de mídia e redes sociais está ativo
- [ ] Item 28: Respostas a perguntas frequentes da mídia estão pré-aprovadas
- [ ] Item 29: Cadência de atualização externa está definida (a cada 12h, 24h, etc.)
- [ ] Item 30: Comunicação de encerramento da crise está planejada

### Seção 4 — Gestão de Impacto (Impact Management)
- [ ] Item 31: Dashboard de impacto da crise está operacional (métricas em tempo real)
- [ ] Item 32: Clientes mais afetados estão sendo contatados individualmente
- [ ] Item 33: Plano de compensação ou remediação para clientes está definido (se aplicável)
- [ ] Item 34: Impacto em parceiros e fornecedores está mapeado e comunicado
- [ ] Item 35: Impacto em colaboradores (bem-estar, produtividade) está sendo monitorado
- [ ] Item 36: Continuidade operacional está sendo mantida para funções críticas
- [ ] Item 37: Evidências e logs estão sendo preservados (chain of custody)

### Seção 5 — Recuperação (Recovery)
- [ ] Item 38: Critérios de encerramento da crise estão definidos (quando voltamos ao normal)
- [ ] Item 39: Plano de recuperação tem milestones e timeline claros
- [ ] Item 40: Comunicação de que a crise foi resolvida está planejada para todas as audiências
- [ ] Item 41: Medidas preventivas para evitar recorrência estão sendo implementadas
- [ ] Item 42: Monitoramento pós-crise está ativo por pelo menos 30 dias

### Seção 6 — Retrospectiva (Post-Crisis Retro)
- [ ] Item 43: Retrospectiva está agendada para no máximo 2 semanas após encerramento da crise
- [ ] Item 44: Todos os envolvidos na resposta participam da retrospectiva
- [ ] Item 45: Timeline detalhado de eventos e ações está reconstruído
- [ ] Item 46: O que funcionou bem está documentado para replicação
- [ ] Item 47: O que falhou está documentado com root cause analysis
- [ ] Item 48: Action items de melhoria estão definidos com owners e deadlines
- [ ] Item 49: O plano de resposta a crises é atualizado com base nos aprendizados
- [ ] Item 50: Relatório final da crise é apresentado ao Board

## Critérios de Aprovação
A resposta a crise é considerada adequada quando:

1. **Protocolo de 24h (Seção 1) foi ativado dentro dos SLAs definidos**
2. **Comunicação inicial foi emitida dentro de 4 horas da declaração de crise**
3. **Single source of truth foi estabelecida e mantida durante toda a crise**
4. **Impacto foi contido conforme plano de contenção (Seção 4)**
5. **Retrospectiva foi realizada dentro de 2 semanas (Seção 6)**
6. **Action items de melhoria foram atribuídos e têm tracking (Seção 6)**
7. **O plano de crise foi atualizado com os aprendizados**

## O que Fazer se Falhar
Se a resposta a crise não foi adequada:

1. **Post-incident review aprofundado:** Análise detalhada de cada falha na resposta
2. **Gap analysis:** Identificar se a falha foi de plano, execução ou comunicação
3. **Treinamento:** Conduzir treinamento intensivo para o crisis team
4. **Simulação:** Agendar table-top exercise dentro de 30 dias para praticar cenários
5. **Investimento:** Avaliar se faltam ferramentas, headcount ou processos
6. **Accountability:** Sem blame, mas com clara identificação de onde o processo falhou
7. **Benchmark:** Comparar resposta com best practices de empresas similares
8. **Board communication:** Reportar ao Board as falhas identificadas e o plano de melhoria
