# Checklist de Qualidade do Sistema de Performance (Performance System Quality)

## Propósito
Garantir que o sistema de avaliação de performance seja percebido como justo,
que critérios de promoção sejam claros e transparentes, e que feedback loops
estejam ativos e funcionais. Este checklist previne perda de talentos por
frustração com sistemas de avaliação opacos ou inconsistentes.

## Quando Aplicar
- Antes de cada ciclo de avaliação de performance (semestral ou anual)
- Após o encerramento de cada ciclo (retrospectiva do processo)
- Quando taxas de turnover indicam insatisfação com gestão de performance
- Ao redesenhar ou atualizar o sistema de performance
- Quando novas lideranças são treinadas no processo de avaliação

## Agente Responsável
- **Primário:** Chief People Officer (CPO) ou Head of People Operations
- **Secundário:** Cada gestor como executor do sistema com seus reportes diretos
- **Revisor:** CEO para calibração de nível sênior e validação do sistema

## Checklist

### Seção 1 — Avaliação Justa (Fair Evaluation)
- [ ] Item 1: Critérios de avaliação estão documentados e acessíveis a todos os colaboradores
- [ ] Item 2: Critérios são específicos por nível (career ladder) e função
- [ ] Item 3: O peso de cada dimensão de avaliação está claro (resultados, competências, valores)
- [ ] Item 4: Exemplos concretos de cada nível de performance estão documentados
- [ ] Item 5: Auto-avaliação é parte do processo e é considerada na avaliação final
- [ ] Item 6: Peer feedback é coletado e incorporado de forma estruturada
- [ ] Item 7: O processo de calibração (calibration session) está definido e é executado
- [ ] Item 8: Viés de recência (recency bias) é mitigado com coleta de evidências ao longo do período
- [ ] Item 9: Viés de similaridade, gênero e outros vieses são monitorados estatisticamente
- [ ] Item 10: O gestor é treinado anualmente em práticas de avaliação justa
- [ ] Item 11: Existe processo de apelação para colaboradores que discordam da avaliação
- [ ] Item 12: Resultados de avaliação são distribuídos seguindo curva esperada (sem forçar curva artificial)

### Seção 2 — Critérios de Promoção (Promotion Clarity)
- [ ] Item 13: Career ladder está documentada com requisitos claros por nível
- [ ] Item 14: A transição entre níveis está descrita com competências e evidências necessárias
- [ ] Item 15: O processo de promoção (quem decide, como, quando) está documentado e público
- [ ] Item 16: Promoções são baseadas em evidência demonstrada, não em potencial não comprovado
- [ ] Item 17: Existe comitê de promoção ou processo de calibração cross-team
- [ ] Item 18: Tempo mínimo e máximo em cada nível serve como guia, não como regra rígida
- [ ] Item 19: Dual-track career existe (individual contributor e management) com equidade
- [ ] Item 20: Promoções são comunicadas de forma que reforce os critérios (o porquê é público)
- [ ] Item 21: Não-promoções são comunicadas com feedback construtivo e plano de desenvolvimento
- [ ] Item 22: Dados de promoção são analisados por diversidade (gênero, etnia, senioridade)

### Seção 3 — Feedback Loops Ativos
- [ ] Item 23: Feedback contínuo (não apenas no ciclo formal) é incentivado e praticado
- [ ] Item 24: Cadência mínima de 1:1 entre gestor e reporte direto é semanal ou quinzenal
- [ ] Item 25: Tópicos de desenvolvimento estão incluídos como item recorrente nos 1:1s
- [ ] Item 26: Feedback é bidirecional (gestor também recebe feedback do reporte direto)
- [ ] Item 27: Ferramenta de feedback está disponível e é de fácil utilização
- [ ] Item 28: A qualidade do feedback dado é avaliada (não apenas a frequência)
- [ ] Item 29: Recognition público e privado acontece de forma consistente
- [ ] Item 30: Feedback construtivo é dado em tempo hábil (não acumulado para o ciclo formal)
- [ ] Item 31: Skip-level meetings acontecem com frequência mínima trimestral
- [ ] Item 32: O NPS do processo de feedback é medido após cada ciclo formal

### Seção 4 — Desenvolvimento e Growth
- [ ] Item 33: Cada colaborador tem um plano de desenvolvimento individual (IDP) atualizado
- [ ] Item 34: O IDP está alinhado com as necessidades do negócio e aspirações do indivíduo
- [ ] Item 35: Budget de desenvolvimento (treinamento, conferências, cursos) está alocado
- [ ] Item 36: Programas de mentoring estão disponíveis para high potentials
- [ ] Item 37: Rotação entre áreas ou projetos é possível e incentivada para desenvolvimento
- [ ] Item 38: Stretch assignments são usados ativamente como ferramenta de desenvolvimento
- [ ] Item 39: O progresso no IDP é revisado pelo menos trimestralmente

### Seção 5 — Gestão de Baixa Performance (Low Performance Management)
- [ ] Item 40: Processo de PIP (Performance Improvement Plan) está documentado e é justo
- [ ] Item 41: PIPs são usados genuinamente para desenvolvimento, não apenas como prelúdio de desligamento
- [ ] Item 42: O suporte oferecido durante o PIP é real e substancial (coaching, recursos, tempo)
- [ ] Item 43: Critérios de sucesso do PIP são claros, mensuráveis e alcançáveis
- [ ] Item 44: Desligamentos por performance são conduzidos com dignidade e respeito
- [ ] Item 45: O time de People acompanha cada caso de baixa performance desde a identificação

## Critérios de Aprovação
O sistema de performance é considerado saudável quando:

1. **Mínimo de 85% dos itens do checklist estão completos**
2. **100% dos colaboradores têm acesso aos critérios de avaliação e promoção**
3. **Calibração (Seção 1, Item 7) foi realizada em todos os squads**
4. **NPS do processo de avaliação está acima de +30 entre colaboradores**
5. **90% dos gestores completaram treinamento de avaliação no último ano**
6. **Análise de viés (Seção 1, Item 9) não mostra disparidades significativas**
7. **Pelo menos 80% dos colaboradores têm IDP atualizado (Seção 4)**

## O que Fazer se Falhar
Se o sistema de performance não atinge os critérios:

1. **Survey de percepção:** Coletar feedback anônimo sobre o que está quebrado no processo
2. **Benchmarking:** Comparar com best practices de empresas similares em estágio semelhante
3. **Simplificar:** Se o sistema é muito complexo, as pessoas desengajam — buscar simplicidade
4. **Treinamento de gestores:** Investir em capacitação dos gestores como coaches de performance
5. **Transparência radical:** Tornar critérios e processos mais visíveis e compreensíveis
6. **Revisão da career ladder:** Atualizar se está desatualizada ou desalinhada com a realidade
7. **Piloto:** Testar mudanças em um squad antes de roll out completo
8. **External help:** Considerar consultoria de People & Org Design se o problema é sistêmico
