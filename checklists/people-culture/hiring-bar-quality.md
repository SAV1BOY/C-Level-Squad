# Checklist de Qualidade do Hiring Bar (Hiring Bar Quality)

## Propósito
Garantir que o processo de contratação mantenha um bar (padrão) consistente e elevado,
com entrevistas estruturadas, scorecards utilizados e critérios de avaliação claros.
Este checklist protege a organização contra contratações apressadas ou baseadas em
"gut feeling" que diluem a qualidade do time ao longo do tempo.

## Quando Aplicar
- Na abertura de cada nova posição (antes de iniciar sourcing)
- Durante o processo seletivo (como guia para entrevistadores)
- Na revisão trimestral de qualidade de contratações (hiring quality review)
- Quando métricas de qualidade de contratação indicam problemas
- Ao onboardar novos entrevistadores no processo de hiring

## Agente Responsável
- **Primário:** Hiring Manager da posição
- **Secundário:** Head of Talent Acquisition ou Recruiter Lead
- **Revisor:** Bar Raiser designado (inspirado no modelo Amazon)

## Checklist

### Seção 1 — Definição do Bar (Bar Definition)
- [ ] Item 1: O perfil da posição está documentado com competências técnicas e comportamentais
- [ ] Item 2: O nível de senioridade esperado está alinhado com a career ladder
- [ ] Item 3: Must-have vs. nice-to-have skills estão claramente separados
- [ ] Item 4: O hiring bar está calibrado com o nível atual do time (no mínimo, top 50% do time atual)
- [ ] Item 5: Anti-patterns (sinais de alerta) estão documentados para a posição
- [ ] Item 6: O impacto esperado nos primeiros 90 dias está descrito
- [ ] Item 7: Cultural fit é avaliado com critérios objetivos (não viés de afinidade)
- [ ] Item 8: A descrição da posição (job description) é precisa e não inflacionada

### Seção 2 — Processo de Entrevista Estruturada (Structured Interview)
- [ ] Item 9: O interview loop está desenhado com etapas claras e propósito de cada uma
- [ ] Item 10: Cada etapa avalia competências específicas (sem sobreposição excessiva)
- [ ] Item 11: Perguntas comportamentais e situacionais estão padronizadas por competência
- [ ] Item 12: Rubric de avaliação (scoring rubric) existe para cada competência avaliada
- [ ] Item 13: Exemplos de respostas fortes, médias e fracas estão documentados na rubric
- [ ] Item 14: Case studies ou exercícios práticos são relevantes para o trabalho real
- [ ] Item 15: O tempo de cada etapa está definido e é respeitado
- [ ] Item 16: Acomodações para candidatos com necessidades especiais estão previstas
- [ ] Item 17: O processo não é excessivamente longo (máximo de 5 etapas, 2-3 semanas)
- [ ] Item 18: Cada entrevistador foi treinado no processo e na rubric

### Seção 3 — Scorecards e Avaliação (Scorecards & Evaluation)
- [ ] Item 19: Scorecard padronizado é preenchido por cada entrevistador após cada entrevista
- [ ] Item 20: O scorecard é preenchido em até 24 horas após a entrevista (evitar memory decay)
- [ ] Item 21: O scorecard captura evidências concretas (não apenas notas numéricas)
- [ ] Item 22: Entrevistadores registram sua avaliação independentemente (antes do debrief)
- [ ] Item 23: O debrief coletivo acontece somente após todos os scorecards serem submetidos
- [ ] Item 24: Decisão de hire/no-hire é baseada em scorecards, não em impressões verbais
- [ ] Item 25: O Bar Raiser tem veto power para proteger a qualidade do bar
- [ ] Item 26: Empate ou dúvida significativa resulta em no-hire (when in doubt, don't hire)

### Seção 4 — Diversidade e Inclusão no Processo
- [ ] Item 27: O pipeline de candidatos inclui diversidade em gênero, etnia e background
- [ ] Item 28: A linguagem do job description foi revisada para evitar viés (gender decoder)
- [ ] Item 29: O painel de entrevistadores é diverso em pelo menos 2 dimensões
- [ ] Item 30: Viés inconsciente é treinado anualmente com todos os entrevistadores
- [ ] Item 31: Dados de diversidade do pipeline e contratações são monitorados
- [ ] Item 32: Fontes de sourcing incluem canais de comunidades diversas
- [ ] Item 33: O processo é acessível a candidatos de diferentes backgrounds socioeconômicos

### Seção 5 — Experiência do Candidato (Candidate Experience)
- [ ] Item 34: Tempo entre aplicação e primeira resposta é inferior a 5 dias úteis
- [ ] Item 35: O candidato recebe comunicação clara sobre próximos passos em cada etapa
- [ ] Item 36: Feedback construtivo é oferecido a candidatos finalistas que não foram aprovados
- [ ] Item 37: A experiência do candidato é medida (survey pós-processo)
- [ ] Item 38: O processo respeita o tempo do candidato (agendamento eficiente)
- [ ] Item 39: A proposta (offer) é competitiva e apresentada de forma transparente
- [ ] Item 40: Candidatos que recusam a proposta são entrevistados para entender motivos

### Seção 6 — Métricas de Qualidade de Hiring
- [ ] Item 41: Quality of hire é medida após 6 e 12 meses de cada contratação
- [ ] Item 42: Taxa de aprovação no período de experiência está acima de 90%
- [ ] Item 43: Hiring manager satisfaction com o processo é medida e está acima de 8/10
- [ ] Item 44: Time-to-fill está dentro do benchmark para cada tipo de posição
- [ ] Item 45: Offer acceptance rate está acima de 80%
- [ ] Item 46: A correlação entre scorecard predictions e performance real é analisada
- [ ] Item 47: O processo é revisado trimestralmente com base nas métricas coletadas

## Critérios de Aprovação
O hiring bar é considerado saudável quando:

1. **100% das posições abertas têm perfil e scorecard definidos antes do início do sourcing**
2. **100% dos entrevistadores foram treinados no processo (Seção 2)**
3. **95% das entrevistas têm scorecard preenchido em até 24 horas**
4. **Quality of hire score está acima do threshold definido**
5. **Offer acceptance rate está acima de 80%**
6. **Análise de viés não mostra disparidades significativas no pipeline ou contratações**
7. **Bar Raiser participou de 100% dos debriefs de posições sênior**

## O que Fazer se Falhar
Se o hiring bar não atinge os critérios:

1. **Hiring freeze parcial:** Pausar contratações em áreas com bar comprometido até correção
2. **Bar Raiser calibration:** Reunir Bar Raisers para recalibrar padrões e critérios
3. **Interview training:** Reciclar treinamento de entrevistadores com foco em gaps identificados
4. **Process simplification:** Se o processo é muito complexo, candidatos bons desistem — simplificar
5. **Scorecard review:** Atualizar scorecards e rubrics com base em dados de quality of hire
6. **Comp review:** Se offer acceptance está baixa, revisar competitividade de compensação
7. **Source diversification:** Ampliar canais de sourcing se pipeline não está diverso
8. **Feedback loop:** Conectar dados de performance dos contratados com o processo de avaliação
