# Checklist de PIP (Performance Improvement Plan)

## Objetivo
Estruturar o processo de plano de melhoria de performance, garantindo que o colaborador receba suporte adequado e que o processo seja justo, documentado e legalmente sólido.

---

## Fase 1: Avaliação da Necessidade de PIP

### Diagnóstico de Performance
- [ ] Documentar gaps específicos de performance com exemplos concretos
- [ ] Verificar se feedback regular foi dado antes de considerar PIP
- [ ] Confirmar que expectativas foram comunicadas claramente
- [ ] Avaliar se há fatores externos impactando performance (pessoal, saúde)
- [ ] Verificar se ferramentas, treinamento e suporte adequados foram fornecidos
- [ ] Descartar problemas sistêmicos (processo, ferramenta, workload)

### Consulta com RH e Jurídico
- [ ] Discutir situação com Business Partner de RH
- [ ] Revisar histórico de performance reviews do colaborador
- [ ] Verificar se há precedentes similares na empresa
- [ ] Avaliar riscos legais e trabalhistas
- [ ] Confirmar que PIP é a ação apropriada vs coaching ou realocação
- [ ] Documentar alternativas consideradas antes do PIP

### Decisão de Prosseguir
- [ ] Aprovação do gestor do gestor (skip-level)
- [ ] Aprovação do RH para iniciar o processo
- [ ] Definir se objetivo é genuinamente recuperar ou documentar
- [ ] Comprometer-se com suporte real durante o plano
- [ ] Definir timeline do PIP (geralmente 30-60-90 dias)
- [ ] Preparar mentalmente para investir tempo significativo no processo

---

## Fase 2: Elaboração do PIP

### Estrutura do Documento
- [ ] Descrever claramente as áreas de melhoria necessárias
- [ ] Usar exemplos específicos e mensuráveis (não vagos ou subjetivos)
- [ ] Definir metas SMART para cada área de melhoria
- [ ] Estabelecer milestones intermediários com checkpoints
- [ ] Definir critérios objetivos de sucesso e insucesso
- [ ] Documentar consequências em caso de não atingimento
- [ ] Incluir recursos e suporte que serão oferecidos

### Metas e Expectativas
- [ ] Meta 1: [área técnica/funcional] com métricas claras
- [ ] Meta 2: [área comportamental] com exemplos de comportamento esperado
- [ ] Meta 3: [área de entrega] com deliverables específicos
- [ ] Cada meta com indicadores de progresso semanais
- [ ] Metas devem ser desafiadoras mas atingíveis
- [ ] Metas devem estar alinhadas com a função, não com exceções

### Suporte Oferecido
- [ ] 1:1s semanais dedicados ao progresso do PIP
- [ ] Mentoria ou coaching adicional designado
- [ ] Treinamentos específicos para gaps identificados
- [ ] Pair work com colega mais experiente se aplicável
- [ ] Redução temporária de escopo para focar na melhoria
- [ ] Acesso a recursos adicionais (cursos, livros, ferramentas)

---

## Fase 3: Comunicação e Início

### Conversa de Abertura do PIP
- [ ] Agendar reunião presencial ou call privada
- [ ] Ter representante de RH presente na conversa
- [ ] Comunicar com empatia mas com clareza sobre a seriedade
- [ ] Apresentar o documento do PIP detalhadamente
- [ ] Explicar cada meta e critério de sucesso
- [ ] Descrever o suporte que será oferecido
- [ ] Abrir espaço para perguntas e perspectiva do colaborador
- [ ] Deixar claro que o objetivo é a melhoria genuína
- [ ] Solicitar assinatura de ciência (não concordância)

### Documentação
- [ ] Registrar a conversa em ata assinada por ambas as partes
- [ ] Enviar cópia do PIP por email para registro
- [ ] Arquivar documento no sistema de RH
- [ ] Notificar jurídico sobre início do processo
- [ ] Criar pasta dedicada para documentação do PIP

---

## Fase 4: Acompanhamento Semanal

### Check-ins Semanais
- [ ] Revisar progresso em cada meta com dados concretos
- [ ] Documentar cada check-in com ata assinada
- [ ] Fornecer feedback específico e acionável
- [ ] Reconhecer progressos e melhorias observadas
- [ ] Ajustar suporte se abordagem atual não está funcionando
- [ ] Manter tom construtivo e de parceria

### Documentação Contínua
- [ ] Registrar exemplos positivos de melhoria
- [ ] Registrar exemplos de gaps que persistem
- [ ] Coletar feedback de stakeholders sobre evolução
- [ ] Manter RH atualizado sobre progresso semanalmente
- [ ] Documentar qualquer ajuste feito no plano e razões
- [ ] Arquivar evidências objetivas (métricas, entregas, feedback)

### Checkpoints Intermediários
- [ ] Checkpoint 30 dias: avaliar progresso vs expectativa
- [ ] Decisão: continuar, ajustar ou encerrar PIP
- [ ] Checkpoint 60 dias (se PIP de 90): reavaliar trajetória
- [ ] Comunicar avaliação formal em cada checkpoint
- [ ] Documentar decisão de cada checkpoint com justificativa

---

## Fase 5: Encerramento do PIP

### Cenário 1: Sucesso (Metas Atingidas)
- [ ] Documentar evidências de atingimento de cada meta
- [ ] Comunicar formalmente o encerramento bem-sucedido
- [ ] Reconhecer o esforço e melhoria do colaborador
- [ ] Definir plano de sustentação da melhoria
- [ ] Manter check-ins mensais por mais 3 meses
- [ ] Remover estigma: tratar como fresh start
- [ ] Documentar encerramento positivo no RH

### Cenário 2: Insucesso (Metas Não Atingidas)
- [ ] Documentar evidências de não atingimento com dados
- [ ] Validar decisão com RH e jurídico antes de comunicar
- [ ] Avaliar opções: extensão do PIP, realocação ou desligamento
- [ ] Se desligamento: seguir checklist de offboarding
- [ ] Comunicar decisão com empatia e respeito
- [ ] Oferecer pacote de saída conforme política da empresa
- [ ] Documentar todo o processo para registro legal

### Cenário 3: Parcial (Progresso Significativo mas Incompleto)
- [ ] Avaliar se extensão do PIP por 30 dias é justificável
- [ ] Redefinir metas restantes com timeline ajustado
- [ ] Manter mesmo nível de suporte e acompanhamento
- [ ] Documentar razões para extensão
- [ ] Definir que esta será a extensão final

---

## Princípios Fundamentais do PIP

### Faça
- Documente tudo meticulosamente
- Ofereça suporte genuíno e investimento de tempo
- Use dados e exemplos concretos, nunca impressões vagas
- Mantenha confidencialidade do processo
- Trate o colaborador com dignidade e respeito em todo momento

### Não Faça
- Não use PIP como formalidade para desligamento já decidido
- Não defina metas impossíveis para justificar demissão
- Não discuta o PIP com outros membros do time
- Não ignore sinais de problema emocional ou de saúde mental
- Não pule check-ins ou documentação por falta de tempo
