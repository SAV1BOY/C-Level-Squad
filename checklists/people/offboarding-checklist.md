# Checklist de Offboarding

## Objetivo
Conduzir o processo de desligamento de forma profissional, respeitosa e completa, protegendo a empresa e preservando o relacionamento com o colaborador.

---

## Fase 1: Comunicação do Desligamento

### Preparação (Antes da conversa)
- [ ] Alinhar decisão com RH e jurídico
- [ ] Definir tipo de desligamento: voluntário, involuntário, acordo mútuo
- [ ] Calcular verbas rescisórias e preparar proposta financeira
- [ ] Definir data de último dia de trabalho
- [ ] Preparar talking points para a conversa
- [ ] Agendar sala privada ou call confidencial
- [ ] Ter representante de RH presente na conversa
- [ ] Preparar carta de desligamento formal

### Conversa de Desligamento
- [ ] Conduzir com empatia, respeito e objetividade
- [ ] Comunicar decisão de forma clara e direta
- [ ] Explicar termos financeiros e benefícios
- [ ] Informar sobre período de aviso prévio (trabalhado ou indenizado)
- [ ] Esclarecer próximos passos administrativos
- [ ] Oferecer suporte de outplacement se aplicável
- [ ] Documentar o que foi acordado na conversa

### Comunicação para a Organização
- [ ] Alinhar com o colaborador o que será comunicado externamente
- [ ] Comunicar o time imediato pessoalmente (gestor direto)
- [ ] Enviar comunicado para stakeholders que precisam saber
- [ ] Preparar FAQ para perguntas frequentes do time
- [ ] Não expor motivos pessoais do desligamento publicamente

---

## Fase 2: Transição de Conhecimento

### Documentação
- [ ] Listar projetos e responsabilidades do colaborador
- [ ] Documentar status de cada projeto em andamento
- [ ] Registrar processos que só o colaborador conhece
- [ ] Documentar acessos, senhas e credenciais administradas
- [ ] Listar contatos de clientes e fornecedores gerenciados
- [ ] Atualizar wiki e documentação técnica relevante

### Transferência de Responsabilidades
- [ ] Definir quem assumirá cada responsabilidade
- [ ] Agendar sessões de knowledge transfer com sucessores
- [ ] Transferir ownership de documentos e projetos
- [ ] Redirecionar emails e notificações relevantes
- [ ] Atualizar RACI e organogramas
- [ ] Realizar handover formal com cada stakeholder impactado

### Relacionamento com Clientes
- [ ] Mapear clientes com relacionamento direto com o colaborador
- [ ] Planejar transição de relacionamento para novo responsável
- [ ] Comunicar mudança para clientes de forma profissional
- [ ] Garantir continuidade de SLAs e compromissos

---

## Fase 3: Revogação de Acessos

### Acessos Digitais (No último dia ou imediato se necessário)
- [ ] Desativar email corporativo
- [ ] Revogar acesso a Slack, Teams e ferramentas de comunicação
- [ ] Remover de repositórios de código (GitHub, GitLab, Bitbucket)
- [ ] Revogar acesso a ferramentas de produtividade (Jira, Notion, Confluence)
- [ ] Desativar VPN e acessos remotos
- [ ] Remover de ferramentas de cloud (AWS, GCP, Azure)
- [ ] Revogar acessos a ferramentas financeiras e de RH
- [ ] Desativar SSO e revogar tokens de autenticação
- [ ] Remover de listas de distribuição e grupos

### Acessos Físicos
- [ ] Recolher badge e credenciais de acesso
- [ ] Desativar biometria se cadastrada
- [ ] Retirar acesso a estacionamento
- [ ] Atualizar lista de acesso com segurança patrimonial

### Equipamentos
- [ ] Recolher laptop e periféricos corporativos
- [ ] Realizar backup de dados corporativos do equipamento
- [ ] Wipe seguro do equipamento após backup
- [ ] Recolher celular corporativo se aplicável
- [ ] Inventariar equipamentos devolvidos vs fornecidos

---

## Fase 4: Processos Administrativos

### Financeiro e Legal
- [ ] Processar verbas rescisórias conforme legislação
- [ ] Calcular férias proporcionais e vencidas
- [ ] Processar 13o salário proporcional
- [ ] Emitir guias de FGTS e seguro-desemprego se aplicável
- [ ] Providenciar exame demissional
- [ ] Entregar documentação rescisória ao colaborador
- [ ] Atualizar registros em e-Social e órgãos competentes
- [ ] Cancelar ou converter benefícios (plano de saúde, previdência)

### Stock Options / Equity
- [ ] Informar status de vesting e exercício
- [ ] Documentar deadline para exercício pós-saída
- [ ] Orientar sobre tributação e processo de exercício
- [ ] Atualizar cap table se necessário

---

## Fase 5: Encerramento

### Entrevista de Desligamento
- [ ] Conduzir entrevista de desligamento com RH (não com gestor)
- [ ] Usar roteiro padronizado para consistência
- [ ] Perguntar sobre experiência, cultura e gestão
- [ ] Coletar sugestões de melhoria
- [ ] Documentar insights para análise agregada
- [ ] Garantir confidencialidade das respostas

### Último Dia
- [ ] Permitir despedida adequada do time
- [ ] Entregar carta de recomendação se aplicável
- [ ] Agradecer contribuições do colaborador
- [ ] Confirmar informações de contato atualizadas
- [ ] Entregar documentação final e recibos

### Alumni e Relacionamento Contínuo
- [ ] Convidar para rede de alumni se existente
- [ ] Manter porta aberta para retorno futuro (boomerang)
- [ ] Conectar no LinkedIn se apropriado
- [ ] Solicitar avaliação no Glassdoor de forma ética
- [ ] Considerar para programa de referral de talentos
