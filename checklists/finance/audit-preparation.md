# Checklist de Preparação de Auditoria

> Checklist para garantir que a organização esteja preparada para auditorias
> externas, internas ou de compliance, minimizando riscos e retrabalho.

---

## 1. Planejamento Pré-Auditoria (6-8 semanas antes)

- [ ] Data da auditoria confirmada com a firma auditora
- [ ] Escopo da auditoria definido e documentado
- [ ] Equipe interna de suporte à auditoria designada
- [ ] Cronograma detalhado de entregas acordado
- [ ] Sala/espaço para os auditores reservado (presencial ou virtual)
- [ ] Acessos a sistemas necessários preparados para auditores
- [ ] Lista de documentos solicitados (PBC list) recebida e distribuída
- [ ] Responsáveis por cada item do PBC designados
- [ ] Reunião de kick-off agendada com auditores e time interno
- [ ] Budget da auditoria aprovado

## 2. Documentação Financeira

### 2.1 Demonstrações e Relatórios
- [ ] Balanço patrimonial preparado e conciliado
- [ ] DRE preparada com análise de variações
- [ ] Demonstração de fluxo de caixa preparada
- [ ] DMPL (Demonstração de Mutações do PL) preparada
- [ ] Notas explicativas redigidas e revisadas
- [ ] Balancete analítico gerado e reconciliado
- [ ] Relatório da administração redigido

### 2.2 Conciliações
- [ ] Conciliação bancária de todas as contas atualizada
- [ ] Conciliação de contas a receber realizada
- [ ] Conciliação de contas a pagar realizada
- [ ] Conciliação de estoque (se aplicável)
- [ ] Conciliação de ativos fixos e depreciação
- [ ] Conciliação de empréstimos e financiamentos
- [ ] Conciliação intercompany (se aplicável)
- [ ] Conciliação fiscal (impostos a pagar/recuperar)

### 2.3 Suporte Documental
- [ ] Contratos relevantes organizados e acessíveis
- [ ] Notas fiscais de compras e vendas arquivadas
- [ ] Extratos bancários dos últimos 12 meses disponíveis
- [ ] Comprovantes de pagamento de impostos organizados
- [ ] Documentação de provisões e estimativas contábeis
- [ ] Cartas de circularização preparadas (clientes, fornecedores, bancos)
- [ ] Laudos de avaliação atualizados (imóveis, intangíveis)
- [ ] Apólices de seguro vigentes disponíveis

## 3. Controles Internos

- [ ] Mapeamento de processos-chave atualizado
- [ ] Matriz de segregação de funções revisada
- [ ] Políticas de aprovação e alçadas documentadas
- [ ] Testes de controles internos executados pelo time
- [ ] Deficiências identificadas com plano de remediação
- [ ] Evidências de controles coletadas e organizadas
- [ ] Fluxo de aprovação de despesas documentado
- [ ] Processo de reconhecimento de receita documentado
- [ ] Controle de acessos a sistemas financeiros revisado
- [ ] Logs de alterações em lançamentos contábeis disponíveis

## 4. Compliance e Regulatório

- [ ] Obrigações fiscais em dia (IRPJ, CSLL, PIS, COFINS, ISS)
- [ ] Obrigações trabalhistas em dia (FGTS, INSS, férias)
- [ ] DCTF, ECD, ECF entregues no prazo
- [ ] Certidões negativas de débito obtidas
- [ ] Livros contábeis e fiscais registrados
- [ ] Compliance com normas CPC/IFRS verificado
- [ ] Mudanças em normas contábeis aplicáveis identificadas
- [ ] Eventos subsequentes ao fechamento documentados
- [ ] Partes relacionadas identificadas e transações documentadas
- [ ] Contingências judiciais atualizadas com o jurídico

## 5. Tecnologia e Sistemas

- [ ] Sistema contábil (ERP) com dados consistentes e fechados
- [ ] Relatórios do sistema validados contra planilhas auxiliares
- [ ] Backup dos dados do período auditado realizado
- [ ] Trilha de auditoria (audit trail) habilitada nos sistemas
- [ ] Acessos de usuários desligados revogados
- [ ] Logs de sistema disponíveis para o período
- [ ] Integrações entre sistemas validadas
- [ ] Conversão de dados (se houve migração) documentada

## 6. Pessoas e Comunicação

- [ ] Time financeiro informado sobre cronograma e expectativas
- [ ] Disponibilidade do time garantida durante o período de auditoria
- [ ] Porta-voz designado para comunicação com auditores
- [ ] Protocolo para solicitações adicionais definido
- [ ] Escalonamento para questões complexas definido
- [ ] CFO disponível para reuniões com sócios da auditoria
- [ ] CEO/Board informados sobre o cronograma
- [ ] Treinamento sobre interação com auditores realizado

## 7. Encerramento e Follow-up

- [ ] Carta de representação da administração preparada
- [ ] Draft do relatório de auditoria revisado pelo time
- [ ] Ajustes de auditoria avaliados e registrados (se aceitos)
- [ ] Carta de recomendações discutida com auditores
- [ ] Plano de ação para recomendações elaborado
- [ ] Lições aprendidas documentadas para próximo ciclo
- [ ] Arquivo permanente de auditoria atualizado
- [ ] Relatório final aprovado pelo Conselho/Comitê de Auditoria

---

## Cronograma Típico

| Atividade | Prazo |
|-----------|-------|
| Recebimento do PBC list | 8 semanas antes |
| Preparação de documentos | 6-4 semanas antes |
| Pré-auditoria (interim) | 4-2 semanas antes |
| Fechamento contábil | Data de referência |
| Trabalho de campo | 2-4 semanas após fechamento |
| Draft do relatório | 2 semanas após campo |
| Relatório final | 4 semanas após campo |

---

## Dicas para uma Auditoria Eficiente

1. **Antecipe-se**: Não espere o PBC list para começar a organizar documentos
2. **Comunique proativamente**: Informe auditores sobre mudanças relevantes
3. **Organize digitalmente**: Use pasta compartilhada com nomenclatura padronizada
4. **Documente julgamentos**: Decisões contábeis subjetivas devem ter memorandos
5. **Mantenha registro**: Todas as interações com auditores devem ser documentadas
