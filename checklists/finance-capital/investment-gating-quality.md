# Checklist de Qualidade de Investment Gating (Investment Gating Quality)

## Propósito
Garantir que todo investimento significativo passe por gates (portões) de aprovação
estruturados, com critérios de kill definidos em cada estágio. Este checklist evita
que investimentos continuem por inércia quando deveriam ser pausados ou cancelados,
protegendo capital para oportunidades de maior retorno.

## Quando Aplicar
- Na aprovação inicial de qualquer investimento acima do threshold gerencial
- Em cada gate review durante a execução do investimento
- Quando um investimento apresenta sinais de underperformance
- Na revisão trimestral de portfólio de investimentos
- Antes de aportes adicionais em investimentos já aprovados

## Agente Responsável
- **Primário:** Chief Financial Officer (CFO) como guardião do processo de gating
- **Secundário:** Investment sponsor (líder que propôs o investimento)
- **Revisor:** Investment Committee (CEO, CFO e pelo menos mais 1 C-Level)

## Checklist

### Seção 1 — Gate 0: Proposta Inicial (Initial Proposal Gate)
- [ ] Item 1: O business case está documentado com problema, solução e impacto esperado
- [ ] Item 2: O investimento total estimado (all-in cost) está calculado
- [ ] Item 3: O retorno esperado está quantificado (ROI, NPV, IRR conforme aplicável)
- [ ] Item 4: O timeline de retorno está definido (quando o investimento se paga)
- [ ] Item 5: Alternativas ao investimento foram avaliadas (build vs. buy vs. partner)
- [ ] Item 6: O custo de oportunidade está considerado (o que deixamos de fazer)
- [ ] Item 7: O sponsor do investimento está identificado e comprometido
- [ ] Item 8: O investimento está alinhado com a estratégia e OKRs aprovados
- [ ] Item 9: Riscos principais estão identificados com plano de mitigação
- [ ] Item 10: O investimento foi aprovado pelo Investment Committee para prosseguir

### Seção 2 — Gate 1: Validação (Validation Gate)
- [ ] Item 11: Premissas do business case foram testadas com dados reais (não apenas projeções)
- [ ] Item 12: Prova de conceito (POC) ou piloto foi conduzido com resultados documentados
- [ ] Item 13: Feedback de clientes ou usuários potenciais foi coletado
- [ ] Item 14: Viabilidade técnica foi confirmada pela equipe de engenharia
- [ ] Item 15: Viabilidade operacional foi confirmada pela equipe de operações
- [ ] Item 16: Custos reais da fase de validação estão dentro do orçado (variação < 20%)
- [ ] Item 17: Os dados da validação suportam a continuidade do investimento
- [ ] Item 18: O Investment Committee revisou resultados e aprovou passagem para Gate 2

### Seção 3 — Gate 2: Execução (Execution Gate)
- [ ] Item 19: Plano de execução detalhado está aprovado com milestones e budget
- [ ] Item 20: Equipe está alocada e comprometida com o projeto
- [ ] Item 21: Métricas de sucesso intermediárias (leading indicators) estão definidas
- [ ] Item 22: Cadência de revisão durante execução está estabelecida (mensal no mínimo)
- [ ] Item 23: O burn rate está sendo monitorado contra o budget aprovado
- [ ] Item 24: Riscos identificados estão sendo gerenciados ativamente
- [ ] Item 25: Resultados intermediários estão alinhados com as projeções (ou melhor)
- [ ] Item 26: Se resultados estão abaixo do esperado, plano de correção está documentado

### Seção 4 — Gate 3: Scale (Scale Gate)
- [ ] Item 27: Resultados da fase de execução atingiram thresholds mínimos para escalar
- [ ] Item 28: Unit economics da operação em escala foram projetados e são viáveis
- [ ] Item 29: Infraestrutura e capacidade para escalar estão confirmadas
- [ ] Item 30: Budget adicional para scale está aprovado
- [ ] Item 31: Riscos de escala foram mapeados (complexidade operacional, qualidade)
- [ ] Item 32: O mercado ou demanda suporta a escala planejada
- [ ] Item 33: O Investment Committee aprovou a escalada com budget definido

### Seção 5 — Kill Criteria (Critérios de Encerramento)
- [ ] Item 34: Kill criteria estão definidos antes do início do investimento (não depois)
- [ ] Item 35: Cada gate tem thresholds quantitativos de go/no-go
- [ ] Item 36: O critério de "sunk cost" é irrelevante na decisão de continuar (sunk cost fallacy mitigada)
- [ ] Item 37: O sponsor concorda com os kill criteria e se compromete a respeitá-los
- [ ] Item 38: Se kill criteria são atingidos, o processo de wind-down está definido
- [ ] Item 39: Aprendizados de investimentos encerrados são documentados e compartilhados
- [ ] Item 40: O time de finance monitora kill criteria independentemente do sponsor
- [ ] Item 41: Decisão de kill é tratada como boa gestão de capital, não como fracasso

### Seção 6 — Governança do Portfólio de Investimentos
- [ ] Item 42: O portfólio total de investimentos é revisado trimestralmente
- [ ] Item 43: Cada investimento ativo tem status atualizado (green, yellow, red)
- [ ] Item 44: A concentração de risco no portfólio é avaliada (diversificação)
- [ ] Item 45: O capacity total da organização para gerir investimentos simultâneos é respeitado
- [ ] Item 46: Investimentos são priorizados por retorno esperado ajustado ao risco
- [ ] Item 47: O board recebe relatório de portfólio de investimentos trimestralmente
- [ ] Item 48: Histórico de performance de investimentos anteriores é mantido como benchmark

## Critérios de Aprovação
O processo de investment gating é considerado saudável quando:

1. **100% dos investimentos acima do threshold passam por Gate 0 formal**
2. **Kill criteria estão definidos para 100% dos investimentos ativos (Seção 5)**
3. **Todos os gates são revisados pelo Investment Committee conforme calendário**
4. **Investimentos que atingiram kill criteria foram encerrados ou têm exceção documentada**
5. **Portfólio review trimestral está acontecendo (Seção 6)**
6. **O CFO assina que o processo de gating está funcionando adequadamente**
7. **Pelo menos 80% dos investimentos em Gate 2+ estão on-track ou com recovery plan**

## O que Fazer se Falhar
Se o processo de investment gating não atinge os critérios:

1. **Audit de investimentos:** Revisar todos os investimentos ativos contra kill criteria
2. **Kill decisions:** Tomar decisões difíceis de encerrar investimentos que não performam
3. **Process enforcement:** Garantir que nenhum investimento bypass o processo de gating
4. **Committee reactivation:** Se o Investment Committee não está se reunindo, reativar
5. **CFO empowerment:** Garantir que o CFO tem authority para bloquear gates
6. **Sunk cost training:** Treinar liderança sobre sunk cost fallacy e coragem de parar
7. **Incentive alignment:** Garantir que sponsors não são penalizados por recomendar kill
8. **Benchmark review:** Comparar taxa de sucesso de investimentos com benchmarks de mercado
