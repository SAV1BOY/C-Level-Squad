# Checklist de Qualidade Orçamentária (Budget Quality)

## Propósito
Garantir que todo orçamento apresentado ao C-Level Squad esteja justificado com dados,
cenários modelados e alocação clara de recursos. Este checklist evita aprovação de
budgets inflacionados, mal distribuídos ou desconectados da estratégia, protegendo
a saúde financeira da organização.

## Quando Aplicar
- Durante o ciclo anual de planejamento orçamentário (annual budget planning)
- Em revisões trimestrais de budget (quarterly budget review)
- Quando um pedido de budget incremental é submetido (mid-year request)
- Antes de aprovar investimentos que excedam threshold de aprovação gerencial
- Na preparação de cenários financeiros para o board ou investidores

## Agente Responsável
- **Primário:** Chief Financial Officer (CFO) ou Head of FP&A
- **Secundário:** Cada Squad Lead para o budget do seu squad
- **Revisor:** CEO para aprovação final do budget consolidado

## Checklist

### Seção 1 — Justificativa do Budget (Budget Justification)
- [ ] Item 1: Cada linha de budget tem justificativa escrita vinculada a um objetivo estratégico ou OKR
- [ ] Item 2: O budget está alinhado com a estratégia aprovada (sem itens órfãos)
- [ ] Item 3: Comparação com o budget do período anterior está disponível (YoY analysis)
- [ ] Item 4: Variações significativas em relação ao período anterior estão justificadas
- [ ] Item 5: O ROI esperado de cada categoria de investimento está estimado
- [ ] Item 6: Itens de budget que são recorrentes vs. one-time estão claramente distinguidos
- [ ] Item 7: Custos fixos vs. variáveis estão separados e identificados
- [ ] Item 8: Premissas de receita que sustentam o budget estão documentadas
- [ ] Item 9: O budget reflete as prioridades comunicadas pelo CEO e board
- [ ] Item 10: Trade-offs entre investimento e margem estão explícitos

### Seção 2 — Modelagem de Cenários (Scenario Modeling)
- [ ] Item 11: Cenário base (base-case) está modelado com premissas claras
- [ ] Item 12: Cenário otimista (upside) está modelado com premissas diferentes do base
- [ ] Item 13: Cenário pessimista (downside) está modelado com impacto quantificado
- [ ] Item 14: Cada cenário tem premissas explícitas e testáveis
- [ ] Item 15: Sensitivity analysis foi conduzida para as variáveis mais impactantes
- [ ] Item 16: O ponto de breakeven está calculado para cada cenário
- [ ] Item 17: Cash runway (meses de operação com caixa atual) está calculado por cenário
- [ ] Item 18: Trigger points para mudar de cenário base para contingência estão definidos
- [ ] Item 19: O impacto de câmbio (se aplicável) foi considerado nos cenários
- [ ] Item 20: Cenários de stress test extremo (black swan) foram pelo menos discutidos

### Seção 3 — Alocação de Recursos (Resource Allocation)
- [ ] Item 21: A alocação por squad ou departamento está clara e aprovada
- [ ] Item 22: A proporção entre run-the-business e change-the-business está definida
- [ ] Item 23: Investimentos em growth vs. eficiência estão balanceados conforme estratégia
- [ ] Item 24: Headcount plan está integrado com o budget financeiro
- [ ] Item 25: Custos de tecnologia e infraestrutura estão detalhados e realistas
- [ ] Item 26: Contingência (reserve buffer) está incluída (recomendado: 5-10% do total)
- [ ] Item 27: Processos de realocação mid-year estão definidos (como redirecionar verba)
- [ ] Item 28: Aprovações escalonadas por valor estão documentadas (approval matrix)

### Seção 4 — Tracking e Accountability
- [ ] Item 29: Dashboard de acompanhamento de budget vs. actual está configurado
- [ ] Item 30: Frequência de revisão está definida (mínimo mensal para squads, trimestral para C-Level)
- [ ] Item 31: Variações acima de threshold (ex: 10%) geram alerta automático
- [ ] Item 32: Cada squad lead é accountable pelo budget do seu squad
- [ ] Item 33: Forecast de final de período (full-year forecast) é atualizado trimestralmente
- [ ] Item 34: Accrual e reconhecimento de despesas seguem princípios contábeis adequados
- [ ] Item 35: O CFO apresenta budget review ao C-Level Squad mensalmente

### Seção 5 — Governança e Aprovação
- [ ] Item 36: O budget foi aprovado pelos stakeholders corretos (CFO, CEO, Board se aplicável)
- [ ] Item 37: O processo de aprovação está documentado com sign-off formal
- [ ] Item 38: Mudanças no budget pós-aprovação seguem processo formal de change request
- [ ] Item 39: Delegação de authority para gastos está clara por nível hierárquico
- [ ] Item 40: Auditoria interna do budget é conduzida pelo menos anualmente
- [ ] Item 41: O budget está reconciliado com o plano financeiro de longo prazo (3-5 anos)
- [ ] Item 42: Compliance com políticas de despesa está monitorada
- [ ] Item 43: Relatório de budget vs. actual é apresentado ao Board trimestralmente

## Critérios de Aprovação
O budget é considerado aprovado quando:

1. **100% das linhas de budget têm justificativa vinculada à estratégia (Seção 1)**
2. **Pelo menos 3 cenários foram modelados com premissas documentadas (Seção 2)**
3. **Alocação por squad/departamento está aprovada por cada squad lead (Seção 3)**
4. **Dashboard de tracking está configurado e funcional (Seção 4)**
5. **CFO assinou a aprovação técnica do budget**
6. **CEO aprovou o budget consolidado**
7. **Board aprovou (se threshold de board approval for atingido)**

## O que Fazer se Falhar
Se o budget não atinge os critérios de qualidade:

1. **Revisão detalhada:** Identificar quais linhas carecem de justificativa ou estão inflacionadas
2. **Challenge session:** CFO conduz sessão de challenge com cada squad lead
3. **Cenários adicionais:** Se cenários estão incompletos, modelar com premissas conservadoras
4. **Benchmark externo:** Comparar alocação com benchmarks de empresas similares
5. **Priorização forçada:** Se budget total excede capacidade, forçar stack rank de investimentos
6. **Prazo de correção:** Máximo de 10 dias úteis para resubmissão
7. **CFO intervention:** CFO pode realocar unilateralmente se squads não convergem
8. **Não aprovar parcialmente:** Budget incompleto não deve ser aprovado por partes
