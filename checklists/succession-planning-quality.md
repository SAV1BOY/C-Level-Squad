# Checklist de Qualidade — Succession Planning (Planejamento de Sucessão)

## Propósito
Garantir que o planejamento de sucessão seja robusto: pipeline de sucessores identificados para posições críticas, readiness de cada candidato avaliada com objetividade, timeline de desenvolvimento definido e gaps endereçados com ações concretas. Este checklist protege a organização contra riscos de pessoas-chave (key person risk) e assegura continuidade de liderança em todos os cenários.

## Quando Aplicar
- Na revisão anual do succession plan (tipicamente vinculada ao talent review)
- Quando posições críticas ficam vagas ou há risco iminente de vacância
- Na preparação de materiais para o comitê de pessoas do board
- Quando há mudança estratégica que altera o perfil necessário de liderança
- Na avaliação de readiness para promoções de nível executivo
- Quando agentes de pessoas identificam riscos de retenção em posições-chave

## Agente Responsável
- **Primário:** CHRO Agent ou People Agent
- **Co-responsável:** CEO Agent (para posições de C-Level e report direto)
- **Contribuidores:** Cada C-Level Agent para sucessão em suas áreas
- **Validador:** Board People/Compensation Committee

## Checklist

### Seção 1 — Pipeline Identificado
- [ ] As posições críticas (key roles) da organização estão identificadas e listadas
- [ ] Os critérios para classificar uma posição como crítica estão documentados
- [ ] Cada posição crítica tem pelo menos 2 sucessores potenciais identificados
- [ ] Os sucessores são de diferentes backgrounds e perfis (diversidade no pipeline)
- [ ] Os sucessores internos e externos potenciais estão separados na avaliação
- [ ] O mapa de riscos de pessoas-chave (key person risk) está atualizado
- [ ] As posições sem sucessores identificados estão sinalizadas como risco crítico
- [ ] O pipeline considera tanto short-term (emergency) quanto long-term successors
- [ ] Os high-potentials (HiPos) da organização estão mapeados independentemente de posição
- [ ] A diversidade do pipeline está avaliada contra metas de D&I da organização
- [ ] O pipeline foi revisado com inputs de múltiplos líderes (não apenas o gestor direto)
- [ ] A confidencialidade do succession plan está garantida (acesso restrito)

### Seção 2 — Readiness Avaliada
- [ ] Cada sucessor tem uma avaliação de readiness com escala clara (pronto agora, 1 ano, 2+ anos)
- [ ] A avaliação de readiness é baseada em critérios objetivos, não apenas opinião do gestor
- [ ] As competências técnicas e de liderança estão avaliadas separadamente
- [ ] O track record de performance do sucessor está documentado (últimos 3 anos)
- [ ] O potencial de crescimento do sucessor está avaliado (não apenas performance passada)
- [ ] Os gaps de competência de cada sucessor estão identificados com especificidade
- [ ] A motivação e aspiração do sucessor estão verificadas (quer o role?)
- [ ] O risco de perda (flight risk) de cada sucessor está avaliado
- [ ] A avaliação inclui feedback 360 ou multi-source quando disponível
- [ ] Os derailers (riscos de fracasso) de cada sucessor estão identificados
- [ ] A avaliação é atualizada no mínimo anualmente com dados recentes
- [ ] O comparativo entre candidatos internos e o mercado externo está documentado

### Seção 3 — Timeline Definido
- [ ] Cada sucessor tem um individual development plan (IDP) com timeline
- [ ] Os milestones de desenvolvimento estão definidos por trimestre ou semestre
- [ ] As experiências de desenvolvimento necessárias estão planejadas (stretch assignments, rotations)
- [ ] O mentoring e coaching necessários estão definidos com mentores designados
- [ ] O training formal (programas, cursos, certificações) está planejado e orçado
- [ ] O timeline de readiness está calibrado realisticamente (não otimista demais)
- [ ] O plano de exposição a stakeholders (board, clientes-chave, parceiros) está definido
- [ ] Os checkpoints de avaliação de progresso estão agendados
- [ ] O plano de transição (handover plan) para quando a sucessão ocorrer está delineado
- [ ] O cenário de emergência (emergency succession) está documentado e comunicado
- [ ] O timeline está alinhado com a estratégia da organização (perfil necessário no futuro)

### Seção 4 — Gaps Endereçados
- [ ] Os gaps de competência estão priorizados por criticidade e timeline
- [ ] Cada gap tem um plano de desenvolvimento específico (não genérico)
- [ ] Os recursos para desenvolvimento estão alocados (budget, tempo, mentores)
- [ ] Os stretch assignments estão definidos com objetivos claros de aprendizado
- [ ] A exposição a desafios que simulam o role futuro está planejada
- [ ] O suporte organizacional para o desenvolvimento está garantido (tempo protegido)
- [ ] Os gaps que não podem ser fechados internamente estão sinalizados (considerar talent externo)
- [ ] O progresso de fechamento de gaps está sendo monitorado regularmente
- [ ] O feedback contínuo ao sucessor sobre seu desenvolvimento está implementado
- [ ] Os gaps culturais ou de fit estão avaliados e endereçados

### Seção 5 — Governança e Comunicação
- [ ] O succession plan está reportado ao board/comitê de pessoas na cadência definida
- [ ] A confidencialidade é mantida — apenas stakeholders necessários têm acesso
- [ ] A comunicação com os sucessores sobre suas expectativas é cuidadosa e apropriada
- [ ] O impacto emocional e político da sucessão está considerado e gerenciado
- [ ] O processo de decisão final de sucessão está definido (quem decide, como, quando)
- [ ] O plano de comunicação para quando a sucessão ocorrer está preparado
- [ ] Os cenários de saída inesperada (death, disability, termination, resignation) estão cobertos
- [ ] A integração com o processo de performance management está implementada
- [ ] O succession plan está vinculado ao workforce planning e headcount strategy
- [ ] A eficácia do succession planning está medida (taxa de preenchimento interno, readiness accuracy)

## Critérios de Aprovação
- 100% das posições críticas identificadas com pelo menos 2 sucessores mapeados
- Readiness avaliada com critérios objetivos para cada sucessor
- Individual development plans definidos com timeline e milestones
- Emergency succession plan documentado e comunicado ao board
- Pipeline diverso e alinhado com metas de D&I
- Plan revisado por CEO Agent e apresentado ao board anualmente
- Score mínimo de completude: 85% dos itens marcados

## O que Fazer se Falhar
1. Se posições críticas não têm sucessores, ativar busca externa e desenvolvimento acelerado
2. Se readiness não está avaliada, realizar talent review assessment imediato
3. Se development plans não existem, criar IDPs com prazo de 30 dias
4. Se o pipeline não é diverso, ampliar critérios de busca e revisar vieses
5. Se o emergency plan não existe, criar imediatamente como prioridade de risco
6. Registrar gaps no RalphLoop para melhorar o ciclo seguinte de talent review
7. Nunca aceitar que posições de C-Level não tenham successor pipeline documentado
