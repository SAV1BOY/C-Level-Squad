# Checklist de Qualidade de Pricing e Packaging (Pricing & Packaging Quality)

## Propósito
Garantir que toda estratégia de precificação e empacotamento de produtos esteja
fundamentada em análise de valor percebido, métricas claras de value metric,
tiers lógicos e elasticidade testada. Este checklist protege contra erros de pricing
que destroem margem, confundem clientes ou deixam receita na mesa.

## Quando Aplicar
- Antes do lançamento de qualquer novo produto ou feature tier
- Durante revisões anuais ou semestrais de pricing
- Quando métricas de conversão indicam problemas no funil de monetização
- Após mudanças significativas no cenário competitivo de preços
- Antes de expansão para novos mercados geográficos com pricing diferente

## Agente Responsável
- **Primário:** Chief Revenue Officer (CRO) ou Head of Pricing
- **Secundário:** Chief Product Officer (CPO) para alinhamento de packaging
- **Revisor:** CFO para impacto financeiro e CEO para alinhamento estratégico

## Checklist

### Seção 1 — Value Metric (Métrica de Valor)
- [ ] Item 1: A value metric principal está definida e é compreensível para o cliente em menos de 10 segundos
- [ ] Item 2: A value metric está alinhada com o valor que o cliente extrai do produto
- [ ] Item 3: A value metric escala proporcionalmente com o uso e sucesso do cliente
- [ ] Item 4: A value metric é mensurável, previsível e auditável pelo cliente
- [ ] Item 5: Pelo menos 3 alternativas de value metric foram avaliadas antes da escolha final
- [ ] Item 6: A value metric foi testada com pelo menos 20 clientes ou prospects em pesquisa qualitativa
- [ ] Item 7: A value metric não cria friction desnecessário no momento de compra
- [ ] Item 8: A value metric permite expansão natural de receita (net dollar retention)

### Seção 2 — Estrutura de Tiers (Tier Structure)
- [ ] Item 9: O número de tiers está entre 2 e 4 (sweet spot de simplicidade)
- [ ] Item 10: Cada tier tem um buyer persona claramente definido
- [ ] Item 11: A progressão entre tiers é lógica e o upgrade path é óbvio
- [ ] Item 12: Features em cada tier estão alinhadas com as necessidades do persona-alvo
- [ ] Item 13: Existe um tier de entrada acessível (free trial, freemium ou starter plan)
- [ ] Item 14: O tier enterprise está flexível o suficiente para customizações
- [ ] Item 15: Não existem features no tier errado (feature misalignment)
- [ ] Item 16: A diferenciação entre tiers é clara e não confunde o comprador
- [ ] Item 17: O most popular tier está claramente sinalizável (anchor pricing)
- [ ] Item 18: Add-ons e módulos adicionais estão definidos separadamente dos tiers

### Seção 3 — Análise de Elasticidade (Elasticity Testing)
- [ ] Item 19: Price sensitivity analysis (Van Westendorp ou Gabor-Granger) foi conduzida
- [ ] Item 20: O price point está dentro da faixa de aceitabilidade identificada na pesquisa
- [ ] Item 21: Elasticidade de preço foi testada com pelo menos 2 segmentos de clientes
- [ ] Item 22: O impacto de um aumento de 10% e 20% no preço foi modelado na conversão
- [ ] Item 23: O impacto de uma redução de 10% e 20% no preço foi modelado no volume
- [ ] Item 24: Willingness to pay foi validada com dados de mercado, não apenas surveys
- [ ] Item 25: Sazonalidade e ciclos de compra foram considerados no pricing
- [ ] Item 26: O efeito de desconto no valor percebido foi avaliado (discount policy)

### Seção 4 — Análise Competitiva de Pricing
- [ ] Item 27: Os preços dos top 5 competidores estão mapeados e atualizados
- [ ] Item 28: O posicionamento de preço relativo (premium, par, discount) está definido
- [ ] Item 29: A proposta de valor que justifica o posicionamento de preço está clara
- [ ] Item 30: Cenário de guerra de preços foi modelado com impacto em margem
- [ ] Item 31: Diferenças de packaging entre competidores foram analisadas
- [ ] Item 32: Preços de referência do mercado (anchoring) estão considerados

### Seção 5 — Impacto Financeiro (Financial Impact)
- [ ] Item 33: Projeção de receita por tier está modelada para 12, 24 e 36 meses
- [ ] Item 34: Impacto no CAC (Customer Acquisition Cost) por tier está estimado
- [ ] Item 35: Impacto no LTV (Lifetime Value) por tier está calculado
- [ ] Item 36: Margem bruta por tier atende ao threshold mínimo definido pela empresa
- [ ] Item 37: Mix de receita projetado por tier está definido (revenue mix)
- [ ] Item 38: Impacto em net dollar retention está modelado
- [ ] Item 39: Cenários de downside financeiro estão documentados
- [ ] Item 40: Break-even por tier está calculado

### Seção 6 — Implementação e Comunicação
- [ ] Item 41: Plano de migração para clientes existentes está definido (grandfathering policy)
- [ ] Item 42: Comunicação de mudança de preço para base existente está redigida e revisada
- [ ] Item 43: Pricing page do site está desenhada e testada com A/B framework
- [ ] Item 44: Equipe de vendas foi treinada no novo pricing e packaging
- [ ] Item 45: Ferramentas de billing e invoicing estão configuradas para suportar os novos tiers
- [ ] Item 46: FAQ interno e externo sobre pricing está pronto
- [ ] Item 47: Processo de aprovação de descontos e exceções está definido
- [ ] Item 48: Métricas de monitoramento pós-lançamento estão definidas (conversion rate, ARPU, churn)

## Critérios de Aprovação
A estratégia de pricing e packaging é aprovada quando:

1. **Mínimo de 85% dos itens do checklist marcados como completos**
2. **Todos os itens da Seção 1 (Value Metric) devem estar completos**
3. **Análise de elasticidade (Seção 3) deve ter pelo menos 80% de itens completos**
4. **Projeções financeiras (Seção 5) devem estar completas e revisadas pelo CFO**
5. **Plano de migração (Seção 6) deve estar aprovado para clientes existentes**
6. **O CRO, CPO e CFO assinaram a aprovação conjunta**
7. **Pelo menos um teste com clientes reais (Seção 3) foi conduzido**

## O que Fazer se Falhar
Se o checklist de pricing não atingir os critérios:

1. **Identificar gaps prioritários:** Listar itens faltantes por seção com criticidade
2. **Validação adicional:** Se gaps estão na Seção 3 (elasticidade), conduzir pesquisa adicional
3. **Modelagem financeira:** Se gaps estão na Seção 5, solicitar ao FP&A modelos adicionais
4. **Prazo de correção:** Máximo de 10 dias úteis para nova submissão
5. **Não lançar sem aprovação:** Pricing não deve ir ao mercado sem checklist aprovado
6. **Considerar soft-launch:** Se houver incerteza residual, fazer rollout gradual com métricas
7. **Documentar no decision log:** Registrar gaps, decisões e riscos assumidos
