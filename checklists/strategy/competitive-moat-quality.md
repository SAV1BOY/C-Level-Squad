# Checklist de Qualidade do Moat Competitivo (Competitive Moat Quality)

## Propósito
Assegurar que a avaliação de vantagens competitivas sustentáveis (moats) da organização
seja rigorosa, documentada e atualizada. Este checklist verifica se o moat foi corretamente
identificado, se a defensibilidade foi testada contra cenários adversos e se há planos
de reação para movimentos de competidores.

## Quando Aplicar
- Durante a elaboração ou revisão do plano estratégico anual
- Antes de decisões de investimento significativas (M&A, novas linhas de negócio)
- Quando um competidor faz um movimento disruptivo no mercado
- Em revisões trimestrais de posicionamento competitivo
- Antes de apresentações a investidores sobre diferenciação

## Agente Responsável
- **Primário:** Chief Strategy Officer (CSO) ou Strategy Squad Lead
- **Secundário:** Chief Product Officer (CPO) para moats de produto
- **Revisor:** CEO e CFO como aprovadores finais

## Checklist

### Seção 1 — Identificação do Moat (Moat Identification)
- [ ] Item 1: O tipo de moat principal está claramente categorizado (network effects, switching costs, brand, scale, IP, etc.)
- [ ] Item 2: Moats secundários ou complementares foram identificados e documentados
- [ ] Item 3: A fonte específica do moat está mapeada (qual recurso, processo ou ativo gera a vantagem)
- [ ] Item 4: O moat está quantificado com métricas objetivas (market share, retention rate, cost advantage)
- [ ] Item 5: A evolução histórica do moat nos últimos 12 meses está documentada
- [ ] Item 6: Existe clareza sobre se o moat é estrutural ou conjuntural

### Seção 2 — Avaliação de Defensibilidade (Defensibility Assessment)
- [ ] Item 7: O moat foi testado contra cenário de competidor com 10x mais capital
- [ ] Item 8: O tempo estimado para um competidor replicar o moat está quantificado
- [ ] Item 9: Barreiras de entrada foram classificadas como baixas, médias ou altas com justificativa
- [ ] Item 10: O custo para manter e fortalecer o moat está estimado (annual moat maintenance cost)
- [ ] Item 11: Vulnerabilidades conhecidas do moat estão documentadas honestamente
- [ ] Item 12: Cenário de disruption tecnológica que eliminaria o moat foi considerado
- [ ] Item 13: A dependência de fatores externos (regulação, parceiros) está mapeada
- [ ] Item 14: O moat foi avaliado sob a perspectiva do cliente (o cliente percebe a diferenciação?)
- [ ] Item 15: Existe evidência de que o moat se fortalece com o tempo (compounding moat)
- [ ] Item 16: Switching costs do ponto de vista do cliente estão quantificados

### Seção 3 — Análise de Competidores (Competitor Analysis)
- [ ] Item 17: Os top 5 competidores diretos estão identificados e perfilados
- [ ] Item 18: Competidores indiretos e substitutos foram mapeados
- [ ] Item 19: Os moats de cada competidor principal estão documentados para comparação
- [ ] Item 20: Movimentos estratégicos recentes dos competidores (últimos 6 meses) estão registrados
- [ ] Item 21: Sinais fracos (weak signals) de movimentos futuros dos competidores foram coletados
- [ ] Item 22: A velocidade de reação dos competidores a nossos movimentos foi estimada
- [ ] Item 23: Potenciais novos entrantes (startups, big tech) foram identificados
- [ ] Item 24: Alianças estratégicas entre competidores foram mapeadas

### Seção 4 — Plano de Reação Competitiva (Competitor Reaction Plan)
- [ ] Item 25: Para cada competidor top 3, existe um playbook de reação documentado
- [ ] Item 26: Cenários de guerra de preços foram modelados com impacto financeiro
- [ ] Item 27: Cenários de aquisição de competidores por players maiores foram considerados
- [ ] Item 28: Plano de resposta a feature parity por competidores está definido
- [ ] Item 29: Estratégia de resposta a campanhas de marketing agressivas está pronta
- [ ] Item 30: Trigger points para ativar cada playbook de reação estão definidos
- [ ] Item 31: Budget de contingência para reação competitiva está reservado
- [ ] Item 32: O time responsável por monitoramento competitivo contínuo está designado

### Seção 5 — Fortalecimento do Moat (Moat Strengthening)
- [ ] Item 33: Iniciativas ativas para fortalecer o moat estão priorizadas no roadmap
- [ ] Item 34: Investimentos em IP (propriedade intelectual) estão planejados e orçados
- [ ] Item 35: Estratégia de retenção e aquisição de talento-chave para o moat existe
- [ ] Item 36: Parcerias estratégicas que reforçam o moat estão identificadas
- [ ] Item 37: Métricas de saúde do moat são monitoradas com frequência mensal
- [ ] Item 38: O plano de investimento em moat para os próximos 12 meses está aprovado
- [ ] Item 39: Network effects, se aplicáveis, possuem growth loops documentados

### Seção 6 — Validação Externa (External Validation)
- [ ] Item 40: Pelo menos 2 analistas ou advisors externos validaram a análise de moat
- [ ] Item 41: Feedback de clientes sobre diferenciação foi coletado (NPS, win/loss analysis)
- [ ] Item 42: Win/loss analysis dos últimos 2 trimestres confirma o posicionamento do moat
- [ ] Item 43: A percepção de mercado sobre o moat foi verificada (press, analyst reports)

## Critérios de Aprovação
A avaliação de moat competitivo é considerada aprovada quando:

1. **Mínimo de 85% dos itens marcados como completos**
2. **Todos os itens das Seções 1 e 2 devem estar completos** — identificação e defensibilidade são obrigatórios
3. **Pelo menos 3 dos 5 competidores top têm perfil completo na Seção 3**
4. **Playbooks de reação existem para os top 3 competidores (Seção 4)**
5. **Pelo menos uma validação externa (Seção 6) foi realizada**
6. **O CEO e o CFO revisaram e aprovaram a avaliação final**
7. **O documento está versionado e acessível no repositório central**

## O que Fazer se Falhar
Se a avaliação de moat não atingir os critérios mínimos:

1. **Diagnóstico de gaps:** Mapear exatamente quais seções e itens falharam
2. **Priorização:** Classificar os gaps como críticos (bloqueiam decisão) ou não-críticos
3. **Sprint de correção:** Alocar no máximo 10 dias úteis para completar os itens faltantes
4. **Consultoria externa:** Se o gap for de conhecimento de mercado, considerar contratar
   análise externa especializada (analyst firms, industry experts)
5. **Escalação ao CEO:** Se gaps críticos persistirem, o CEO deve decidir se prossegue
   com risco documentado ou pausa a iniciativa
6. **Registro:** Documentar falha, motivos e plano de ação no decision log
7. **Revisão de processo:** Se falhas recorrentes, revisar o processo de coleta de inteligência competitiva
