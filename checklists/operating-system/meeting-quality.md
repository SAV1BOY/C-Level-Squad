# Checklist de Qualidade de Reuniões (Meeting Quality)

## Propósito
Assegurar que toda reunião recorrente e ad-hoc no âmbito do C-Level Squad seja
produtiva, com agenda definida, pre-reads distribuídos, decisões tomadas e
follow-ups rastreados. Este checklist combate a cultura de reuniões improdutivas
que consomem tempo executivo sem gerar output claro.

## Quando Aplicar
- Antes de agendar qualquer nova reunião recorrente
- No início de cada reunião (verificação rápida de 2 minutos)
- Na auditoria mensal de efetividade de reuniões
- Quando feedback indica insatisfação com a qualidade das reuniões
- Ao redesenhar a cadência de reuniões da organização

## Agente Responsável
- **Primário:** O convocador da reunião (meeting owner)
- **Secundário:** Chief of Staff para auditoria de qualidade de reuniões
- **Revisor:** Cada participante tem co-responsabilidade por preparação

## Checklist

### Seção 1 — Pré-Reunião (Pre-Meeting)
- [ ] Item 1: O objetivo da reunião está claramente definido (decidir, informar, brainstorm ou alinhar)
- [ ] Item 2: Agenda escrita foi distribuída com pelo menos 24 horas de antecedência
- [ ] Item 3: Cada item da agenda tem time-box e owner designado
- [ ] Item 4: Pre-reads e materiais de apoio foram enviados com pelo menos 24 horas de antecedência
- [ ] Item 5: A lista de participantes é a mínima necessária (princípio do menor grupo efetivo)
- [ ] Item 6: Participantes obrigatórios vs. opcionais estão claramente indicados
- [ ] Item 7: O tempo total da reunião é o mínimo necessário (não default de 60 min)
- [ ] Item 8: Decisões esperadas da reunião estão listadas na agenda
- [ ] Item 9: Conflitos de pauta com outras reuniões foram verificados
- [ ] Item 10: Se é reunião recorrente, a frequência ainda faz sentido (não é inercial)

### Seção 2 — Durante a Reunião (During Meeting)
- [ ] Item 11: A reunião começou no horário, sem esperar atrasados
- [ ] Item 12: O facilitador foi designado e está conduzindo ativamente
- [ ] Item 13: Um note-taker foi designado para capturar decisões e action items
- [ ] Item 14: A agenda está sendo seguida com respeito aos time-boxes
- [ ] Item 15: Tangentes são identificadas e movidas para parking lot
- [ ] Item 16: Todos os participantes tiveram oportunidade de contribuir
- [ ] Item 17: Decisões estão sendo tomadas com método claro (consenso, RACI, owner decide)
- [ ] Item 18: Quando não há consenso, o tie-breaking mechanism é ativado
- [ ] Item 19: Action items são capturados com owner, deadline e critério de done
- [ ] Item 20: A reunião está terminando com 5 minutos para recap e confirmação de next steps

### Seção 3 — Pós-Reunião (Post-Meeting)
- [ ] Item 21: Meeting notes foram distribuídas em até 4 horas após a reunião
- [ ] Item 22: Decisões tomadas estão registradas no decision log central
- [ ] Item 23: Action items foram inseridos no sistema de tracking (tarefas, tickets)
- [ ] Item 24: Participantes que não puderam comparecer receberam resumo assíncrono
- [ ] Item 25: Follow-ups da reunião anterior foram verificados no início da nova reunião
- [ ] Item 26: Materiais e artefatos gerados na reunião estão salvos no repositório
- [ ] Item 27: Se a reunião gerou decisões que afetam outros squads, eles foram notificados

### Seção 4 — Qualidade de Reuniões Recorrentes (Recurring Meeting Health)
- [ ] Item 28: Cada reunião recorrente tem um purpose statement documentado
- [ ] Item 29: A cadência (semanal, quinzenal, mensal) é revisada a cada trimestre
- [ ] Item 30: Reuniões recorrentes têm um template padronizado de agenda
- [ ] Item 31: Attendance rate da reunião está acima de 80%
- [ ] Item 32: A reunião produz outputs claros em pelo menos 80% das ocorrências
- [ ] Item 33: Reuniões sem output claro por 3 semanas consecutivas são candidatas a cancelamento
- [ ] Item 34: Feedback dos participantes sobre a reunião é coletado trimestralmente
- [ ] Item 35: O calendário total de reuniões recorrentes é auditado mensalmente pelo Chief of Staff

### Seção 5 — Cultura de Reuniões (Meeting Culture)
- [ ] Item 36: Existe uma política de no-meeting blocks (horários protegidos sem reunião)
- [ ] Item 37: A cultura de "essa reunião poderia ser um email/Slack" é incentivada
- [ ] Item 38: Reuniões de status update estão sendo substituídas por async updates onde possível
- [ ] Item 39: O custo de cada reunião (tempo executivo × hourly rate) é considerado na decisão de convocar
- [ ] Item 40: Reuniões com mais de 8 pessoas são exceção justificada, não regra
- [ ] Item 41: O default de duração é 25 ou 50 minutos (não 30 ou 60) para permitir transição
- [ ] Item 42: Reuniões de sexta-feira são minimizadas para permitir trabalho focado (deep work)

### Seção 6 — Ferramentas e Infraestrutura (Tools & Infrastructure)
- [ ] Item 43: Ferramenta de notas colaborativas está padronizada e acessível
- [ ] Item 44: Templates de agenda estão disponíveis para os tipos mais comuns de reunião
- [ ] Item 45: Sistema de tracking de action items é único e integrado ao workflow
- [ ] Item 46: Gravação de reuniões críticas é feita quando aplicável (com consentimento)
- [ ] Item 47: Integração entre calendário, ferramenta de notas e task tracker funciona

## Critérios de Aprovação
A qualidade de reuniões é considerada satisfatória quando:

1. **Mínimo de 85% dos itens aplicáveis estão sendo cumpridos consistentemente**
2. **100% das reuniões têm agenda prévia distribuída (Seção 1)**
3. **100% das reuniões geram meeting notes em até 4 horas (Seção 3)**
4. **90% dos action items são completados dentro do deadline**
5. **Auditoria trimestral de reuniões recorrentes foi realizada (Seção 4)**
6. **No-meeting blocks estão sendo respeitados (Seção 5)**
7. **Feedback dos participantes indica satisfação acima de 7/10**

## O que Fazer se Falhar
Se a qualidade de reuniões está abaixo do padrão:

1. **Meeting audit:** Chief of Staff conduz auditoria de todas as reuniões recorrentes
2. **Cancelar reuniões improdutivas:** Eliminar reuniões que não geram output consistente
3. **Training:** Oferecer treinamento de facilitação para meeting owners
4. **Templates:** Garantir que templates estão disponíveis e são fáceis de usar
5. **Accountability:** Tornar o envio de agenda prévia um requisito para a reunião acontecer
6. **CEO role modeling:** CEO deve exemplificar boas práticas de reunião em seus encontros
7. **Métricas:** Implementar score de qualidade de reunião e trackear evolução mensal
8. **Meeting-free day:** Considerar implementar um dia sem reuniões por semana
