# Checklist de Qualidade — Capital Allocation (Alocação de Capital)

## Propósito
Garantir que decisões de alocação de capital sejam tomadas com rigor: runway avaliado, ROI estimado com premissas explícitas, cenários modelados, downside protegido e gating criteria definidos. Este checklist protege a organização contra alocações de capital subótimas, preservando a disciplina financeira e maximizando o retorno sobre cada real investido.

## Quando Aplicar
- Antes de aprovar qualquer investimento acima do threshold de materialidade definido
- Na alocação anual de budget por iniciativa ou departamento
- Quando investimentos em M&A, expansão ou novos produtos são considerados
- Em decisões de funding rounds ou captação de capital
- Na revisão trimestral de alocação de capital vs performance realizada
- Quando agentes financeiros geram recomendações de investimento para validação

## Agente Responsável
- **Primário:** CFO Agent
- **Co-responsável:** CEO Agent (para decisões estratégicas de alocação)
- **Revisor:** Board Finance Committee ou investidores (quando aplicável)
- **Suporte analítico:** FP&A Agent ou Financial Modeling Agent

## Checklist

### Seção 1 — Runway Avaliado
- [ ] O cash runway atual está calculado em meses com premissas explícitas
- [ ] O burn rate mensal está documentado e segregado (fixed vs variable)
- [ ] O impacto da alocação proposta no runway está modelado
- [ ] O runway mínimo aceitável (safety threshold) está definido e respeitado
- [ ] As fontes de financiamento atuais e futuras estão mapeadas
- [ ] A necessidade de capital adicional (fundraising) está avaliada e timeline definido
- [ ] O working capital requirements está atualizado e considerado
- [ ] O impacto sazonal no cash flow está modelado
- [ ] A liquidez disponível para oportunidades emergentes está preservada (dry powder)
- [ ] O covenant compliance (se aplicável) está verificado pós-alocação

### Seção 2 — ROI Estimado
- [ ] O ROI esperado da alocação está calculado com metodologia explícita
- [ ] As premissas de receita estão documentadas e justificadas com dados de mercado
- [ ] As premissas de custo estão detalhadas e validadas por área operacional
- [ ] O payback period está estimado com timeline claro
- [ ] O NPV (Net Present Value) está calculado com discount rate justificada
- [ ] O IRR (Internal Rate of Return) está calculado e comparado com o cost of capital
- [ ] O comparativo com investimentos alternativos (opportunity cost) está documentado
- [ ] As premissas de crescimento estão calibradas contra benchmarks do setor
- [ ] O ROI incremental (marginal) está separado do ROI total
- [ ] A sensibilidade do ROI às premissas-chave está analisada
- [ ] O ROI ajustado ao risco está considerado (risk-adjusted returns)

### Seção 3 — Cenários Modelados
- [ ] No mínimo 3 cenários estão modelados: otimista, base e pessimista
- [ ] As premissas de cada cenário estão explícitas e diferenciadas
- [ ] O impacto financeiro de cada cenário está quantificado (revenue, cost, cash, margin)
- [ ] Os triggers para mudança entre cenários estão definidos
- [ ] O cenário pessimista inclui stress test com premissas severas mas realistas
- [ ] O impacto de cada cenário no runway e na saúde financeira da empresa está modelado
- [ ] A probabilidade estimada de cada cenário está declarada
- [ ] O plano de ação para cada cenário está delineado
- [ ] O cenário de "total loss" (investimento completamente perdido) está contemplado
- [ ] A análise de Monte Carlo ou sensibilidade foi realizada quando o investimento é material

### Seção 4 — Downside Protegido
- [ ] O maximum downside (perda máxima possível) está quantificado
- [ ] O downside é aceitável para a organização no contexto atual de runway e receita
- [ ] Mecanismos de proteção estão implementados: staged funding, milestones gates, clawbacks
- [ ] O stop-loss threshold está definido (quanto estamos dispostos a perder antes de parar)
- [ ] A irreversibilidade do investimento está avaliada (one-way vs two-way door)
- [ ] O impacto de perda total em outros compromissos financeiros está analisado
- [ ] Hedging strategies estão avaliadas quando aplicável (câmbio, taxas, commodities)
- [ ] O seguro contra riscos específicos foi considerado
- [ ] O plano de recovery se o investimento falhar está delineado
- [ ] A exposição concentrada (concentração excessiva em uma aposta) está avaliada

### Seção 5 — Gating Criteria Definidos
- [ ] Cada tranche de investimento tem gating criteria específicos e mensuráveis
- [ ] Os checkpoints de avaliação estão agendados com datas e responsáveis
- [ ] O processo de decisão em cada gate está documentado (quem aprova a próxima tranche)
- [ ] As métricas de performance mínima para liberação de próxima tranche estão definidas
- [ ] O processo de kill (encerramento do investimento) está definido e acordado
- [ ] Os gating criteria são objetivos e não sujeitos a interpretação (não movem goalposts)
- [ ] O plano de realocação de capital se o investimento não passar no gate está definido
- [ ] A comunicação de resultados de cada gate está planejada
- [ ] Os stakeholders que participam de cada gate estão identificados
- [ ] Existe compromisso formal do C-Level de respeitar os gates sem exceções ad hoc

### Seção 6 — Governança e Documentação
- [ ] A decisão de alocação segue o processo de aprovação definido no governance model
- [ ] A documentação está completa e arquivada no repositório oficial
- [ ] O versionamento das análises financeiras está controlado
- [ ] A auditoria trail está preservada (quem aprovou, quando, com base em quê)
- [ ] Os conflitos de interesse foram verificados e documentados
- [ ] O reporting periódico de performance do investimento está agendado
- [ ] O post-mortem de investimentos anteriores informou esta decisão

## Critérios de Aprovação
- Runway pós-alocação está acima do safety threshold definido
- ROI estimado justifica o investimento com premissas razoáveis
- Cenários otimista, base e pessimista modelados com planos de ação
- Downside máximo quantificado e aceitável para a organização
- Gating criteria definidos com compromisso formal de observância
- Análise revisada e aprovada pelo CFO Agent e CEO Agent
- Score mínimo de completude: 95% dos itens para investimentos acima do threshold de materialidade

## O que Fazer se Falhar
1. Se o runway está comprometido, não aprovar a alocação até resolver funding gap
2. Se ROI não está justificado, solicitar análise mais rigorosa ao FP&A Agent
3. Se cenários estão ausentes, não aprovar até modelagem completa
4. Se gating criteria não estão definidos, não liberar mais que a primeira tranche
5. Se downside não está protegido, redesenhar a estrutura do investimento
6. Registrar decisões de alocação (aprovadas e rejeitadas) no learning loop para calibração
7. Nunca aprovar alocação de capital sob pressão de tempo sem diligência mínima
