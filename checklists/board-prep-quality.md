# Checklist de Qualidade — Preparação para Board (Board Prep)

## Propósito
Garantir que a preparação para reuniões de board seja impecável: narrativa clara e coerente, métricas precisas e atualizadas, decisões corretamente enquadradas para o board decidir, e asks (pedidos) claramente definidos. Este checklist protege contra apresentações confusas, dados imprecisos e reuniões de board improdutivas, maximizando o tempo limitado dos conselheiros.

## Quando Aplicar
- Na preparação de cada reunião ordinária do board (tipicamente trimestral)
- Para reuniões extraordinárias convocadas por eventos significativos
- Na preparação de materiais para comitês do board (auditoria, compensação, estratégia)
- Quando agentes preparam drafts de materiais para revisão executiva
- Na revisão final do material antes do envio aos conselheiros

## Agente Responsável
- **Primário:** CEO Agent com suporte do CoS Agent
- **Contribuidores:** CFO Agent (financeiro), CTO Agent (tecnologia), CHRO Agent (pessoas)
- **Revisor:** Board Secretary ou Corporate Governance Agent
- **Preparação logística:** CoS Agent

## Checklist

### Seção 1 — Narrativa Clara
- [ ] A narrativa geral conecta os temas da reunião em um arco coerente
- [ ] O executive summary está presente no início do deck com máximo 2 slides
- [ ] A narrativa responde "como está o negócio" de forma direta e honesta
- [ ] O progresso contra a estratégia está articulado com evidências concretas
- [ ] As mudanças de contexto desde o último board estão explicitamente chamadas
- [ ] A narrativa balanceia realizações com desafios e riscos (não é propaganda)
- [ ] O tom é confiante mas honesto — sem suavizar más notícias
- [ ] A linguagem é acessível a conselheiros que não são especialistas em todas as áreas
- [ ] O material foi editado para clareza e concisão (sem slides redundantes)
- [ ] A narrativa tem fio condutor do início ao fim (não é uma coleção de updates desconexos)
- [ ] O material de pré-leitura foi enviado com antecedência mínima de 5 dias úteis

### Seção 2 — Métricas Precisas
- [ ] Todas as métricas financeiras foram validadas pelo CFO Agent com dados auditáveis
- [ ] As métricas operacionais estão atualizadas com o período mais recente disponível
- [ ] Cada métrica tem comparação: vs target, vs período anterior, vs benchmark quando disponível
- [ ] As definições de métricas são consistentes com reuniões anteriores (sem mudanças silenciosas)
- [ ] Mudanças na metodologia de cálculo estão explicitamente documentadas e justificadas
- [ ] Os gráficos e visualizações são claros, sem distorções visuais ou escalas enganosas
- [ ] As métricas de vaidade foram removidas — apenas métricas que importam estão presentes
- [ ] Os outliers ou anomalias nos dados estão explicados em notas de rodapé
- [ ] Os dados sensíveis estão marcados como confidenciais (watermark se necessário)
- [ ] A fonte de cada métrica está referenciada e o dado é reprodutível

### Seção 3 — Decisões Enquadradas
- [ ] Cada item que requer decisão do board está claramente identificado e separado
- [ ] O contexto de cada decisão está apresentado de forma concisa com opções viáveis
- [ ] As recomendações do management estão claras e fundamentadas
- [ ] Os trade-offs de cada opção estão explícitos para o board avaliar
- [ ] Os riscos de cada decisão estão identificados com planos de mitigação
- [ ] O nível de urgência de cada decisão está comunicado (pode esperar próximo board?)
- [ ] As decisões estão priorizadas na agenda (mais importantes primeiro)
- [ ] O tempo necessário para discussão de cada decisão está estimado e reservado na agenda
- [ ] As decisões de reuniões anteriores estão com status de follow-up atualizado
- [ ] Os temas informativos estão separados dos temas decisórios na agenda

### Seção 4 — Asks Definidos
- [ ] Cada ask (pedido ao board) está formulado de forma clara e específica
- [ ] O tipo de ask está identificado: aprovação, conselho, acesso a rede, suporte político
- [ ] Os asks estão dimensionados — o board sabe exatamente o que se espera deles
- [ ] O impacto de cada ask está documentado (o que muda se o board aprovar/apoiar)
- [ ] As implicações de não obter o ask estão comunicadas
- [ ] Os asks estão alinhados com a capacidade e expertise dos conselheiros
- [ ] O follow-up esperado para cada ask está definido (quando e como o board será atualizado)
- [ ] Os asks de reuniões anteriores foram endereçados com status atualizado
- [ ] Os asks financeiros ou de autorização têm documentação de suporte completa

### Seção 5 — Logística e Formatação
- [ ] A agenda da reunião está definida com tempo alocado por tema e responsável por cada seção
- [ ] O deck de board tem no máximo 20-25 slides core (appendix separado)
- [ ] O material de pré-leitura está completo e enviado no prazo
- [ ] Os appendixes detalhados estão disponíveis para deep dives on-demand
- [ ] O formato do deck segue o template padrão de board (consistência visual)
- [ ] A pauta inclui tempo para perguntas e discussão (não apenas apresentação)
- [ ] Os convidados especiais (se houver) estão confirmados com briefing prévio
- [ ] A ata da reunião anterior está aprovada e distribuída
- [ ] Os materiais estão na plataforma de board management (Board Portal ou equivalente)
- [ ] O backup plan para problemas técnicos (video, conectividade) está preparado

### Seção 6 — Dry Run e Revisão Final
- [ ] O dry run completo da apresentação foi realizado pelo menos 2 dias antes
- [ ] O feedback do dry run foi incorporado no material final
- [ ] O CEO ou presenter principal revisou e está confortável com todo o material
- [ ] Os dados foram re-verificados após o dry run para garantir atualidade
- [ ] Os Q&A antecipados estão preparados (perguntas difíceis com respostas prontas)
- [ ] O material foi revisado por spell-check e consistência de formatação
- [ ] A versão final está marcada e distribuída (sem mais mudanças após envio)

## Critérios de Aprovação
- Narrativa clara e coerente com fio condutor do início ao fim
- 100% das métricas validadas com fontes documentadas
- Todas as decisões enquadradas com opções, recomendações e trade-offs
- Asks específicos e dimensionados para cada tema que requer ação do board
- Material enviado com antecedência mínima de 5 dias úteis
- Dry run realizado com feedback incorporado
- Score mínimo de completude: 95% dos itens marcados

## O que Fazer se Falhar
1. Se a narrativa não está coerente, solicitar sessão de alinhamento com CEO Agent
2. Se métricas estão imprecisas, pausar e revalidar com fontes antes do envio
3. Se decisões não estão enquadradas, reformular com opções e recomendações explícitas
4. Se asks não estão claros, simplificar e objetivar antes da reunião
5. Se o material não está pronto 5 dias antes, considerar adiar itens não-urgentes
6. Nunca enviar material de board que não passou pelo quality gate
7. Registrar feedback do board sobre a qualidade da preparação no RalphLoop
