## Como Usar Este Mapa

1. **Por necessidade**: Use o indice por area funcional para encontrar o documento certo
2. **Por agente**: Use o indice por agente para ver todos os recursos de cada papel
3. **Por tipo**: Use o indice por tipo para encontrar todos os artefatos de uma categoria
4. **Navegacao lateral**: Use os documentos relacionados para aprofundar em temas conectados

## Manutencao

- Este mapa deve ser atualizado sempre que um novo documento for adicionado
- Revisao mensal para garantir que links estao corretos
